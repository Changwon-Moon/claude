# 성과 기록 — 발행 후 실제로 어떻게 됐나

> **이 파일이 회사의 진짜 학습 재료입니다.** 무엇이 터졌는지 알아야 다음 소재를 제대로 고릅니다.
>
> 채우는 방법 두 가지:
> 1. **자동** — 인스타 토큰(`IG_ACCESS_TOKEN`)이 발급되면 `scripts/collect-insights.mjs`가
>    매일 06:00 KST에 조회·저장·댓글 수를 여기에 채웁니다.
> 2. **수동(지금)** — 토큰 발급 전에는 오너가 인스타 앱에서 숫자를 보고 아래 표에 직접 적습니다.
>    한 줄만 적어도 됩니다. 비어 있는 것보다 훨씬 낫습니다.
>
> **저장 수**가 가장 중요한 지표입니다 — 우리 계정은 "저장해두고 다시 볼 카드"를 만드니까요.
> (docs/CONTENT_STRATEGY.md · research/PATTERN_LIBRARY.md 와 함께 봅니다)

## 표 읽는 법

| 열 | 뜻 |
|---|---|
| 발행일 | 인스타에 올린 날 |
| 카드 | `data/review/sets.json` 의 세트 label |
| 도달 | 몇 명에게 보였나 |
| 저장 | **몇 명이 저장했나 — 가장 중요** |

| 메모 | 왜 잘됐나 / 왜 안 됐나 (한 줄이면 충분) |
