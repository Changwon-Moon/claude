# 역대 최고가 인덱스 초기 수집 대기열 — 이 파일에 한 줄 밀어 넣고 푸시하면 실행된다.
# (세션은 Actions 버튼을 못 눌러서 푸시가 유일한 손잡이다)
#
# 한 줄 형식(전부 선택):  budget=5000 from=202001 to=202607
#   budget  이번 실행에서 쓸 최대 API 호출 수. 공공데이터포털 일일 한도를 넘지 않게 나눈다
#   from    시작월 (기본 202001 — 2026-08-12 오너 "모든 신고가는 2020년 1월 이후로만")
#   to      끝월 (기본: 지난달)
#
# 인덱스가 다 차면 워크플로가 스스로 아무것도 안 하고 끝난다 — 이 파일을 지울 필요 없다.

budget=7000
# 2026-08-12: 판정 단위를 전용 59·84 로 좁혀 인덱스 판번호를 2 로 올렸다 → 처음부터 다시 채운다.
#             오늘은 취소된 실행이 이미 얼마간 호출을 썼으므로 예산을 줄여 건다.
budget=4000

# 2026-08-12: 기준선을 2020-01 로 줄였다 (61곳 × 79개월 = 4,819회 → 하루면 찬다)
budget=5000 from=202001

# 2026-08-12: 오너가 **아파트 실거래가를 운영계정으로 전환**했다.
#   기준선 2020-01~2026-07 = 79개월 × 61곳 = 4,819회 → 한 번에 끝내도록 예산을 넉넉히 준다.
#   ⚠️ 명부(공동주택 API) 수집과 **같은 시각에 돌리지 않는다** — 두 수집기가 겹칠 때마다
#      명부 쪽이 `fetch failed`(연결 자체가 끊김)로 죽었다. 같은 호스트를 동시에 두드린 탓으로
#      보고 이번엔 실거래만 단독으로 돌린다. 이게 맞으면 다음부터 순서를 나눠 돌린다.
budget=5200 from=202001
