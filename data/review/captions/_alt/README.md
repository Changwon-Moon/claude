# 미채택 캡션 — 왜 남겨 두나

발행된 캡션은 상위 폴더의 `{label}.txt` 하나다. 여기 있는 것은 **오너가 고르지 않은 안**이다.
지우지 않는 이유는 "무엇을 안 골랐는가"가 다음 캡션을 쓸 때 가장 빠른 기준이기 때문이다.

## 2026-07-31 jeongbi-board — 오너가 실제로 발행하며 잘라낸 것

내가 쓴 A안(약 47줄)에서 오너는 **절반 가까이를 덜어내고** 올렸다. 무엇을 뺐는지가 기준이다.

| 뺀 것 | 왜 뺐다고 봐야 하나 |
|---|---|
| 「짚고 갈 점」 블록 5줄 (전국 누적·단지명 미정 7곳·근사 위치 2곳·HDC 제외) | 카드가 이미 말하고 있거나, 없어도 오해가 안 생기는 단서다. 단서를 길게 붙이면 본문이 묻힌다 |
| 압구정 3곳·신반포 2곳 분석 문단 | 카드의 8칸에 이미 사업지명이 다 있다. 캡션이 카드를 옮겨 적으면 읽을 이유가 준다 |
| 해시태그 10개 → 5개, 브랜드·지역 태그 → 검색어형 한글 태그 | `#서울재개발 #서울재건축 #정비사업 #현대건설 #gs건설` — 사람이 실제로 검색창에 치는 말 |

남긴 것: 훅 한 줄 → 핵심 수치 한 줄 → 순위 목록 → **전환("그런데 지도를 보면")** → 지역 목록 → 저장 유도 → 출처 → 태그.

- `jeongbi-board-B-미채택.txt` — 동네 관점(압구정 3파전). 앞부분이 카드와 겹쳐 무거웠다
- `jeongbi-board-C-미채택.txt` — 브랜드 관점(하이엔드 6곳 · 강남에는 없음). 관찰은 살아 있으니 다음에 단독 소재로 쓸 수 있다
- `jeongbi-board-D-미채택.txt` — 짧은 버전. 지도 이야기가 빠져 카드와 캡션이 따로 놀았다
