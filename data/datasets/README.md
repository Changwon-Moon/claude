# 데이터셋 캐시

> **"한 번 수집·검증한 숫자는 다시 수집하지 않는다."** — 자료허브팀. 규칙 상세: [docs/ASSET_HUB.md](../../docs/ASSET_HUB.md) §3

- 이 폴더는 `data/raw`(일일 수집물, gitignore)와 달리 **커밋 대상** — 정제·검증을 거친 재사용 자산이다
- 편집 시 순서: **캐시 확인 → 없으면 수집 → 검증(`verified: true`) → 캐시 등록 → 사용**
- `verified: false` 데이터는 카드에 쓸 수 없다 (검수 1항 차단)
- 시세류(주가·실거래가 등 매일 변하는 값)는 `perishable: true` — 캐시 재사용 금지, 표시용 이력만

## 등록된 데이터셋

[catalog.json](./catalog.json) 참조 — 새 데이터셋을 만들면 반드시 카탈로그에 한 줄 추가.
