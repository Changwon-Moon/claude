# 실거래 「문 두드림」 대기열 — 한 줄이 한 번의 진단이다. 수집이 아니라 **질문**이다.
# 형식:  lawd=29155,29140 months=202601,202604,202607
#   · lawd 를 여럿 두면 **이웃 구를 나란히** 두드린다 — 옆 구는 나오는데 이 구만 0 이면
#     코드나 구역 문제고, 둘 다 0 이면 키·기간 문제다. 이 대비가 곧 진단이다.
#   · 0건인 달은 응답 본문 앞머리도 함께 남긴다(「정상인데 0」인지 「못 읽은 오류」인지 가른다).
# 이 파일이 바뀌면 .github/workflows/molit-door.yml 이 깨어난다(푸시가 방아쇠다).

# 2026-09-02: 봉선(광주 남구 29155)이 2026.01~07 내내 rawCount 0 이었다. 코드는

# 서구(29140)·북구(29170)를 함께 두드려 **남구만 0 인지**를 본다.

# 전날 지방 수집은 정상이었다 — 이 버튼만 키를 **날것 그대로** 실었기 때문이다(수집기는 정규화한다).
# 이제 정규화·날것을 둘 다 두드린다. 종로구(11110)를 대조군으로 넣어 키 자체가 살아 있는지 먼저 본다.
