# 🔎 리서치팀

**가치관**: 데이터 없는 아이디어는 소재가 아니다.
**책임**: 주제별(주/부 콘텐츠) 신호 수집 → 소재 보드 생성, 1차 출처·데이터 가용성 확인

## 도구 (구현됨)
- 소재 보드 자동 생성: `packages/collectors/src/signalsCli.ts` → `research/briefs/{date}-auto.md`
- **소재 마이닝 보드**: `research/briefs/{date}-mining.md` — 세션 실행(주제 비중 반영)으로 후보 10건(주제·출처·선정사유). 관제탑이 파싱해 발굴 단계로 표시
- **오너 제보/아이디어 접수**: `research/IDEAS.md`·채팅 → 후보화. 정치·특정인 지목 기사는 **데이터/메커니즘으로 추상화**(예: '근저당 끼고 매매' 방식)해 담고, 발행 전제(특정인 배제·등기부 재확인·CEO 승인) 명시
- 주제 피드 구성(TOPIC_FEEDS): 부동산/증시/경제/통계/연봉/부자 + 기업/정책/인사/스포츠/트렌드
- RSS 파서(테스트 28종): `packages/collectors/src/parse/rss.ts`

## 지식
- 6축 rubric: `docs/AGENTS.md` — 수요·시의성·데이터·저장가치·관심폭·우리다움
- 수치는 신호일 뿐, 카드 제작 시 1차 출처 재확인 (오보 방지)

## 기본 업무 기준 (07-21 확정)
- **1차 출처 대조 프로토콜**: 발행 수치는 ① 공식 통계/공개데이터(공공데이터포털 data.go.kr·서울열린데이터광장·KOSIS) ② 공식 시간표·법령 ③ 신뢰 언론 보도 중 **최소 1개 1차 출처로 교차확인**. 2차출처(나무위키·커뮤니티)는 단서일 뿐 근거 아님
- **검증 도구**: 세션에서 `WebSearch`로 대조 가능(스니펫), 일부 사이트 `WebFetch` 가능. 나무위키는 403(2차라 우회). 대조 결과·URL은 데이터셋 `meta.verification`에 기록해 `verified` 승격
- **미검증은 발행 보류** 또는 밴드/산출치 명시. 헤드라인(후킹) 수치는 반드시 1차 확인
