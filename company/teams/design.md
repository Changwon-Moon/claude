# 🎨 디자인팀

**가치관**: 동일 입력 = 동일 픽셀. 런타임에 창의성은 없다(창의성은 템플릿 제작 때).
**책임**: 콘텐츠 JSON → 1080×1350 카드 PNG (결정적 렌더)

## 도구 (구현됨)
- 렌더러: `packages/renderer` (Playwright, 스키마 검증, 캐러셀, 해시 동일성 검증됨). 폰트 로딩 후 레이아웃 후처리 훅 `window.__wiritFit` 호출 — 렌더·검수 파이프라인 동일 적용(결정적)
- **순위표 `ranking-table@1` — 확정 레퍼런스: "2026 대기업 평균연봉 Top10"**. 구현·확정된 기능:
  · 제목행 라벨(순위·기업·연봉·직원수)을 내용 열 위 **가운데 정렬**(값·보조 열 밀도별 고정폭 + 중앙정렬)
  · **제목 fit-to-width**: 표의 좌우 끝을 실측해 제목 좌우 끝을 **표와 동일하게 자동 정렬**하고 그 폭에 맞는 최대 폰트로 채움
  · **1·2·3위 금·은·동 메달**(🥇🥈🥉) + 기업명 금/은/동(진한 금속톤·미세 그림자, 가독성 우선) — `medal`/`rankClass` 헬퍼
  · **좌우 대칭 여백**(justify-content:center) + 데이터 행 **flex 세로 꽉 채움**(하단 여백 조절 가능)
  · 직원수 소수점 정렬(figure space U+2007), 공동순위(`rank`) 지원, 로고 3단계 폴백
- **디자인 검수기**: `packages/renderer/src/designQa.ts` + `qaCli.ts` (`pnpm --filter @wirit/renderer qa <content>`) — 렌더 좌표 측정 자동 검출: 숫자열 정렬 어긋남·우측치우침·이름 잘림·요소 넘침·행 겹침·**안쪽 여백(패딩) 침범(padcross)**. error 시 종료코드 1(발행 차단)
- 가동 템플릿: ranking-table(시안A)·market-daily + dummy-card
- 브랜드 토큰: `templates/_shared/base.css` (잉크네이비 팔레트, 폰트 3종 번들)

## 기본 업무 기준 (카드 제작 표준 · 07-21 확정 — 세션 지시 누적)
- **제목**: fit-to-width로 폭에 맞춰 크게. **좌우 여백은 아래 표(내용)와 동일**하게 맞춘다(카드 끝 풀블리드 지양). 상단 부제·wirit 뱃지와 **겹치지 않게** 아래 배치
- **헤더(제목 행)**: 항상 내용 열 위 **가운데 정렬**. 각 행이 별도 grid면 값 열을 고정폭으로
- **순위 카드**: 1·2·3위 금·은·동 메달 + 기업명 금/은/동 색. **극단값(최고/최저) 하이라이트**(코발트/레드)
- **항목 많으면 2단 표**(좌우 분할). 단위(km/h 등)는 셀 안 작은 회색
- **지하철**: 공식 노선 뱃지(metroBadge), 급/완 **컬러 태그**(급=레드·완=회색)
- **후킹 커버**: 실사진 풀블리드 + 대형 후킹 문구 + 극단 대비 + CTA. 사진은 **감성(인물·분위기) 우선**. 어두운 사진엔 **흰 반전 wirit 뱃지 + 하단 잉크 푸터 바**(본문 톤 통일·아이덴티티 각인) — 사진 커버 기본값. **커버 후킹 제목·하단 워드마크는 크게**(제목 98px·워드마크 40px), CTA는 **👉 손가락 이모지 + "…다음장에서"** 유도 문구
- **캐러셀 기본 구성 = 2장**(1p 후킹 커버 + 2p 데이터 표). 마무리(p3) 장은 **기본 미포함**(팔로우 유도는 표 카드 하단으로 흡수) — 콘텐츠가 길거나 요약이 필요할 때만 옵션
- 배경 **캡처 대비 워터마크**(옅은 wirit.), 데이터 행 flex로 **하단 여백 제거**
- **인스타 비율**: 지하철 등 **후킹 카드셋은 1:1 정사각(1080×1080)** — 피드·그리드·탐색 어디서도 **안 잘림 보장**. 데이터 밀도 큰 순위표(평균연봉 등)는 **4:5(1080×1350) 유지 가능**. 비율은 **템플릿별 `config.json`(width/height)**로 지정, 카드 높이는 뷰포트 100%라 config만 바꾸면 됨. 브랜드 요소(wirit 뱃지·하단 @wirit_note 푸터)는 **어떤 비율에서도 잘리지 않게**
- **우상단 wirit 뱃지 = 배경 따라 분기**: **밝은 종이 배경(표·순위)은 `wirit.` 잉크색 워드마크만**(박스 없이, 공간 절약), **어두운 사진 커버는 흰 박스 뱃지 유지**(각인 강함). 마침표는 코발트
- **렌더 결정성**(동일 입력=동일 픽셀) + **designQa 통과** 필수
