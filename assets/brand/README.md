# assets/brand — 브랜드 원본 자산

여기에 들어갈 파일 (계약):

| 파일 | 용도 | 상태 |
|---|---|---|
| `logo.png` | 원형 로고 원본 (인스타 프로필과 동일한 파일) | ⬜ 업로드 필요 |
| `wordmark.svg` | 카드 하단 워터마크용 워드마크 (M2 세션이 제작) | ⬜ M2에서 제작 |

## logo.png 업로드 방법 (비개발자용 — 2분)

1. github.com에서 이 저장소를 연다 → 브랜치를 작업 브랜치로 선택
2. `assets/brand` 폴더로 이동 → 우측 상단 **Add file → Upload files**
3. 로고 파일을 드래그해서 놓고, 파일명이 `logo.png`인지 확인
4. 하단 **Commit changes** 클릭 — 끝

또는 M2 세션을 시작할 때 채팅에 로고 이미지를 첨부하며 "이 로고를 assets/brand/logo.png 기준으로 워드마크 SVG를 만들어줘"라고 요청해도 된다 (이 경우에도 원본 PNG는 위 방법으로 한 번 올려두는 것을 권장).

컬러·사용 규칙은 [../../docs/BRAND.md](../../docs/BRAND.md) 참고.
