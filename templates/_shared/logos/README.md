# _shared/logos — 기업·브랜드 로고 라이브러리

카드에 실제 기업 로고를 넣기 위한 자산 폴더. 템플릿은 `items[].logo` (또는 `featured.logo`) 에 지정된 **slug**로 `logos/{slug}.svg` (또는 `.png`)를 찾아 렌더한다. 로고가 없으면 이름 첫 글자 **모노그램으로 자동 폴백**한다.

## 현재 보유 (실제 브랜드 색상)

| slug | 기업 | 색 |
|---|---|---|
| samsung | 삼성 계열 | #1428A0 |
| lg | LG 계열 | #A50034 |
| naver | 네이버 | #03C75A |
| kakao | 카카오 | #FFCD00 |
| hyundai | 현대 계열 | #002C5F |

> 초기 시드는 simple-icons(오픈소스 아이콘 세트)에서 가져와 브랜드 색을 입힌 것. 단색 심볼이라 실제 CI와 완전히 같지는 않을 수 있다.

## 로고 표시 3단계 폴백

콘텐츠 항목이 로고를 지정하는 방법은 3가지이며, 위에서부터 우선한다:

1. **실제 로고 이미지** — `"logo": "{slug}"` → `_shared/logos/{slug}.svg` 렌더 (가장 좋음)
2. **브랜드 컬러칩** — `"logoColor": "#EA002C", "logoText": "SK"` → 브랜드색 원 + 약칭(흰 글씨). 실제 로고 파일이 없을 때 회색 모노그램보다 훨씬 로고답게 보이는 임시 대체
3. **모노그램** — 아무것도 없으면 이름 첫 글자(회색 원)

## 로고 추가 방법 (실제 로고로 업그레이드)

> ⚠️ **허브 규칙**: 파일 추가 시 `catalog.json`에 출처·라이선스 항목도 함께 추가해야 한다 ([docs/ASSET_HUB.md](../../../docs/ASSET_HUB.md)). `node scripts/validate-assets.mjs`가 누락을 잡는다.

1. 로고 파일(SVG 권장, 없으면 투명 PNG)을 이 폴더에 `{slug}.svg`로 저장
   - slug는 소문자·하이픈 (예: `sk-hynix`, `posco`, `daewoo-en-c`)
2. 콘텐츠 JSON의 해당 항목에 `"logo": "{slug}"` 추가 → 자동으로 실제 로고로 교체
3. 실제 로고가 생기면 `logoColor`/`logoText`는 무시된다(logo 우선)

## 자동 수집이 안 되는 이유 (2026-07 빌드 환경)

- 이 빌드 환경은 **외부 웹 이미지 다운로드가 차단**되어 있어(프록시 정책), 웹에서 로고를 자동으로 긁어올 수 없다.
- simple-icons(오픈 아이콘 세트)에도 SK하이닉스·건설사·포스코 등 상당수 한국 기업이 없다.
- 그래서 실제 로고가 없는 기업은 **브랜드 컬러칩**(위 2단계)으로 처리한다. 색은 각 사 브랜드에서 연상되는 근사색이며 정식 CI와 다를 수 있다.
- **정식 로고 확보 시**: 운영자가 공식 브랜드 리소스/보도자료에서 받은 파일을 이 폴더에 넣으면 자동 교체된다.

## ⚠️ 저작권·상표 주의 (중요)

- 기업 로고는 각 사의 **등록상표**다. 우리는 **정보 전달 목적의 지명적 사용**(nominative use) 범위에서만 사용한다 (누가 만든/어떤 회사인지 식별). 후원·제휴를 암시하지 않는다.
- 로고를 왜곡·변형하거나 비하 맥락에 쓰지 않는다.
- 권리자가 문제를 제기하면 **즉시 교체/삭제**한다.
- 유료·라이선스가 명시된 로고 팩은 라이선스를 준수한다.
- 상세 정책: [../../../docs/DATA_SOURCES.md](../../../docs/DATA_SOURCES.md) 법적·윤리 체크리스트, [../../../docs/TEMPLATES.md](../../../docs/TEMPLATES.md) §5b.

## 한계 (2026-07 현재)

- 대기업·플랫폼 위주로만 보유. **건설·금융·SK하이닉스·포스코 등 상당수 한국 기업 로고는 아직 없음** → 해당 카드는 모노그램으로 표시된다.
- 로고 라이브러리는 운영하면서 **점진적으로 수집**해 채운다(핵심 자산). 자주 쓰는 소재의 기업부터 우선 확보 권장.
