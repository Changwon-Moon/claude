# _shared/logos — 기업·브랜드 로고 라이브러리

카드에 실제 기업 로고를 넣기 위한 자산 폴더. 템플릿은 `items[].logo` (또는 `featured.logo`) 에 지정된 **slug**로 `logos/{slug}.svg` (또는 `.png`)를 찾아 렌더한다. 로고가 없으면 이름 첫 글자 **모노그램으로 자동 폴백**한다.

## 현재 보유 (실제 브랜드 색상)

| slug | 기업 | 색 |
|---|---|---|
| samsung | 삼성 계열 | #1428A0 |
| lg | LG 계열 | #A50034 |
| naver | 네이버 | #03C75A |
| kakao | 카카오 | #FFCD00 |
| hyundai | 현대 계열 | #002C5F |

> 초기 시드는 simple-icons(오픈소스 아이콘 세트)에서 가져와 브랜드 색을 입힌 것. 단색 심볼이라 실제 CI와 완전히 같지는 않을 수 있다.

## 로고 추가 방법

1. 로고 파일(SVG 권장, 없으면 투명 PNG)을 이 폴더에 `{slug}.svg`로 저장
   - slug는 소문자·하이픈 (예: `sk-hynix`, `posco`, `daewoo-en-c`)
2. 편집 시 콘텐츠 JSON의 해당 항목에 `"logo": "{slug}"` 추가 → 자동으로 로고가 뜬다
3. slug 없거나 파일 없으면 모노그램(첫 글자)으로 폴백 — 깨지지 않는다

## ⚠️ 저작권·상표 주의 (중요)

- 기업 로고는 각 사의 **등록상표**다. 우리는 **정보 전달 목적의 지명적 사용**(nominative use) 범위에서만 사용한다 (누가 만든/어떤 회사인지 식별). 후원·제휴를 암시하지 않는다.
- 로고를 왜곡·변형하거나 비하 맥락에 쓰지 않는다.
- 권리자가 문제를 제기하면 **즉시 교체/삭제**한다.
- 유료·라이선스가 명시된 로고 팩은 라이선스를 준수한다.
- 상세 정책: [../../../docs/DATA_SOURCES.md](../../../docs/DATA_SOURCES.md) 법적·윤리 체크리스트, [../../../docs/TEMPLATES.md](../../../docs/TEMPLATES.md) §5b.

## 한계 (2026-07 현재)

- 대기업·플랫폼 위주로만 보유. **건설·금융·SK하이닉스·포스코 등 상당수 한국 기업 로고는 아직 없음** → 해당 카드는 모노그램으로 표시된다.
