## 반드시 지키는 원칙

- **의심되면 사람에게**: 확신이 낮거나 오너의 취향·전략이 걸리면 `needsHuman=true`로 승인 요청한다.
- **CEO 원칙 우선**: [company/CEO.md](../company/CEO.md)의 관련 원칙을 먼저 따른다 — 오너가 같은 말을 두 번 하게 하지 않는다.

## 세부 지침 (07-31 학습 — 오너와 일하는 순서)

- **단계마다 끊어 묻는다.** 소재 → 그림 형태 → 제목 → 확정 → 캡션.
  앞 단계를 오너가 승인하기 전에 다음 단계를 만들어 오지 않는다.
- **"가능한지 시험해 보고 싶다"는 실험을 하라는 말이다.** 완성품을 대신 내밀지 않는다.
  시험 산출물에는 "발행 금지"라고 적고 `sets.json` 에 올리지 않는다.
- **선택지는 렌더해서 보여준다.** 제목 안·로고·색 팔레트 모두 이미지 한 장으로 비교하게 만든다.
- **자동으로 가져온 자산은 붙이기 전에 대조표로 확인받는다.**
- **오너가 같은 지적을 두 번 하면 문서화 실패다.** 세 곳을 함께 고친다:
  `CARD_CHECKLIST §2` → 잴 수 있으면 `designQa` 검수항 승격 → 팀 학습 로그.
  검수항을 넣었으면 **일부러 어긋나게 되돌려 잡히는지 확인**한다.

## 세부 지침 (2026-07-31 학습 — 두 카드를 연달아 만들며)

### 오너가 "검수해줘"라고 하면 팀을 나눠 각자 다른 눈으로 본다
07-31 에 디자인·AS·기획 세 팀을 각각 돌렸더니 **셋 다 서로 다른 실제 결함**을 찾았다.
한 사람이 세 번 보는 것과 세 관점이 한 번씩 보는 것은 다르다.
- **디자인팀** — 렌더 이미지를 직접 보고 기준 문서와 하나씩 대조 (그래픽이 가려진 곳)
- **AS팀** — 재발 방지. 지적이 코드로 내려갔는지, 검수 목록에서 빠진 요소는 없는지
- **기획팀** — 수치·문구를 원 자료와 한 글자씩 대조, 말이 사실보다 세지 않은지
가장 아팠던 지적은 AS팀에서 나왔다: 검수가 통과한 게 아니라 **아무것도 안 재고 있었다.**

### 파이프라인이 조용히 죽어 있을 수 있다
데이터가 오래됐을 때 "환경 제약"으로 설명하기 전에 **실행 기록을 확인한다.**
확인할 수 없는 환경이면 오너에게 화면을 요청한다 — 추측한 원인을 보고하지 않는다.
07-31 에 증시 수집이 셀프테스트 실패로 죽어 있었는데, 나는 그걸 세션 외부망 탓으로만 말하고 있었다.

### 확정 뒤에 할 일은 정해져 있다
`builders.json` · `sets.json` · `pixel-baselines.json` · `CARD_CHECKLIST §5` · 캡션.
그리고 **산출 위치를 `data/out/_spike` 에서 `data/content/{날짜}/` 로 옮긴다** —
시안 서랍에 둔 채 세트에만 올리면 실사이트에 카드가 영영 안 뜬다.

### 확정본이라도 발행 게이트는 따로다
오너 확정 = 그림이 됐다는 뜻이고, 발행 가능 = 수치가 1차 출처로 대조됐다는 뜻이다.
보도에서 옮긴 값만 있는 카드는 `verified=false` 로 두고 세트 note 에 그 사실을 적는다.

## 2026-08-06 추가 — 세션을 열 때와 닫을 때

**열 때 — 푸시 길부터 본다.** `doctor` 가 `check-push` 를 부른다. 막혀 있으면
**작업을 시작하기 전에 오너에게 말한다.** 이번 세션에서 카드 한 장을 네 번 고쳐 확정까지
마친 뒤에야 알았고, 커밋 6건이 컨테이너에 갇혔다. clone 은 세션 시작에 이미 끝나 성공하고
커밋도 전부 로컬이라 성공한다 — **실패가 마지막 한 번에 몰려서 온다.**

**막혀 있어도 작업은 계속할 수 있다.** 안 되는 건 저장뿐이다:

| 되는 것 | 안 되는 것 |
|---|---|
| 카드 제작·수정·렌더·검수·캡션, PNG 전달, 인스타 발행 | GitHub 저장, 관제탑 화면 갱신, 수집 워크플로 방아쇠 |

**닫을 때 — 컨테이너 안에만 있는 커밋은 없는 것과 같다.**
푸시가 막힌 채 세션을 끝내지 않는다. `git format-patch origin/<브랜치>..HEAD --stdout` 로
뽑아 `SendUserFile` 로 오너에게 보낸다. 원격이 앞서 있으면 **먼저 rebase 해서** 충돌 없는
패치를 만든다(읽기는 열려 있는 경우가 많다). 패치는 오너가 터미널에서 칠 물건이 아니라
**다음 세션의 나에게 넘기는 물건**이다 — 새 세션에서 첨부받아 내가 적용하고 푸시한다.

**막힌 것을 다른 인증 경로로 돌아가지 않는다.** 샌드박스 우회다.

**오너에게 없는 화면을 안내하지 않는다.** 코워크 `[+]` 에는 저장소를 붙이는 항목이 없다
(파일/스킬/커넥터/플러그인 뿐). 모르면 "확인해 보겠습니다"가 맞다 — 그럴듯한 경로를 지어내면
오너가 헛걸음한다.
