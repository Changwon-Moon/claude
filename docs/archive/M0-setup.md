# M0 셋업 가이드 — 계정·API 키 발급 (완전 초보자용)

> 이 문서는 **컴퓨터/개발을 전혀 몰라도** 따라 할 수 있게 만들었습니다.
> 순서대로 하나씩 하세요. 급하지 않습니다. 총 1~2시간.
>
> **용어 딱 두 개만 미리 알기**
> - **API 키(키)**: 우리 프로그램이 각 사이트(인스타·정부데이터 등)의 정보를 꺼내 쓸 수 있게 해주는 **비밀번호 같은 긴 문자열**입니다. 사이트마다 하나씩 발급받습니다.
> - **깃허브(GitHub)**: 우리 프로젝트의 모든 파일이 보관된 **인터넷 창고**입니다. 이 키들을 안전하게 넣어둘 금고도 여기 있습니다.
>
> **막히면**: 막힌 화면을 **휴대폰이나 컴퓨터로 캡처(스크린샷)** 해서, 새 Claude 채팅에 그림을 붙여넣고 "M0 하다가 여기서 막혔어"라고 쓰면 됩니다.

## 이 작업으로 최종적으로 얻는 것

아래 **비밀 문자열(키)**들을 발급받아서, 마지막에 깃허브 금고에 넣는 것이 전부입니다.
**전부 다 지금 할 필요는 없습니다.** 아래처럼 두 묶음으로 나눠서 하세요.

### 🟢 지금 발급 (전부 무료·카드 불필요) — 정확한 데이터·로고로 카드 만들기용

| 무엇 | 어디서 받나 | 금고에 넣을 이름 | 이걸로 만드는 것 |
|---|---|---|---|
| 전자공시 열쇠 | 금융감독원 DART | `DART_API_KEY` | **평균연봉·실적** 카드(정확한 공시값) |
| 한국은행 열쇠 | 한국은행 ECOS | `ECOS_API_KEY` | **환율·금리** 카드 |
| 정부 데이터 열쇠 | 공공데이터포털 | `DATA_GO_KR_API_KEY` | **부동산 실거래·청약** 카드 |
| 로고 열쇠 (선택) | Brandfetch | `BRANDFETCH_API_KEY` | 남은 회사 **로고 자동 취득** |

> Brandfetch는 **선택**입니다 — 이미 위키미디어로 로고 대부분을 자동으로 받고 있어요. 안 해도 됩니다.

### 🔵 나중 발급 (발행·AI 단계에서) — 지금 안 해도 됨

| 무엇 | 어디서 받나 | 금고에 넣을 이름 | 언제 필요 |
|---|---|---|---|
| 인스타 접속 열쇠 | Meta 개발자 사이트 | `IG_ACCESS_TOKEN` | 실제 **인스타 발행** 시작할 때 |
| 인스타 계정 번호 | 같은 곳 | `IG_USER_ID` | 위와 동일 |
| Claude(AI) 열쇠 | Anthropic 콘솔 | `ANTHROPIC_API_KEY` | AI 직원(에이전트) 켤 때 · **유일하게 소액 결제** |

> 오른쪽 "이름"은 **철자·대문자·밑줄(_)까지 정확히 그대로** 써야 합니다. 프로그램과 약속된 이름이라 하나라도 틀리면 작동하지 않아요. 복사해서 쓰세요.

**준비물**: 깃허브 계정. (🔵 나중 묶음엔 페이스북 계정·카드 1장·인스타 @wirit_note 도 필요)

> 💡 **추천 순서**: 오늘은 🟢 묶음(DART → ECOS → 공공데이터, 다 무료)만 하세요. 20~30분이면 됩니다. 🔵는 발행 단계 갈 때 저와 함께 하면 됩니다.

> 💡 **팁**: 키를 받을 때마다 컴퓨터 **메모장(윈도우) / 메모 앱(맥)**에 "이름 = 값" 형태로 붙여넣어 임시로 모아두세요. 마지막 6단계에서 한꺼번에 금고에 옮기고, 그다음 메모장은 지웁니다.
> 예시:
> ```
> ECOS_API_KEY = ABCD1234...
> ANTHROPIC_API_KEY = sk-ant-...
> ```

## 1단계. 인스타그램을 "프로페셔널 계정"으로 바꾸기 (5분)

일반 계정으로는 프로그램이 글을 못 올립니다. 무료로 "프로페셔널"로 바꾸면 됩니다. (팔로워에게 티 안 나고, 언제든 되돌릴 수 있어요.)

1. 휴대폰 **인스타그램 앱**에서 @wirit_note 로 로그인
2. 내 프로필 화면 → 오른쪽 위 **줄 세 개(≡)** 누르기
3. **설정 및 활동** 누르기
4. 아래로 내려서 **크리에이터/비즈니스용 도구 및 컨트롤** (또는 "계정 유형 및 도구") 누르기
5. **프로페셔널 계정으로 전환** 누르기 → 안내를 넘기다가
6. 유형은 **비즈니스** 선택
7. 카테고리를 고르라고 하면 아무거나 (예: "디지털 크리에이터") 선택 → 계속
8. 중간에 **"페이스북 페이지에 연결"** 화면이 나오면 → **건너뛰기 / 나중에 하기** 누르기
   - ⚠️ 우리 방식은 페이스북 페이지가 **필요 없습니다.** 연결하지 마세요.

✅ **완료 확인**: 내 프로필에 **"프로페셔널 대시보드"** 라는 메뉴가 새로 보이면 성공.

## 2단계. 인스타 열쇠 2개 받기 (30분, 제일 어려운 단계 — 천천히)

프로그램이 인스타에 글을 올리려면 Meta(페이스북 회사)에서 "앱"이라는 걸 하나 만들어야 합니다. 어렵게 들리지만, **우리는 남에게 서비스하는 게 아니라 내 계정에만 올리는 거라, 복잡한 심사 없이** 그냥 만들어서 열쇠만 받으면 됩니다.

> 이 단계는 **컴퓨터(노트북/데스크톱)로** 하시는 걸 강력히 권합니다. 화면이 넓어야 편해요.

### 2-1. 개발자 등록

1. 인터넷 브라우저에서 **developers.facebook.com** 접속
2. 오른쪽 위 **로그인** → 본인 **페이스북 개인 계정**으로 로그인
3. 처음이면 **시작하기(Get Started)** 버튼이 보임 → 눌러서 개발자 등록 (이메일·휴대폰 인증 몇 번, 하라는 대로)

### 2-2. 앱 만들기

1. 위쪽 메뉴 **내 앱(My Apps)** → **앱 만들기(Create App)** 누르기
2. **"사용 사례를 선택하세요"** 같은 화면이 나오면 → **Instagram** 이 들어간 항목 선택
   - 만약 목록에 딱 맞는 게 없으면 **"기타(Other)"** → **"비즈니스(Business)"** 선택해도 됩니다
3. **앱 이름**: `wirit` 이라고 입력 (아무 이름이나 가능)
4. **연락처 이메일**: 본인 이메일 입력
5. **앱 만들기** 눌러서 생성 (비밀번호 다시 입력하라고 할 수 있음)

### 2-3. 인스타 연결하고 열쇠 받기

1. 앱이 만들어지면, 화면 **왼쪽 메뉴**에서 **Instagram** 을 찾아 누르기
   - 그 아래 **"API setup with Instagram login"** (한국어면 "Instagram 로그인으로 API 설정") 누르기
2. 화면에 **1, 2, 3 번호가 매겨진 상자**가 보입니다. **1번 "Generate access tokens"** 상자를 봅니다
3. **"Add account" 또는 "Add an Instagram account"** 버튼 누르기
4. 팝업 창이 뜨면 → @wirit_note 로 **로그인** → 권한 요청에 **허용(Allow)** 누르기
5. 다시 원래 화면으로 돌아오면, 연결된 계정 옆에 **"Generate token"** 버튼이 생김 → 누르기
6. **아주 긴 문자열**이 나타납니다. 이게 첫 번째 열쇠예요.
   - 복사 → 메모장에 `IG_ACCESS_TOKEN = 여기에붙여넣기` 형태로 저장
7. 같은 화면 근처에 **숫자로 된 계정 ID**(Instagram user ID)가 보이면 그것도 복사
   - 메모장에 `IG_USER_ID = 그숫자` 저장
   - ❓ 숫자 ID가 어디 있는지 안 보이면 → 그냥 넘어가세요. 나중에 M1 세션에서 "토큰으로 IG_USER_ID 찾아줘"라고 하면 제가 찾아드립니다.

✅ **완료 확인**: 메모장에 `IG_ACCESS_TOKEN` 값이 저장됨. (앱은 그대로 두면 됩니다. 심사 신청 같은 거 안 해도 돼요.)

> 이 열쇠는 60일 뒤 만료되지만, 나중에(M5 단계) 자동으로 갱신하는 기능을 넣을 거라 그 후엔 신경 쓸 필요 없습니다.

## 3단계. 정부 데이터 열쇠 받기 (15분) — 부동산 데이터용

1. 브라우저에서 **data.go.kr** (공공데이터포털) 접속
2. 오른쪽 위 **회원가입** → 가입 후 **로그인**
3. 로그인한 상태에서 **마이페이지**로 이동하면 **"일반 인증키(Encoding)"** 라는 긴 문자열이 보입니다
   - 이게 열쇠예요. 복사 → 메모장에 `DATA_GO_KR_API_KEY = 값` 저장
4. 이제 이 열쇠로 "부동산 실거래가" 데이터를 쓸 수 있게 **신청**을 합니다:
   - 위쪽 **검색창**에 `아파트 매매 실거래가` 입력하고 검색
   - 결과 중 **"국토교통부_아파트 매매 실거래가"** (오픈API 종류) 클릭
   - **활용신청** 버튼 누르기 → 활용목적란에 `콘텐츠 제작 및 데이터 분석` 정도로 적기 → 신청
   - 대부분 **바로 승인**되거나 몇 시간 내 승인됩니다
5. 같은 방법으로 검색창에 `아파트 전월세 실거래가` 도 검색해서 **활용신청** 한 번 더

✅ **완료 확인**: 메모장에 `DATA_GO_KR_API_KEY` 저장됨 + 실거래가 2종 신청함.

## 4단계. 한국은행 데이터 열쇠 받기 (10분) — 금리·환율용

1. 브라우저에서 **ecos.bok.or.kr/api** 접속 (한국은행 경제통계시스템 OpenAPI)
2. **회원가입** → **로그인**
3. **인증키 신청** 메뉴 누르기 → 사용 목적 간단히 적기(예: `데이터 콘텐츠 제작`) → 신청
4. 발급된 **인증키** 복사 → 메모장에 `ECOS_API_KEY = 값` 저장 (보통 즉시~하루 내 발급)

✅ **완료 확인**: 메모장에 `ECOS_API_KEY` 저장됨.

## 5단계. 전자공시(DART) 열쇠 받기 (10분) — 평균연봉·실적용 ⭐

기업의 **정확한 평균연봉**(사업보고서 공시값)을 쓰기 위한 열쇠입니다. **무료·카드 불필요**, 발급이 제일 쉬운 편이에요.

1. 브라우저에서 **opendart.fss.or.kr** 접속 (금융감독원 전자공시 오픈API)
2. 상단 메뉴 **인증키 신청/관리** → **인증키 신청** 누르기
3. 이름·이메일·비밀번호 등 간단히 입력 → **신청** (사용목적란이 있으면 `데이터 콘텐츠 제작` 정도)
4. 입력한 **이메일로 인증 메일**이 옵니다 → 메일 열어서 **인증 링크** 클릭
   - 인증하면 **40자리 인증키**가 발급됩니다 (메일 안 또는 사이트 "인증키 신청/관리" 화면에서 확인)
5. 그 40자리 열쇠 복사 → 메모장에 `DART_API_KEY = 값` 저장

✅ **완료 확인**: 메모장에 `DART_API_KEY` 저장됨. (하루 조회 한도가 넉넉해 우리 용도엔 충분합니다.)

> 이 열쇠를 금고에 넣고 나면, 제가 **"평균연봉 수집 워크플로"**를 돌려 삼성전자·SK하이닉스 등의 **정확한 공시 연봉**을 자동으로 가져와 카드로 만듭니다.

## 6단계. (선택) 로고 열쇠 — Brandfetch (10분)

남은 소수 회사 로고까지 자동으로 채우고 싶을 때만 하세요. **안 해도 됩니다** — 이미 위키미디어에서 대부분 자동 취득됩니다.

1. 브라우저에서 **brandfetch.com/developers** 접속
2. **회원가입**(구글 계정 등) → 로그인
3. 개발자 **대시보드(Dashboard)**에서 **API Key**(또는 client id)를 만들거나 확인 → 복사
   - 무료 요금(Free)로 시작하면 됩니다
4. 메모장에 `BRANDFETCH_API_KEY = 값` 저장

✅ **완료 확인**: 메모장에 `BRANDFETCH_API_KEY` 저장됨. (화면이 가이드와 다르면 캡처해서 새 채팅에 물어보세요.)

## 7단계. Claude(AI) 열쇠 받기 (10분) — AI 두뇌용 · 🔵 나중에 해도 됨

우리 리서치·기획·편집 AI가 쓰는 열쇠입니다. 이것만 **소액 결제(카드 등록)**가 필요합니다.

1. 브라우저에서 **console.anthropic.com** 접속 → **회원가입** → **로그인**
2. 왼쪽/상단 메뉴에서 **Billing**(결제) 찾기 → 카드 등록 → **$10 정도 충전** (초반엔 충분해요)
3. **API Keys** 메뉴 → **Create Key**(키 만들기) 누르기 → 이름 `wirit` 입력 → 생성
4. 만들어진 열쇠(`sk-ant-...`로 시작)를 **즉시 복사** → 메모장에 `ANTHROPIC_API_KEY = 값` 저장
   - ⚠️ 이 열쇠는 **딱 한 번만 보여줍니다.** 창을 닫기 전에 꼭 복사하세요. (놓치면 새로 만들면 됩니다)
5. (안전장치·권장) Billing 화면에서 **월 사용 한도(Spend limit)** 를 `$50` 로 설정 → 예상외 과금 방지

✅ **완료 확인**: 메모장에 `ANTHROPIC_API_KEY` 저장됨.

## 8단계. 깃허브 "금고"에 열쇠 넣기 (15분) — 그림 그리듯 따라하기

지금 메모장에 모아둔 열쇠들을 **깃허브라는 인터넷 창고의 금고(Secrets)**에 옮겨 넣습니다. **프로그램을 설치할 필요 없이, 인터넷 브라우저에서 클릭만** 하면 됩니다. (오늘 🟢 묶음만 했다면 3~4개, 전부 했다면 7개)

> **"금고(Secrets)가 뭔가요?"** — 열쇠를 코드 파일에 그냥 적으면 누구나 볼 수 있어 위험합니다. 깃허브는 열쇠를 **자물쇠 채운 서랍**에 따로 보관해주고, 우리 프로그램이 실행될 때만 몰래 꺼내 씁니다. 한 번 넣으면 사람은 다시 그 값을 볼 수 없어요(그게 정상이고 안전한 겁니다).

### 순서

1. 브라우저에서 **github.com** 접속 → 로그인
2. 우리 프로젝트 저장소 열기
   - 주소창에 직접 쳐도 됩니다: **github.com/Changwon-Moon/claude**
   - (또는 로그인 후 왼쪽 저장소 목록에서 **claude** 클릭)
3. 저장소 화면 **맨 위 가로 메뉴**를 봅니다: `Code  Issues  Pull requests ... ⚙️ Settings`
   - 맨 오른쪽 톱니바퀴 **Settings**(설정) 클릭
   - ❓ Settings가 안 보이면 → 로그인한 계정이 이 저장소 주인이 맞는지 확인
4. Settings로 들어가면 **왼쪽에 세로 메뉴**가 깁니다. 아래로 내려서
   - **Secrets and variables** 를 찾아 클릭 (누르면 하위 항목이 펼쳐짐)
   - 그 아래 **Actions** 클릭
5. 이제 **"Actions secrets and variables"** 화면입니다. 오른쪽에 초록/흰색 버튼 **"New repository secret"**(새 저장소 시크릿) 클릭
6. 입력 칸이 두 개 나옵니다:
   - **Name**(이름) 칸: `IG_ACCESS_TOKEN` 이라고 정확히 입력
   - **Secret**(값) 칸: 메모장에 저장해둔 그 열쇠의 **값** 붙여넣기
   - 아래 **Add secret**(시크릿 추가) 버튼 클릭
7. 방금 한 6번을 **나머지 열쇠에도 반복**합니다. 매번 "New repository secret" → 이름/값 입력 → Add secret:

   **🟢 오늘 (무료):**

   | Name 칸에 넣을 것 (그대로) | Secret 칸에 넣을 것 |
   |---|---|
   | `DART_API_KEY` | 전자공시 40자리 열쇠 |
   | `ECOS_API_KEY` | 한국은행 열쇠 |
   | `DATA_GO_KR_API_KEY` | 정부 데이터 열쇠 |
   | `BRANDFETCH_API_KEY` | 로고 열쇠 (했다면) |

   **🔵 나중 (발행·AI 단계):**

   | Name 칸에 넣을 것 (그대로) | Secret 칸에 넣을 것 |
   |---|---|
   | `IG_ACCESS_TOKEN` | 인스타 긴 열쇠 |
   | `IG_USER_ID` | 인스타 숫자 ID (있으면) |
   | `ANTHROPIC_API_KEY` | Claude 열쇠 |

8. 다 넣으면 화면 목록에 **넣은 이름들**이 줄줄이 보입니다 (값은 `***`처럼 가려짐 — 정상!)
9. 이제 **메모장은 지우세요.** (열쇠가 컴퓨터에 평문으로 남아있지 않게)

✅ **완료 확인**: 깃허브 Secrets 목록에 방금 넣은 이름들이 보이면 끝!

> 🔒 **가장 중요한 보안 규칙**: 열쇠의 **값**을 Claude 채팅·카카오톡·메일·문자에 **절대 붙여넣지 마세요.** 저에게 열쇠를 보여줄 필요가 전혀 없습니다 — 프로그램이 깃허브 금고에서 알아서 꺼내 쓰도록 만들어져 있으니까요. 혹시 실수로 어딘가에 붙여넣었다면, 그 사이트에서 열쇠를 삭제하고 새로 발급받으면 됩니다.

## 자주 막히는 곳 (FAQ)

- **Q. Meta 앱 만들기에서 화면 문구가 가이드와 달라요.** → Meta는 화면을 자주 바꿉니다. "Instagram 로그인으로 API 설정 → 액세스 토큰 생성"이라는 **목적**만 기억하고, 막히면 그 화면을 캡처해서 새 채팅에 물어보세요.
- **Q. 열쇠를 복사하다 잃어버렸어요.** → 대부분 그 사이트에서 **다시 발급/재생성**하면 됩니다. 인스타는 2단계, DART는 5단계, Claude는 7단계를 다시 하면 새 열쇠가 나옵니다.
- **Q. 깃허브 Settings가 안 보여요.** → 저장소 주인 계정으로 로그인했는지 확인하세요.
- **Q. 카드 등록이 부담돼요.** → **소액 결제가 필요한 건 Claude 열쇠(7단계) 하나뿐**입니다. 오늘 하는 🟢 묶음(DART·ECOS·공공데이터·Brandfetch)은 **전부 무료**예요.
- **Q. 오늘 뭐부터 하면 돼요?** → **5단계 DART 하나만** 해도 정확한 연봉 카드가 나옵니다. 여유되면 4단계(ECOS)·3단계(공공데이터)까지 하면 환율·부동산 카드도 열립니다.
