# 관제탑을 "실시간"으로 만들기 — 단계별 안내 (비개발자용)

## 먼저, "실시간"이 뭘 뜻하는지 나눠 보기

지금 관제탑은 **사진**에 가깝습니다. 제가 그때그때 찍어서 보내드리고, 오너가 눌러서 고른 결과를
**손으로 복사해 저에게 보내주셔야** 반영됩니다.

"실시간"이라는 한 단어 안에는 사실 **서로 다른 세 가지 소원**이 들어 있습니다.

| | 소원 | 지금은? |
|---|---|---|
| ① | **주소가 고정**이라 언제든 즐겨찾기로 연다 | ❌ 매번 새로 만들어 보내드림 |
| ② | **누르면 그 자리에서 저장**된다 (복사-붙여넣기 없이) | ❌ 요약 복사 → 저에게 전달 |
| ③ | **내용이 저절로 최신**이 된다 (새 소재·새 카드가 알아서 올라옴) | ❌ 제가 다시 만들어야 함 |

이 셋은 난이도가 다르고, **따로따로 해결할 수 있습니다.** 한 번에 다 하려 들면 커집니다.

---

## 비유 하나 — 학급 게시판

- **지금**: 선생님(저)이 종이에 표를 그려 나눠줌 → 학생(오너)이 연필로 체크 → 그 종이를 다시 선생님에게 제출
- **1단계**: 교실 벽에 게시판을 붙임 (**주소 고정**). 누구나 지나가다 본다
- **2단계**: 선생님이 매일 아침 게시판을 새로 갈아 붙임 (**자동 갱신**)
- **3단계**: 학생이 게시판에 **직접 스티커**를 붙일 수 있게 됨 (**직접 저장**)
- **4단계**: 스티커가 교무실 명부에도 **자동으로 옮겨 적힘** (**한 곳이 진짜 원본**)
- **5단계**: 게시판에 "새 주제 찾아주세요" 쪽지를 꽂으면 **선생님이 자동으로 호출**됨
- **6단계**: 아예 게시판 대신 **학급 홈페이지**를 만듦 (필요할 때만)

## 단계별 상세

### 1단계 — 고정 주소 만들기

**뭘 하나**: 지금은 제가 만들어 보내는 링크가 매번 달라질 수 있습니다.
`https://wirit-tower.pages.dev` 같은 **평생 안 바뀌는 주소**를 하나 만듭니다.

**왜 필요한가**: ②·③을 하려면 반드시 먼저 있어야 합니다.
claude.ai 아티팩트 페이지는 보안 때문에 **바깥과 통신이 전부 막혀 있어서**, 거기서는
아무리 잘 만들어도 "직접 저장"이 불가능합니다. Pages 주소에서는 됩니다.

**누가**: 오너. **시간**: 약 15분 · **비용**: 0원

> ⚠️ **두 가지 걸림돌이 있고, 둘 다 0원으로 풀립니다.**
> ① 비공개 저장소는 GitHub Pages가 유료 ② 배포본에 카드 썸네일이 빠짐
> → **Cloudflare Pages(무료) + 빌드 시 카드 재생성**으로 해결.
> **방법: [control-tower-hosting.md](./control-tower-hosting.md)** (이쪽을 따르세요)
> GitHub Pages를 쓰는 경우는 [control-tower-pages.md](./control-tower-pages.md)

---

### 2단계 — 내용이 저절로 최신이 되게 (자동 재생성)

**뭘 하나**: "매일 아침 7시에 관제탑을 다시 만들어서 게시판에 붙여라"를 컴퓨터에 예약해 둡니다.
(GitHub Actions라는 무료 자동 실행기가 합니다. 이미 다른 작업 12개가 이걸로 돌고 있습니다.)

**왜 필요한가**: 제가 새 카드를 만들거나 소재를 추가하면, 오너가 아무것도 안 해도
다음날 아침 관제탑에 **알아서 올라와 있습니다.**

**주의할 점**: 이건 "몇 초 단위 실시간"이 아니라 **"하루 한 번 최신"**입니다.
초 단위 실시간이 필요한 일이 아니라서, 이걸로 충분합니다. (원하면 1시간마다로 줄일 수 있습니다.)

**누가**: 제가 배선합니다(아이디어 보드를 관제탑 생성에 합치는 작업).
**시간**: 저 1세션 · **비용**: 0원

---

### 3단계 — 버튼이 진짜로 저장되게 (열쇠 만들기)

**뭘 하나**: 관제탑이 오너 대신 저장소에 글을 쓰려면 **열쇠(토큰)**가 있어야 합니다.
GitHub에서 "이 저장소만, 읽고 쓰기만" 되는 **제한된 열쇠**를 만들어 관제탑에 한 번 넣어 둡니다.

그러면 ✓승인을 누르는 순간 → 저장소의 결정 파일에 **바로 기록**됩니다. 복사-붙여넣기 끝.

**왜 필요한가**: 이게 "실시간"이라는 말의 **핵심 90%**입니다.

**안전한가**: 열쇠는 **오너 브라우저 안에만** 저장되고 GitHub 외 어디로도 나가지 않습니다.
권한도 이 저장소 하나로 묶여 있어서, 잃어버려도 GitHub에서 한 번 눌러 폐기하면 끝입니다.

**중요**: 이 기능은 **이미 만들어져 있습니다**(관제탑 라이브 모드).
지금은 소재 마이닝·로고 취득·자료 인박스에만 붙어 있고, **아이디어 보드에는 아직 안 붙어 있습니다.**
그 연결만 하면 됩니다.

**누가**: 오너가 열쇠 발급(5분) + 제가 아이디어 보드에 배선(1세션)
**시간**: 5분 + 1세션 · **비용**: 0원
**방법**: [control-tower-live.md](./control-tower-live.md)

---

### 4단계 — "진짜 원본"을 한 곳으로 (기기 간 동기화)

**뭘 하나**: 지금 오너의 결정은 **그 브라우저 안에만** 저장됩니다(localStorage).
그래서 PC에서 고른 걸 휴대폰에서 열면 안 보입니다.

3단계가 되면 결정이 저장소에 쌓이므로, 관제탑이 **열릴 때 저장소에서 읽어오게** 바꿉니다.
→ PC에서 고르고 휴대폰에서 열어도 **똑같이 보입니다.**

**왜 나중인가**: 3단계가 없으면 읽어올 원본 자체가 없습니다. 순서가 정해져 있습니다.

**누가**: 제가. **시간**: 1세션 · **비용**: 0원

---

### 5단계 — "신규 소재 발굴" 버튼이 진짜로 동작하게

**뭘 하나**: 지금 이 버튼은 **요청을 적어두는 것**까지만 합니다(페이지가 AI를 부를 수 없어서).
3단계의 열쇠가 있으면, 버튼이 저장소에 **"이슈"라는 쪽지**를 자동으로 붙일 수 있습니다.
그 쪽지가 붙으면 **저를 자동으로 호출**하도록 예약해 둘 수 있습니다.

→ 오너: 버튼 누름 → (몇 분 뒤) 관제탑에 새 소재가 올라와 있음. **대화창을 안 거칩니다.**

**주의**: 이 단계부터는 **AI 사용료**가 듭니다(호출할 때마다 과금).
그래서 "아무 때나 자동"보다 **버튼을 눌렀을 때만** 도는 구조를 권합니다.

**누가**: 제가. **시간**: 1~2세션 · **비용**: AI 호출당 소액(월 몇 천 원 수준부터)

---

### 6단계 — 진짜 웹 서비스로 (필요해질 때만)

**뭘 하나**: 서버와 데이터베이스를 두고, 로그인·여러 사람 동시 편집·즉시 반영까지 되는
본격 웹 앱(Next.js)으로 갑니다.

**언제 필요한가**: 아래 중 **하나라도** 해당될 때입니다.
- 오너 말고 **다른 사람들도** 관제탑을 쓴다
- 하루에 **수십 번** 결정한다 (하루 한두 번이면 3단계로 충분)
- 관제탑에서 누른 버튼이 **즉시 발행**까지 이어져야 한다

**지금은 필요 없습니다.** 혼자 쓰고, 하루 몇 번 쓰는 도구에 서버를 두면 **관리 부담만 늘어납니다.**

**비용**: 월 5~20달러 + 관리 수고

## 정리 — 어디까지 하면 될까

| 단계 | 오너가 할 일 | 제가 할 일 | 얻는 것 | 비용 |
|---|---|---|---|---|
| **1** 고정 주소 | Cloudflare 가입·설정 (15분) | 배포 워크플로 1세션 | 즐겨찾기로 언제든 열기 **+ 썸네일 복구** | 0원 |
| **2** 자동 갱신 | 없음 | 1세션 | 매일 아침 최신 상태 | 0원 |
| **3** 직접 저장 ⭐ | 열쇠 발급 (5분) | 1세션 | **복사-붙여넣기 사라짐** | 0원 |
| **4** 기기 동기화 | 없음 | 1세션 | PC·폰 어디서나 같은 화면 | 0원 |
| 5 자동 발굴 | 없음 | 1~2세션 | 버튼 → AI가 알아서 | AI 호출료 |
| 6 웹 서비스 | 결제 | 여러 세션 | 완전한 앱 | 월 $5~20 |

**추천: 1 → 2 → 3 → 4 까지.** 여기까지가 체감의 90%이고, **전부 0원**이며,
오너가 직접 하실 일은 **총 20분**(Cloudflare 설정 15분 + 열쇠 발급 5분)뿐입니다.
5·6단계는 실제로 답답함을 느끼신 다음에 결정해도 늦지 않습니다.

## 다음 행동 (제안)

1. 오너: **[control-tower-hosting.md](./control-tower-hosting.md)** 로 Cloudflare 설정 (15분)
2. 저: 배포 워크플로 작성(카드 재생성 → 썸네일 포함) + 아이디어 보드를 관제탑에 합치기
3. 오너: [control-tower-live.md](./control-tower-live.md)로 **열쇠 발급** (5분)
4. 저: 승인·수정·삭제·추가가 저장소에 바로 기록되도록 연결 + 기기 동기화

> 순서를 지키는 게 중요합니다. 1단계 없이 3단계를 하면, 아티팩트 페이지는 통신이 막혀 있어
> **아무리 만들어도 동작하지 않습니다.**
