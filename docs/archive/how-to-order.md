# 🏭 무한 제작 운영법 — 저를 어떻게 쓰면 되나

> 한 줄 요약: **저와의 대화 1회 = 영구 자산 1개.**
> 한 번 만든 카드 유형은 관제탑 버튼만으로 영원히 재생산됩니다.
> 그러니 저를 **"카드 만드는 데"가 아니라 "공장을 늘리는 데"** 쓰십시오.

---

## 1. 두 종류의 일을 구분하세요

| | 누가 | 얼마나 걸리나 |
|---|---|---|
| **새 카드 유형 만들기** | 저(작업 세션) | 세션당 3~5종 |
| **만든 유형 재생산** | **관제탑 버튼** | 5~8분, 무제한 |

지금 자산: **템플릿 15종 · 빌더 8개 · 실거래 432파일 · 소재 45건**
(정기 28건 — 데일리 2 · 주간 5 · 월간 10 · 분기 5 · 연간 6 / 일회성 16 / 분류 대기 1)

빌더 1개 = 매달 버튼 한 번으로 카드 1장. **빌더가 20개면 매달 20장을 제 개입 없이 찍습니다.**

---

## 1-2. 소재 보드는 '얼마나 자주 내는가'로 서 있습니다

2026-07-27부터 소재 보드의 칸이 **주제(부동산·증시…)가 아니라 발행 주기**입니다.
보드를 볼 때 답이 나와야 하는 질문이 "이건 무슨 분야지?"가 아니라
**"이건 언제 또 내야 하지?"**였기 때문입니다.

| 칸 | 뜻 |
|---|---|
| 🔁 정기 · 데일리 | 장 마감마다 |
| 🔁 정기 · 주간 | 요일 고정 연재 |
| 🔁 정기 · 월간 | 실거래가 매월 5일 갱신될 때 |
| 🔁 정기 · 분기 | 3개월은 지나야 순위가 바뀜 |
| 🔁 정기 · 연간 | 공시·확정이 1년에 한 번 |
| 🔥 일회성 · 시의성 | 사건 당일. 지나면 김빠짐 |
| 1️⃣ 일회성 | 한 번 내면 끝 |
| 🆕 분류 대기 | 아직 안 정함 — ✎ 눌러 주기를 골라주세요 |

소재마다 **자동 / 수동** 뱃지가 붙습니다.

- **자동** = 수집기가 이미 돌고 있음 → 보관함 [🔁 다시 제작] 한 번이면 이번 판이 나옵니다
- **수동** = 자료를 사람이 다시 넣어야 함 → 채팅으로 주문하셔야 합니다

새로 들어온 소재(자동 수집·지시함)는 전부 **🆕 분류 대기**로 갑니다.
정기인지 일회인지는 기계가 알 수 없는 오너의 판단이라, 화면에서 ✎로 정해주시면 그 칸으로 옮겨갑니다.

## 2. ⚠️ 재발행이 쉬우려면 — 데이터 소스가 갈림길입니다

**같은 카드를 매달 다시 뽑을 수 있느냐**는 데이터가 자동으로 갱신되느냐로 갈립니다.

### ✅ 자동 갱신되는 소스 (= 정기물로 만들 수 있음)

| 소스 | 갱신 주기 | 만들 수 있는 것 |
|---|---|---|
| 국토부 실거래 | **매월 5일 자동** | 부동산 랭킹·지도·신고가·평당가 |
| 국내 증시(야후) | **평일 자동** | 코스피·코스닥 카드 |
| 미국 증시·금리 | **평일 자동** | 해외 지수·환율·금리 |
| DART 평균연봉 | 수동(연 1회급) | 연봉 랭킹 |

이 소스로 만든 카드는 **[🔁 최신 데이터로 다시 제작] 한 번이면 이번 달 판**이 나옵니다.

### ⚠️ 1회성이 되는 경우

뉴스 기사에서 손으로 뽑은 수치로 만들면, 다시 제작해도 **같은 숫자만** 나옵니다.
갱신하려면 저를 다시 불러야 합니다.

**→ 그래서 주문하실 때 이렇게 말해 주세요:**

> "이거 **매달 낼 거야**" 또는 "이건 **이번 한 번만**"

매달 낼 거라면 제가 **데이터를 계속 가져올 방법까지 함께 만듭니다**(수집기 + 빌더 등록).
그러면 다음 달부터는 버튼입니다.

## 3. 주문하는 법 — 이 채팅에

그냥 편하게 던지시면 됩니다. **다 넣을수록 좋습니다:**

- 기사 링크 (여러 개 좋습니다)
- "이런 각도가 재밌을 것 같다" 같은 생각
- 참고할 다른 계정 캡처
- 원하는 카드 형태 ("지도로", "순위표로", "커버 한 장으로")

**좋은 주문 예:**

> 전세가율 지도 만들자. 서울 25개구 전세/매매 비율로.
> 매달 낼 거야. 데이터는 알아서 찾아줘.

> (기사 링크) 이 기사 숫자로 카드 하나. 이번 한 번만이면 돼.

**제가 알아서 하는 것**: 데이터 소스 확정 → 수치 추출 코드 → 템플릿 선택 → 렌더 → 캡션 → 검수 → 등록.
**오너가 결정할 것**: 소재를 낼지 말지, 최종 발행 승인.

## 4. 밀린 일은 하루 한 번에

관제탑 **오늘** 탭 →  **📋 밀린 일 한번에 넘기기**

대기 중인 요청·제작·캡션을 **지시문 하나로 묶어** 복사합니다.
채팅에 붙여넣으면 그날 밀린 게 한 번에 처리됩니다.
(건마다 [지시문 복사]를 누를 필요가 없습니다)

## 5. 매일 운영 루틴 (5분)

1. 관제탑 **오늘** 탭 열기
2. **결재 대기**가 있으면 → 카드·캡션 확인 → **[🚀 발행 승인]** (= 나가도 좋다)
3. **올릴 차례**가 있으면 → [JPG 내려받기] + [캡션 복사] → **인스타 앱에서 직접 업로드**
   → 돌아와서 **[✅ 인스타에 올렸습니다]**
4. **밀린 일**이 있으면 → [한번에 넘기기] → 채팅에 붙여넣기
5. 정기물 낼 때가 되면 → 보관함에서 [🔁 다시 제작]

끝입니다.

## 5-2. 📮 발행은 오너가, 기록은 관제탑이

**인스타 자동 업로드는 하지 않습니다** (2026-07-27 결정). 올리는 사람은 오너입니다.

그런데 그러면 **시스템은 무엇이 올라갔는지 알 방법이 없습니다.**
실제로 그래서 사고가 났습니다 — 오너는 올리고 계셨는데 관제탑은 "발행 0건"이라고 보고했습니다.
원인은 하나였습니다: **"내가 올렸다"를 적을 칸이 없었습니다.**

이제 그 칸이 [✅ 인스타에 올렸습니다] 버튼입니다. 누르면:

| | 무슨 일이 |
|---|---|
| ① | 발행 대기열이 **완료**로 체크되고 발행일이 남습니다 |
| ② | 그때 나간 **카드 JPG + 캡션 + 근거**가 `published/` 에 통째로 보관됩니다 |
| ③ | **성과 탭 → 발행 이력**에 뜹니다 |

### 왜 굳이 이미지를 따로 보관하나요?

카드 그림은 저장소에 없습니다(용량) — 매번 데이터에서 **다시 그립니다.**
그런데 실거래가 갱신되면 **지난달 카드의 숫자가 바뀝니다.**
그러면 "우리가 그때 뭘 발행했는지"를 영영 확인할 수 없습니다.

그래서 **발행된 것만은 그날 픽셀 그대로 굳혀 둡니다.** 이게 완성본 저장소입니다.

**⚠️ 그 버튼을 안 누르면 발행 사실이 어디에도 남지 않습니다.** 올리신 뒤 꼭 눌러주세요.
