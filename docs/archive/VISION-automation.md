# 접어 둔 비전 — AI 자동 파이프라인 (요약 보존)

> 이 문서는 **지금 운영하는 방식이 아니다.** 2026년 7월 초에 그린 "AI 여러 팀이 매일 자동으로
> 소재를 뽑고 → 카드를 만들고 → 검수하고 → 자동 발행하는" 청사진을, 언젠가 다시 볼 수 있게
> 한 장으로 요약해 남긴 것이다. 현재 실제 운영은 루트 `README.md`와 `docs/HANDOFF.md`에 있다.

## 원래 꿈꾼 그림

리서치 → 기획 → 편집(데이터 변환) → 디자인 → 품질검수 → 발행까지 사람 개입을 게이트로만 두고,
9개 AI 팀이 닫힌 루프로 돌며 매일 콘텐츠를 찍어내는 시스템. 오너는 감독·승인만.

- **자동 수집**: 부동산원·국토부·DART·한국은행·증시를 GitHub Actions가 정기 수집 → 이 부분은 **실제로 구현되어 살아있다**(`docs/DATA_REFRESH.md`).
- **자동 제작·검수**: 수집된 데이터로 카드를 자동 재생산하고 코드 검수(designQa)를 통과 → **정기물은 부분 구현**(auto-produce 배관).
- **자동 발행**: 승인 게이트(폰 알림) 뒤 Instagram Graph API로 자동 업로드 → **폐지**.
- **런타임 에이전트**: 각 팀이 상주 봇으로 동작(`prompts/*.md` 초안) → **도착한 적 없음.** 지금 '팀'은 세션이 참고하는 기준 문서 묶음이다.

## 왜 접었나

- **자동 발행은 2026-07-27 오너 결정으로 폐지**했다. 인스타 업로드는 오너가 직접 한다(오보·톤 리스크를 사람이 최종 확인).
- **상주 에이전트 런타임**은 비용·복잡도 대비 실익이 없었다. 코워크 세션이 저장소를 열고 기준을 상속받아 손으로 만드는 방식이 더 정확하고 결정적이었다.
- 그 결과 "팀"은 봇이 아니라 **판단 원칙(`company/CEO.md`) + 작업 창구(`docs/CARD_CHECKLIST.md`) + 자동 검수(`designQa` 코드)**의 3층 문서 체계로 남았다.

## 지금도 살아있는 조각 (이 비전에서 건진 것)

- **결정적 렌더**(같은 입력=같은 픽셀)와 **provenance**(수치는 원자료에서 코드가 추출) — 오보 0의 뼈대.
- **계약 우선**: 카드는 JSON 계약(필드·픽셀)으로 정의(`docs/TEMPLATES.md`).
- **정기물 자동 수집·재생산 배관**(`docs/DATA_REFRESH.md`).
- **빌드타임 vs 런타임 구분**, **저장소가 유일한 진실 원천**(커밋되지 않은 산출물은 존재하지 않는다).

## 다시 추진한다면

발행 자동화가 아니라 **제작 자동화 심화**가 다음 지렛대다: 정기물 auto-produce를 넓히고,
소재 발굴을 관제탑 보드로 더 자동화하되, **발행 앞단(사람 확인)은 유지**하는 방향.
상세 설계 사료는 같은 폴더의 `ROADMAP.md`·`EXECUTION_PLAN.md`·`CONTROL_TOWER.md`에 있다.
