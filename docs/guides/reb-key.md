# 🔑 전세·월세 지수 자동 수집 켜기 — 부동산원 열쇠 받기 (오너용, 약 5분)

> 이 열쇠 하나면 **전세가격지수·월세가격지수가 매달 자동으로** 저장소에 들어옵니다.
> 그러면 관련 카드는 버튼 한 번으로 매달 새 판이 나옵니다.

---

## 왜 이 열쇠인가

전세가격지수·월세가격지수를 **만드는 기관이 한국부동산원 자신**입니다.
뉴스 기사나 다른 시세 사이트는 2차 가공물이라 기준시점·표본이 다르면 숫자가 어긋납니다.
우리는 **오보 0**이 원칙이라 만든 곳에서 직접 받아옵니다.

---

## 1단계 — R-ONE 가입 (2분)

1. https://www.reb.or.kr/r-one 접속
2. 우측 상단 **회원가입** → 개인 회원으로 가입 (이메일 인증)
3. 로그인

## 2단계 — 열쇠(인증키) 신청 (2분)

1. 상단 메뉴에서 **OpenAPI** (또는 **오픈API**) 클릭
2. **인증키 신청** / **활용신청** 버튼
3. 신청서에 이렇게 적으시면 됩니다:
   - 활용 목적: `주택 가격지수 데이터 시각화 콘텐츠 제작`
   - 활용 형태: `웹사이트 / 콘텐츠`
4. 신청 → **인증키가 화면에 바로 나옵니다** (승인 대기 없이 즉시 발급됩니다)
5. 인증키를 **복사**해 두세요

## 3단계 — GitHub에 등록 (1분)

1. 저장소 페이지 → 상단 **Settings**
2. 왼쪽 메뉴 **Secrets and variables** → **Actions**
3. **New repository secret** 버튼
4. **Name** 칸: `REB_API_KEY` (정확히 이대로)
5. **Secret** 칸: 복사한 인증키 붙여넣기
6. **Add secret**

✅ 끝입니다. 이제 매달 16일에 자동으로 최신 지수가 들어옵니다.

---

## 바로 확인해 보기

저장소 → **Actions** 탭 → 왼쪽에서 **전세·월세 지수 수집 (한국부동산원)**
→ **Run workflow** → `mode`를 `collect` 로 두고 실행

2~3분 뒤 `data/datasets/reb-rent-index.json` 이 생기면 성공입니다.

### 잘 안 되면

| 화면에 뜨는 말 | 뜻 | 할 일 |
|---|---|---|
| `REB_API_KEY 시크릿이 없습니다` | 3단계가 안 됨 | 이름 철자 확인 (`REB_API_KEY`) |
| `JSON 아님 · <html…` | 열쇠가 아직 안 먹음 | 발급 직후면 5분 뒤 재실행 |
| `통계표를 못 찾았습니다` | 통계표 이름이 개편됨 | `mode`를 `discover`, `keyword`를 `전세`로 두고 실행 → 나온 목록을 저에게 그대로 붙여넣어 주세요 |

마지막 경우는 **제가 처리할 일**입니다. 목록만 주시면 맞는 표로 고정해 두겠습니다.

---

## 이 열쇠로 무엇이 열리나

부동산원 R-ONE에는 전세·월세 지수 말고도 **매매가격지수, 전세가율, 거래량, 미분양** 같은
통계가 같이 있습니다. 열쇠 하나로 전부 열리므로, 앞으로 이 계열 카드는
**추가 발급 없이** 만들 수 있습니다.
