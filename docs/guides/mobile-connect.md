# 📱 휴대폰에서 관제탑 연결하기

> 5분이면 끝납니다. 한 번 하면 그 폰에서는 다시 안 해도 됩니다.

## 왜 폰에서 또 해야 하나요?

관제탑은 **GitHub 토큰**(저장소에 기록할 권한을 담은 긴 문자열)으로 움직입니다.
이 토큰은 보안을 위해 **그 기기의 그 브라우저에만** 저장됩니다 — 서버에 보관하지 않습니다.

그래서 PC에서 연결해도 폰은 "연결 필요"로 뜹니다. **기기마다 한 번씩** 붙여넣어야 합니다.
(같은 토큰을 여러 기기에 써도 됩니다. PC에서 만든 토큰을 어딘가 안전하게 적어뒀다면 그걸 그대로 붙여넣으면 3초면 끝납니다.)

---

## 방법 1 — PC 토큰을 그대로 쓰기 (가장 빠름)

PC에서 토큰을 만들 때 복사해 둔 문자열(`github_pat_...`)이 있다면:

1. 폰에서 관제탑 접속 → 우상단 **[연결 필요]** 누르기
2. 칸에 그 문자열 붙여넣기 → **[연결하기]**

끝입니다. **토큰을 안 적어뒀다면** GitHub이 다시 보여주지 않으므로 아래 방법 2로 새로 만드세요.

> ⚠️ 토큰을 카카오톡·문자로 자신에게 보내는 건 편하지만, 대화 기록에 비밀번호가 남는 것과 같습니다.
> 옮긴 뒤에는 그 메시지를 지우세요. 가장 안전한 건 폰에서 새로 만드는 방법 2입니다.

---

## 방법 2 — 폰에서 새로 만들기

### 1단계. 토큰 만들기 화면 열기

관제탑 → 우상단 **[연결 필요]** → **[토큰 만들기 ↗]**
(또는 주소창에 직접: `github.com/settings/personal-access-tokens/new`)

GitHub 로그인을 요구하면 로그인하세요.

> 화면이 좁아 버튼을 찾기 어려우면, 브라우저 메뉴(⋮) → **데스크톱 사이트**를 켜세요. 훨씬 편합니다.

### 2단계. 이름과 기간

| 칸 | 넣을 값 |
|---|---|
| **Token name** | `wirit 관제탑` (아무 이름이나 됩니다) |
| **Expiration** | `90 days` 이상 (짧으면 만료돼서 또 만들어야 합니다) |

### 3단계. 어느 저장소에 쓸지

**Repository access** → **Only select repositories** 선택 → 목록에서 **`Changwon-Moon/claude`** 고르기

### 4단계. 권한 2개 켜기 ⭐ 여기가 제일 중요합니다

**Permissions** → **Repository permissions** 를 펼치고, 목록에서 두 개를 찾아 바꿉니다:

| 권한 | 설정 | 이게 없으면 |
|---|---|---|
| **Contents** | **Read and write** | 승인·삭제·수정지시가 저장되지 않습니다 |
| **Actions** | **Read and write** | **소재 발굴·카드 제작 버튼이 안 먹습니다** |

> 목록이 깁니다. 알파벳 순이라 **Actions**는 위쪽, **Contents**는 중간쯤에 있습니다.
> 나머지는 전부 `No access` 그대로 두세요 — 필요한 것만 주는 게 안전합니다.

### 5단계. 만들고 복사

맨 아래 **Generate token** → 화면에 `github_pat_...`로 시작하는 긴 문자열이 나옵니다.
**이 화면을 벗어나면 다시 볼 수 없습니다.** 바로 복사하세요(길게 눌러 전체 선택 → 복사).

### 6단계. 관제탑에 붙여넣기

관제탑 → **[연결 필요]** → 칸에 붙여넣기 → **[연결하기]**

**"연결 성공"**이 뜨면 완료입니다. 우상단이 **🟢 연결됨**으로 바뀝니다.

---

## 잘 됐는지 확인하는 법

관제탑이 연결할 때 **권한을 실제로 확인**합니다:

- **"연결 성공"** → 정상. 모든 버튼이 동작합니다.
- **"연결됐지만 Actions 권한이 없습니다"** → 4단계에서 Actions를 빠뜨린 것입니다.
  기록은 되지만 **소재 발굴·카드 제작 버튼이 안 먹습니다.**
  → GitHub에서 그 토큰을 열어 Actions를 `Read and write`로 바꾸면 됩니다(토큰을 새로 만들 필요 없음).
- **"이 저장소에 접근할 수 없습니다"** → 3단계에서 저장소를 안 골랐거나 다른 걸 골랐습니다.

## 자주 막히는 곳

**Q. 붙여넣기가 안 됩니다.**
토큰 칸을 길게 눌러 «붙여넣기»를 선택하세요. 복사가 안 된 상태라면 5단계를 다시 하세요(토큰은 재발급해야 합니다).

**Q. "연결 실패: GitHub 401"**
토큰이 잘못 붙여넣어졌습니다. 앞뒤 공백이나 잘린 글자가 없는지 확인하세요.

**Q. 폰을 바꾸거나 브라우저 기록을 지웠습니다.**
토큰이 지워진 것이라 다시 붙여넣어야 합니다. 토큰 자체는 살아 있으니 적어둔 걸 붙여넣으면 됩니다.

**Q. 토큰이 유출된 것 같습니다.**
GitHub → Settings → Developer settings → Personal access tokens에서 해당 토큰 **Delete**.
관제탑에서도 **[연결 해제]**를 누르세요. 그 뒤 새로 만들면 됩니다.

## 참고 — 무엇이 어디에 저장되나

| | 저장 위치 | 서버로 전송? |
|---|---|---|
| 토큰 | 그 기기 브라우저 안(localStorage) | **GitHub 외에는 전송 안 함** |
| 오너의 결정(승인·삭제·지시) | 저장소(GitHub) | — |
| 관제탑 비밀번호 | Cloudflare 시크릿 | — |

관제탑 서버(Cloudflare)는 토큰을 **보관하지도, 볼 수도 없습니다.** 브라우저가 GitHub에 직접 요청합니다.
