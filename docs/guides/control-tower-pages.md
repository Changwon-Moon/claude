# 관제탑을 인터넷 주소(GitHub Pages)로 상시 열기 — 초보자용 가이드

관제탑을 URL 하나로 만들어, PC·휴대폰 어디서든 즐겨찾기해 여는 방법입니다. **딱 한 번만** 설정하면 됩니다.

## 왜 필요한가
- 지금은 관제탑 파일(`index.html`)을 매번 받아서 열어야 합니다.
- Pages를 켜면 **고정 주소**가 생겨서, 저장소가 갱신될 때마다 관제탑도 자동으로 최신으로 바뀝니다.

## 설정 (1회, 약 1분)

1. GitHub에서 이 저장소(`Changwon-Moon/claude`) 페이지를 엽니다.
2. 상단 **Settings**(설정) 탭을 누릅니다.
3. 왼쪽 메뉴에서 **Pages**를 누릅니다.
4. **Build and deployment → Source** 에서 드롭다운을 **"GitHub Actions"** 로 바꿉니다.
5. 끝. 저장 버튼은 없습니다(선택하면 바로 적용).

## 게시 확인

- 위 설정 후, `관제탑 배포 (GitHub Pages)` 워크플로가 자동으로 돌거나, **Actions 탭 → 해당 워크플로 → Run workflow** 버튼으로 수동 실행할 수 있습니다.
- 초록불이 뜨면 **Settings → Pages** 상단에 `Your site is live at https://...` 주소가 나타납니다. 그 주소가 관제탑입니다.

## 알아둘 점

- **비공개(private) 저장소**는 GitHub Pro(유료)에서만 Pages가 됩니다. 무료 요금제라면 저장소를 public으로 바꾸거나, 지금처럼 **파일/아티팩트**로 여는 방식을 계속 쓰면 됩니다.
- Pages 버전은 **렌더 카드 썸네일이 빠질 수 있습니다**(원본 이미지가 저장소에 포함되지 않도록 설정돼 있어서). 소재보드·결정·회사(원칙·팀·프롬프트)·자산 정보는 모두 정상 표시됩니다. 썸네일까지 보려면 세션에서 만든 완전판(파일/아티팩트)을 쓰세요.
- 관제탑에서의 **편집(원칙·프롬프트 수정지시)**은 Pages/파일/아티팩트 모두 동일하게 "지시 전달함 → 요약 복사 → Claude" 흐름으로 동작합니다.
