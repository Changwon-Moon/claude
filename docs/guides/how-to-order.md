# 🏭 무한 제작 운영법 — 저를 어떻게 쓰면 되나

> 한 줄 요약: **저와의 대화 1회 = 영구 자산 1개.**
> 한 번 만든 카드 유형은 관제탑 버튼만으로 영원히 재생산됩니다.
> 그러니 저를 **"카드 만드는 데"가 아니라 "공장을 늘리는 데"** 쓰십시오.

---

## 1. 두 종류의 일을 구분하세요

| | 누가 | 얼마나 걸리나 |
|---|---|---|
| **새 카드 유형 만들기** | 저(작업 세션) | 세션당 3~5종 |
| **만든 유형 재생산** | **관제탑 버튼** | 5~8분, 무제한 |

지금 자산: **템플릿 15종 · 빌더 8개 · 실거래 432파일 · 소재 52건**

빌더 1개 = 매달 버튼 한 번으로 카드 1장. **빌더가 20개면 매달 20장을 제 개입 없이 찍습니다.**

---

## 2. ⚠️ 재발행이 쉬우려면 — 데이터 소스가 갈림길입니다

**같은 카드를 매달 다시 뽑을 수 있느냐**는 데이터가 자동으로 갱신되느냐로 갈립니다.

### ✅ 자동 갱신되는 소스 (= 정기물로 만들 수 있음)

| 소스 | 갱신 주기 | 만들 수 있는 것 |
|---|---|---|
| 국토부 실거래 | **매월 5일 자동** | 부동산 랭킹·지도·신고가·평당가 |
| 국내 증시(야후) | **평일 자동** | 코스피·코스닥 카드 |
| 미국 증시·금리 | **평일 자동** | 해외 지수·환율·금리 |
| DART 평균연봉 | 수동(연 1회급) | 연봉 랭킹 |

이 소스로 만든 카드는 **[🔁 최신 데이터로 다시 제작] 한 번이면 이번 달 판**이 나옵니다.

### ⚠️ 1회성이 되는 경우

뉴스 기사에서 손으로 뽑은 수치로 만들면, 다시 제작해도 **같은 숫자만** 나옵니다.
갱신하려면 저를 다시 불러야 합니다.

**→ 그래서 주문하실 때 이렇게 말해 주세요:**

> "이거 **매달 낼 거야**" 또는 "이건 **이번 한 번만**"

매달 낼 거라면 제가 **데이터를 계속 가져올 방법까지 함께 만듭니다**(수집기 + 빌더 등록).
그러면 다음 달부터는 버튼입니다.

---

## 3. 주문하는 법 — 이 채팅에

그냥 편하게 던지시면 됩니다. **다 넣을수록 좋습니다:**

- 기사 링크 (여러 개 좋습니다)
- "이런 각도가 재밌을 것 같다" 같은 생각
- 참고할 다른 계정 캡처
- 원하는 카드 형태 ("지도로", "순위표로", "커버 한 장으로")

**좋은 주문 예:**

> 전세가율 지도 만들자. 서울 25개구 전세/매매 비율로.
> 매달 낼 거야. 데이터는 알아서 찾아줘.

> (기사 링크) 이 기사 숫자로 카드 하나. 이번 한 번만이면 돼.

**제가 알아서 하는 것**: 데이터 소스 확정 → 수치 추출 코드 → 템플릿 선택 → 렌더 → 캡션 → 검수 → 등록.
**오너가 결정할 것**: 소재를 낼지 말지, 최종 발행 승인.

---

## 4. 밀린 일은 하루 한 번에

관제탑 **오늘** 탭 →  **📋 밀린 일 한번에 넘기기**

대기 중인 요청·제작·캡션을 **지시문 하나로 묶어** 복사합니다.
채팅에 붙여넣으면 그날 밀린 게 한 번에 처리됩니다.
(건마다 [지시문 복사]를 누를 필요가 없습니다)

---

## 5. 매일 운영 루틴 (5분)

1. 관제탑 **오늘** 탭 열기
2. **결재 대기**가 있으면 → 카드·캡션 확인 → [JPG 내려받기] → 인스타 업로드 → [발행 승인]
3. **밀린 일**이 있으면 → [한번에 넘기기] → 채팅에 붙여넣기
4. 정기물 낼 때가 되면 → 보관함에서 [🔁 다시 제작]

끝입니다.

---

## 6. 더 자동화하려면 (오너 결정 사항)

| 원하는 것 | 필요한 것 | 비용 |
|---|---|---|
| **새 카드도 무인 제작** | Anthropic 크레딧 | 카드당 약 $0.3~1 · 월 30건 = $10~30 |
| **인스타 자동 업로드** | IG 토큰 발급 | 무료 (코드는 완성돼 있음) |

둘 다 **결제·계정 인증이라 사람만 할 수 있습니다.** 하시면 그 다음은 제가 구현합니다.

---

## 7. 목표 그림

```
지금:   빌더 8개  →  버튼만으로 매달 8장
3세션:  빌더 20개 →  버튼만으로 매달 20장
크레딧: 새 카드도 무인 →  소재만 고르면 끝
```

**세션을 열 때마다 "새 유형 3~5개"를 시키십시오.** 그게 복리로 쌓입니다.
