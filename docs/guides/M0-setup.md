## 1단계. 인스타그램 프로페셔널 계정 전환 (5분)

1. 인스타그램 앱에서 @wirit_note 로그인 → 프로필 → 우상단 ≡ 메뉴 → **설정 및 활동**
2. **계정 유형 및 도구** (또는 "크리에이터/비즈니스 도구") → **프로페셔널 계정으로 전환**
3. 유형은 **비즈니스** 선택 (크리에이터도 API는 되지만, 발행 자동화 용도는 비즈니스 권장)
4. 카테고리는 "미디어" 또는 "디지털 크리에이터" 아무거나 (나중에 변경 가능)
5. 페이스북 페이지 연결을 물어보면 **건너뛰기** — 우리 방식(인스타그램 직접 로그인 API)은 페이지가 필요 없음

- [ ] 프로필에 "프로페셔널 대시보드"가 보이면 완료

## 2단계. Meta 개발자 앱 + 인스타 토큰 발급 (30분, 가장 중요)

**배경 설명**: 인스타에 프로그램으로 게시물을 올리려면 Meta "앱"이 하나 필요합니다. 우리는 남에게 서비스하는 게 아니라 **내 계정에만** 올리므로, 앱을 심사받거나 공개할 필요 없이 "개발 모드" 상태로 충분합니다.

1. [developers.facebook.com](https://developers.facebook.com) 접속 → 페이스북 계정으로 로그인 → 우상단 **시작하기**로 개발자 등록 (이메일 인증)
2. **내 앱 → 앱 만들기**:
   - 사용 사례(use case)를 물으면 **Instagram 관련** 항목 선택 (예: "Instagram API에 액세스" / "기타 → 비즈니스")
   - 앱 이름: `wirit-pipeline` (아무거나 가능), 연락처 이메일 입력 → 생성
3. 앱 대시보드 왼쪽 메뉴에서 **Instagram → API setup with Instagram login** (한국어 UI면 "Instagram 로그인으로 API 설정") 진입
4. **1. Generate access tokens** 섹션에서 **Add an Instagram account** 클릭
   - @wirit_note 계정으로 로그인 → 권한 **허용(Allow)**
5. 연결된 계정 옆의 **Generate Token** 클릭 → 나오는 긴 문자열이 **장기 액세스 토큰** (60일 유효)
   - [ ] 토큰을 복사해 임시로 안전한 곳(메모장 등 로컬)에 보관 → 6단계에서 GitHub Secrets에 넣고 임시본은 삭제
6. 같은 화면(또는 계정 상세)에 표시되는 **Instagram user ID** (숫자)도 복사
   - 안 보이면: 새 세션에 "토큰으로 IG_USER_ID 조회해줘"라고 요청하면 확인용 명령을 만들어 줌

**알아둘 것**:
- 토큰은 60일마다 만료되지만, **M5에서 자동 갱신 코드**를 넣을 예정이라 이후엔 신경 쓸 필요 없음. 그전에 만료되면 5번 과정으로 재발급하면 됨
- 앱은 "개발 모드"로 계속 둠 — 심사 신청 불필요

- [ ] `IG_ACCESS_TOKEN`, `IG_USER_ID` 확보 완료

## 3단계. 공공데이터포털 인증키 (15분 + 승인 대기)

부동산 실거래가 등 정부 데이터의 원천입니다.

1. [data.go.kr](https://www.data.go.kr) 회원가입 → 로그인
2. 마이페이지에 표시되는 **일반 인증키(Encoding)** 가 기본 키 — 복사
3. 검색창에 **"아파트 매매 실거래가"** 검색 → "국토교통부_아파트 매매 실거래가 상세 자료" (오픈API) → **활용신청**
   - 활용 목적: "데이터 분석 및 콘텐츠 제작" 정도로 작성, 기간은 최대
   - 대부분 **자동 승인**(즉시~수 시간)
4. 같은 방식으로 **"아파트 전월세 실거래가"** 도 활용신청 (부동산 시리즈용)

- [ ] `DATA_GO_KR_API_KEY` 확보 + 실거래가 API 2종 활용신청 승인

## 4단계. 한국은행 ECOS 인증키 (10분)

기준금리·환율·경제지표의 원천입니다.

1. [ecos.bok.or.kr/api](https://ecos.bok.or.kr/api) 접속 → 회원가입/로그인
2. **인증키 신청** 메뉴 → 사용 목적 간단히 작성 → 신청 (보통 즉시~1일 내 발급)
3. 발급된 인증키 복사

- [ ] `ECOS_API_KEY` 확보

## 5단계. Anthropic API 키 (10분)

리서치·기획·편집 에이전트의 두뇌입니다.

1. [console.anthropic.com](https://console.anthropic.com) 가입 → 로그인
2. **Billing**에서 카드 등록 + **$10 충전** (초기엔 충분. 자동 충전은 끄고 시작 권장)
3. **API Keys → Create Key** → 이름 `wirit-pipeline` → 생성된 키 복사 (**한 번만 보여주므로 즉시 복사**)
4. (권장) Billing에서 **월 사용 한도(Spend limit)** 를 $50로 설정 — 비용 폭주 안전장치

- [ ] `ANTHROPIC_API_KEY` 확보

## 6단계. GitHub Secrets에 키 저장 (10분)

키를 코드나 채팅에 넣지 않고, GitHub이 제공하는 금고에 넣습니다. 파이프라인(GitHub Actions)만 이 금고를 읽을 수 있습니다.

1. github.com에서 이 저장소 열기 → **Settings** 탭 → 왼쪽 **Secrets and variables → Actions**
2. **New repository secret** 클릭 → 아래 표의 이름과 값을 하나씩 등록 (총 5개):

| Name (철자 그대로) | Secret (값) |
|---|---|
| `IG_ACCESS_TOKEN` | 2단계의 장기 토큰 |
| `IG_USER_ID` | 2단계의 숫자 ID |
| `DATA_GO_KR_API_KEY` | 3단계 인증키 |
| `ECOS_API_KEY` | 4단계 인증키 |
| `ANTHROPIC_API_KEY` | 5단계 키 |

3. 등록 후 로컬 메모장 등에 임시 보관한 키 원본은 **삭제**

- [ ] Secrets 5개 등록 완료 (목록에 이름 5개가 보이면 됨 — 값은 다시 볼 수 없는 게 정상)

**보안 원칙**: 키 값을 Claude 채팅·카톡·메일에 절대 붙여넣지 마세요. 세션이 키가 필요한 작업(발행 테스트 등)을 할 때는 GitHub Actions를 통해 실행하도록 만들어져 있습니다.
