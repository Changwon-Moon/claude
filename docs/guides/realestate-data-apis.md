# 부동산 데이터 연동 가이드 (운영자용)

> 목표: 국토부 실거래가 기반 콘텐츠를 **자동 제작**하기 위한 키 발급·연동 안내.
> 결론 요약: **필수는 공공데이터포털 키 1개**뿐. 아실·네이버부동산은 연동하지 않는다(아래 이유).

## 1. 필수 — 국토부 실거래가 API (무료, 10분)

**뭘 주나**: 전국 아파트 매매/전월세 **실거래** 원본(법정동·단지명·전용면적·거래금액·층·계약일). 우리 "오보 0" 원칙의 1차 출처.

**발급 절차** (이미 DART 때 해본 것과 동일 패턴):
1. [공공데이터포털](https://www.data.go.kr) 로그인 (기존 계정 사용)
2. 검색: **"아파트 매매 실거래가 상세 자료"** (국토교통부) → [활용신청] → 자동승인
3. 같은 방법으로 **"아파트 전월세 실거래가 자료"**도 [활용신청] (키는 공용 1개)
4. 마이페이지 → 일반 인증키(Encoding) 복사
5. GitHub 저장소 → Settings → Secrets and variables → Actions → **`MOLIT_API_KEY`** 로 등록

**한도**: 기본 일 1,000회 — 서울 25개구 월 단위 수집엔 충분. 과거 5년치 일괄 수집은 며칠에 나눠 실행(수집기가 캐시하므로 1회만 하면 됨).

## 2. 선택 (Phase 3) — 카카오 로컬 API (좌표, 무료)

역세권·지도형 콘텐츠(역별 대장, 15억 배치 지도)에 **단지·역 좌표**가 필요할 때.
1. [developers.kakao.com](https://developers.kakao.com) → 앱 만들기 → REST API 키 복사
2. GitHub Secrets → **`KAKAO_REST_KEY`**
- 용도: 단지 주소→좌표 변환(지오코딩) **1회 배치**만. 이후 저장소에 캐시.
- 지하철역 좌표는 서울 열린데이터광장·국가철도공단 공공데이터로 무료 확보(키 불요).

## 3. 연동하지 않는 것 — 아실·호갱노노·네이버페이부동산

- **공식 공개 API가 없다.** 자동 수집(크롤링)은 각 서비스 약관 위반 소지 + 차단 리스크 + 데이터 출처를 "아실"로 표기해야 하는 문제(2차 출처).
- 결정적으로 **불필요**: 이들 서비스의 원천도 국토부 실거래가다. 우리는 원천(1차)을 직접 쓰므로 더 정확하고 출처 표기도 깨끗함.
- 용도 한정: 제작 후 **눈 검증(교차확인) 보조 화면**으로만 사용.

## 4. 이 키로 자동화되는 것 (요약)

- 수집기: 구·월 단위 실거래 수집 → `data/datasets/molit/` 캐시 (Actions cron)
- **대장 선정 엔진(코드)**: 지역(구/동/역 반경)별 ①절대가 대장 ②국평(84㎡) 대장 자동 산출 + provenance
- 카드 자동 생성: 대장 도감·주간 신고가·예산 지도·상승률 등 (research/IDEAS.md '실거래 자동화 뱅크' 참조)

## 5. 비용
전부 **무료**. (공공데이터포털·카카오 로컬 기본 쿼터 내)

### A-1. 상세 발급 절차 (07-21 추가 — 5종)

#### 🟢 ① 학교알리미 공시정보 — 사실 새 가입 불필요
- **좋은 소식**: 별도 사이트(schoolinfo.go.kr) 가입이 필요 없습니다. **공공데이터포털에 이미 올라와 있습니다.**
- 절차: data.go.kr 로그인(기존 계정) → 검색창에 **"한국교육학술정보원 학교알리미 공시정보"** → [활용신청] → 자동승인 → 마이페이지에서 **기존에 쓰던 인증키 그대로 사용 가능**(활용신청만 추가하면 됨, 새 키 발급 불필요)
- 참고: schoolinfo.go.kr 사이트 자체는 네이버/카카오 계정으로도 로그인되지만, **자동화(코드로 수집)에는 공공데이터포털 경로를 씁니다.**

#### 🟢 ② 지하철역 좌표 — API도 필요 없이 파일 다운로드로 끝
- 이것도 별도 키 불필요. data.go.kr에서 **"서울교통공사 1~8호선 역사 좌표(위경도) 정보"** 검색 → 파일데이터 다운로드(엑셀/CSV, 276개 역 좌표 소수점 6자리)
- 1회 다운로드해서 저장소에 캐시해두면 끝 — 매번 API 호출할 필요가 없는 정적 데이터입니다.
- (선택) 실시간 열차 위치 등 동적 데이터가 필요해지면 그때 서울열린데이터광장(data.seoul.go.kr) 인증키를 별도 신청 — 지금 단계에선 불필요.

#### 🔵 ③ 지방행정 인허가 데이터 (학원·병원·카페 등) — 별도 사이트 가입 필요
1. **localdata.go.kr** 접속 → 회원가입(공공데이터포털과 별개 사이트·별도 계정)
2. 상단 메뉴 **개발자센터 → API신청** → 원하는 업종 그룹(학원·의료기관·휴게음식점 등) 선택해 신청
3. 신청 시 **기관/단체명**과 **인증키 조회용 번호**를 직접 입력해야 함(발급 후 이 정보로 키를 재조회하므로 **꼭 기록해두세요** — 분실 시 재신청해야 함)
4. 승인 후 **개발자센터 → 인허가API KEY조회**에서 키 확인
5. GitHub Secrets → `LOCALDATA_API_KEY`로 등록

#### 🔵 ④ R-ONE 부동산통계정보시스템 — 별도 사이트 가입 필요
1. **reb.or.kr/r-one** (한국부동산원 부동산통계정보시스템) 접속 → 회원가입/로그인 (공공데이터포털과 별개)
2. 상단 **Open API → 인증키 신청** 메뉴에서 키 발급
3. ⚠️ 인증키를 URL에 넣지 않으면 자동으로 `sample` 처리되어 **10건만 출력**되니, 반드시 키를 파라미터에 포함해야 정상 작동
4. 개발가이드 페이지(Open API → 개발가이드)에서 원하는 통계표(전국 주택가격동향·공동주택 실거래가격지수·미분양 현황 등) 목록·요청 URL 형식 확인
5. GitHub Secrets → `RONE_API_KEY`로 등록
- 참고: data.go.kr에도 "한국부동산원_부동산통계 조회 서비스"가 있어 보이나, 상세 통계표 커버리지는 R-ONE 본가가 더 넓습니다. 필요한 통계가 실제 있는지는 신청 전 개발가이드에서 확인 권장.

#### 🔵 ⑤ 카카오맵(카카오 로컬) — 개발자 계정 필요
1. **developers.kakao.com** 접속 → 카카오계정으로 로그인(있으면 그대로 사용)
2. 우측 상단 **[내 애플리케이션] → [애플리케이션 추가하기]**
3. 앱 이름은 자유롭게(예: "wirit-geocoding"), 회사명은 개인이면 본인 이름/닉네임 입력해도 무방
4. 생성된 앱 클릭 → **앱 키** 탭에서 **REST API 키** 복사 (JavaScript 키가 아니라 **REST API 키**를 써야 서버/스크립트에서 호출 가능)
5. (참고) **플랫폼 등록은 지오코딩 REST API 호출엔 보통 불필요** — 웹/앱에 지도를 직접 띄우는 JS SDK를 쓸 때만 도메인 등록이 필요합니다. 우리는 "주소→좌표 변환"만 서버에서 1회성으로 돌릴 것이므로 앱 생성 + REST API 키만 있으면 충분
6. GitHub Secrets → `KAKAO_REST_KEY`로 등록
- 무료 한도: 지오코딩(주소→좌표 변환) 일 10만 건 — 서울 25개구·역세권 단지 좌표를 한 번 변환해 캐시해두는 우리 용도로는 충분하고도 남음

### E. 단지 "사진" — 솔직한 안내 ⚠️
특정 단지 실사진을 합법·자동으로 가져올 공식 API는 **없다**:
- 네이버/카카오 로드뷰·항공뷰 캡처 재배포 = 약관 위반
- 대안: ① **Pexels 등 감성 사진**(아파트 스카이라인 — "특정 단지 아님" 명시, 기존 photo-fetch 파이프라인) ② **위키미디어 공용**의 유명 단지 사진(일부 존재, CC — 저작자 표기) ③ **공공누리(kogl.or.kr) 1유형** 서울시 경관·항공사진 ④ 지도/일러스트 대체(자체 SVG)
- 도감 시리즈 표준: 실사진 없이도 성립하는 **데이터 중심 디자인** 유지(현재 No.01 방식)
