# 부동산 데이터 연동 가이드 (운영자용)

> 목표: 국토부 실거래가 기반 콘텐츠를 **자동 제작**하기 위한 키 발급·연동 안내.
> 결론 요약: **필수는 공공데이터포털 키 1개**뿐. 아실·네이버부동산은 연동하지 않는다(아래 이유).

## 1. 필수 — 국토부 실거래가 API (무료, 10분)

**뭘 주나**: 전국 아파트 매매/전월세 **실거래** 원본(법정동·단지명·전용면적·거래금액·층·계약일). 우리 "오보 0" 원칙의 1차 출처.

**발급 절차** (이미 DART 때 해본 것과 동일 패턴):
1. [공공데이터포털](https://www.data.go.kr) 로그인 (기존 계정 사용)
2. 검색: **"아파트 매매 실거래가 상세 자료"** (국토교통부) → [활용신청] → 자동승인
3. 같은 방법으로 **"아파트 전월세 실거래가 자료"**도 [활용신청] (키는 공용 1개)
4. 마이페이지 → 일반 인증키(Encoding) 복사
5. GitHub 저장소 → Settings → Secrets and variables → Actions → **`MOLIT_API_KEY`** 로 등록

**한도**: 기본 일 1,000회 — 서울 25개구 월 단위 수집엔 충분. 과거 5년치 일괄 수집은 며칠에 나눠 실행(수집기가 캐시하므로 1회만 하면 됨).

## 2. 선택 (Phase 3) — 카카오 로컬 API (좌표, 무료)

역세권·지도형 콘텐츠(역별 대장, 15억 배치 지도)에 **단지·역 좌표**가 필요할 때.
1. [developers.kakao.com](https://developers.kakao.com) → 로그인 → **내 애플리케이션**
   - 앱이 이미 있으면(예: 알림용으로 만든 것) **그걸 그대로 씁니다.** 앱 하나에 REST API 키는 하나입니다
   - 없으면 **애플리케이션 추가하기** → 앱 이름 `wirit` / 회사명 `wirit`
2. 만든 앱 클릭 → 좌측 **앱 키** → **REST API 키** 복사 (32자 안팎의 영숫자)
3. GitHub → 저장소 → **Settings** → **Secrets and variables** → **Actions**
   - ⚠️ **반드시 `Actions` 탭입니다.** 바로 옆 `Dependabot` 탭은 화면이 거의 똑같은데
     **Actions 워크플로에서는 읽히지 않습니다.** 2026-07-31 에 이 키가 이름만 있고
     값이 0자로 들어와 지오코딩이 통째로 건너뛰어졌습니다 — 이 함정이 유력한 원인이었습니다
4. **New repository secret** → Name `KAKAO_REST_KEY` / Secret 에 붙여넣기 → **Add secret**
   - 이미 같은 이름이 있으면 연필(수정)로 **값을 다시 넣습니다**. 값은 화면에 안 보이므로
     "등록돼 있다"만으로는 값이 들어 있는지 알 수 없습니다

**확인하는 법**: 값이 제대로 들어갔는지는 `scripts/geocode-sites.mjs` 가 알려줍니다.
Actions 로그(또는 커밋되는 `data/geocode-last.md`)에 `🔑 카카오 키 확인 (N자)` 가 찍히면 성공,
`KAKAO_REST_KEY(0자)` 가 보이면 값이 비어 있는 것입니다. **값은 절대 로그에 찍지 않습니다.**
- 용도: 단지 주소→좌표 변환(지오코딩) **1회 배치**만. 이후 저장소에 캐시.
- 지하철역 좌표는 서울 열린데이터광장·국가철도공단 공공데이터로 무료 확보(키 불요).

## 3. 연동하지 않는 것 — 아실·호갱노노·네이버페이부동산

- **공식 공개 API가 없다.** 자동 수집(크롤링)은 각 서비스 약관 위반 소지 + 차단 리스크 + 데이터 출처를 "아실"로 표기해야 하는 문제(2차 출처).
- 결정적으로 **불필요**: 이들 서비스의 원천도 국토부 실거래가다. 우리는 원천(1차)을 직접 쓰므로 더 정확하고 출처 표기도 깨끗함.
- 용도 한정: 제작 후 **눈 검증(교차확인) 보조 화면**으로만 사용.

## 4. 이 키로 자동화되는 것 (요약)

- 수집기: 구·월 단위 실거래 수집 → `data/datasets/molit/` 캐시 (Actions cron)
- **대장 선정 엔진(코드)**: 지역(구/동/역 반경)별 ①절대가 대장 ②국평(84㎡) 대장 자동 산출 + provenance
- 카드 자동 생성: 대장 도감·주간 신고가·예산 지도·상승률 등 (research/IDEAS.md '실거래 자동화 뱅크' 참조)

## 5. 비용
전부 **무료**. (공공데이터포털·카카오 로컬 기본 쿼터 내)

### E. 단지 "사진" — 솔직한 안내 ⚠️
특정 단지 실사진을 합법·자동으로 가져올 공식 API는 **없다**:
- 네이버/카카오 로드뷰·항공뷰 캡처 재배포 = 약관 위반
- 대안: ① **Pexels 등 감성 사진**(아파트 스카이라인 — "특정 단지 아님" 명시, 기존 photo-fetch 파이프라인) ② **위키미디어 공용**의 유명 단지 사진(일부 존재, CC — 저작자 표기) ③ **공공누리(kogl.or.kr) 1유형** 서울시 경관·항공사진 ④ 지도/일러스트 대체(자체 SVG)
- 도감 시리즈 표준: 실사진 없이도 성립하는 **데이터 중심 디자인** 유지(현재 No.01 방식)
