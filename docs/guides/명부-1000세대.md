## 읽을 때 알아둘 것

- **단지명은 공동주택 관리 대장의 이름**이라 실거래 신고 표기와 조금 다를 수 있다
  (예: `신당남산타운(분양)` / `신당남산타운임대`). 판정할 때는 괄호·공백을 지우고 맞추되,
  **애매하면 붙이지 않는다** — 잘못 붙이면 1,000세대 미만 단지가 알림에 섞인다.
- **임대 단지가 분양 단지와 따로 잡히는 경우가 있다.** 둘 다 1,000세대를 넘으면 둘 다 오른다.
- 문턱을 바꾸려면 `data/apt-universe-queue.txt` 에 `min=1500` 한 줄을 밀어 넣는다 —
  **세대수는 이미 전수 조사돼 있어 다시 수집하지 않는다.**
