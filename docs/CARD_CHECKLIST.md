# ✅ 카드 제작 체크리스트 — 만들기 전·내보내기 전에 반드시 훑는다

> **이 문서가 있는 이유** (2026-07-30 오너 지적)
> 「미쳐버린 서울 월세 폭등」·「1년 만에 월세 38만원」 두 카드를 만들면서 오너가 **이미 정해둔 기준을
> 다시 말하게 된 항목이 열 개가 넘었다.** 원인은 기준이 없어서가 아니다 — 기준이 긴 학습 로그
> 안에 흩어져 있어서 작업 전에 아무도 훑지 않았기 때문이다.
>
> 그래서 이 문서는 **짧고, 순서가 있고, 자동/수동이 구분된 단일 창구**다.
> CEO.md·BRAND.md·TEMPLATES.md 는 *왜*를 설명하는 원천이고, 이 문서는 *무엇을 확인하는가*다.
>
> **규칙**: 카드 작업을 시작할 때 이 문서를 읽고, 내보내기 전에 §0 을 실행한다.
> 오너가 같은 지적을 또 하면 → 그 항목을 여기에 올리고, 가능하면 **검수 코드로 승격**한다.

## §2. 사람이 봐야 하는 것 — 두 번 말하게 한 항목 (재발 금지)

### 제목
- [ ] **폭에 맞춰 크게, 좌우 여백 최소.** `fitTitle`(singoga-map) / `__wiritFit`(year-bars) 을 켠다. 고정 폰트 크기로 두지 않는다
- [ ] 제목 좌우 끝 = **본문(표)과 동일**. 카드 끝 풀블리드 지양
- [ ] 우상단 로고 뱃지와 **"붙어 보이지도 않게"** — 겹치지 않는 것만으론 부족, 세로 30px 이상
- [ ] 강조는 한 군데만. 이 계정에서 **레드 = 오름**이라 상승 카드 제목 강조에 써도 뜻이 어긋나지 않는다

### 표
- [ ] **열을 늘리기 전에 값의 길이를 잰다.** `--val-w` 176px · `--sub-w` 188px 이다.
      "7조 6,946억" 같은 값은 176px 를 넘겨 **옆 칸을 덮는다**. 4열이 안 들어가면
      3열로 줄이고 나머지는 캡션으로 내린다 — 카드는 한 가지만 또렷하게 말한다 (2026-07-31)
- [ ] **보조 열(`sub`)은 짧은 수치 전용이다.** "현재 227만원"·"24.8%" 는 되고
      지명("압구정3구역 외 3곳")은 안 된다. 지명은 길이를 예측할 수 없다
- [ ] 머리글 열 = 데이터 열과 **같은 grid**. `auto` 열은 **고정 폭으로 못박는다** (auto 는 머리글은 라벨 폭, 행은 값 폭으로 각자 계산해 어긋난다 → `colalign`)
- [ ] 머리글 정렬은 **데이터에 맞춘다** — 순위 가운데 / 이름 왼쪽 / 값 오른쪽
- [ ] 행 수는 눈대중이 아니라 **실측으로 한계를 찾는다**. 보조값이 붙어 2줄이 되면 들어가는 줄 수가 달라진다(16행 넘침 → 11행 통과)
- [ ] 행이 10개 이하로 적으면 `spread` 로 간격을 펴서 본문 높이를 채운다(정보를 늘리지 않고 간격만)

### 여백
- [ ] 하단 주석과 **푸터 사이에 숨을 준다**(≥14px, `footergap`)
- [ ] 빈 사분면이 크면 강조 카드·워터마크로 채운다 — 단 **데이터 위에는 아무것도 얹지 않는다**

### 숫자 표기
- [ ] **한 카드 안에서 소수 자릿수를 통일**한다. 카드가 `103.9` 인데 그래프 라벨이 `103.90` 이면 독자가 의심한다
- [ ] 단위는 한 번만. 축·부제에 있으면 라벨에서 뺀다(라벨이 칸보다 넓어져 옆 칸과 겹친다)
- [ ] 금액 단위 환산은 **데이터가 확정한 값만** 쓴다. `meta.unit` 이 기대와 다르면 빌더가 던지게 한다(천원→만원 ÷100 오용으로 송파 월세가 23만원이 된 사고)

### 지도 (토허제)
- [ ] **머리글(`head.l`/`head.r`)을 반드시 명시한다.** 안 주면 `singoga-map` 기본값 "신고가 건수 · 비율"이 그대로 나간다 — 정비사업 건수를 '신고가 건수'라 부르면 그 자체가 오보다 (2026-07-31)
- [ ] **2줄 라벨(이름+숫자)은 무게중심에 중앙정렬한다.** 그냥 두면 아래로 뻗어 서초처럼 남북으로 긴 구에서 숫자가 경계 밖으로 나간다
- [ ] 새로 그리지 않는다 — `scripts/lib/tohuh-map.mjs` + `data/datasets/tohuh-2026.json` 을 불러온다
- [ ] 표기는 데이터에서: `label`(표) / `mapLabel`(지도) / `rebCode`(R-ONE). 이름으로 지역을 집지 않는다
- [ ] 새 카드는 `placement:"nearest"` — **소속(자기 도형 안)이 겹침 회피보다 앞선다.** 라벨이 남의 구에 있으면 숫자가 통째로 오독된다. 라벨보다 좁은 구는 "살짝 겹치고 제자리"가 정답
- [ ] 기본값 `"down"` 은 **발행된 신고가 카드가 굳어 있는 배치**다 — 절대 건드리지 않는다

### 디자인 톤 — "AI티" 금지 (07-30 오너)
- [ ] 큰 라운드(20px+) + 옅은 회색 채움 + 사선 무늬 조합 = **어느 서비스에나 있는 UI 카드**로 읽힌다. 각을 세우고(≤4px) 채움을 걷어내 **종이 바탕 + 괘선**으로 간다
- [ ] 박스를 두 개 이상 쓰면 **차이가 정보를 담게** 한다. 실선 = 실측 / 점선 = 추정. 장식으로 다르게 만들지 않는다
- [ ] 강조는 **크기보다 색과 굵기**로. 한 박스 안 글자는 같은 크기가 기본(예외를 두면 그 예외가 무슨 뜻인지 말할 수 있어야 한다)
- [ ] 여러 박스를 나란히 두면 **숫자 크기를 서로 맞춘다**(각자 줄이면 어긋난다 → 공통 크기를 한 번 계산해 함께 적용)

### 추정치 — 원자료에 없는 숫자
- [ ] **네 곳에서 실측과 갈라 놓는다**: ①점선+사선 막대 ②'추정' 꼬리표 ③실측/추정 경계 세로선 ④캡션에 산술 가정. 하나만 빠져도 추정치가 사실로 읽힌다
- [ ] 카드에 산정 근거를 못 넣으면 **캡션에 반드시 넣는다**
- [ ] 점선·사선을 실선·단색으로 바꾸지 않는다 — 그 순간 추정이 실측이 된다

### 문구 — 계산으로 확인되지 않은 말은 쓰지 않는다
- [ ] "역사상 최고" · "전체" · "N년 연속" 같은 말은 **코드가 확인했을 때만** 나가게 한다(`isPeakNow`, `upAll`, 연속 구간 계산). 손으로 적으면 다음 달 데이터에서 거짓이 된다
- [ ] 제목이 데이터와 모순되면 **문구가 아니라 제목을 고친다**(과천 −1만원이 표에 보이는데 제목이 '전체 폭등'이면 같은 카드가 자기 모순)
- [ ] **오너 메모의 수치와 계산값이 다르면 계산값을 쓰고, 차이를 보고한다**(9.6% 요청 → 계산값 9.2%)

## §3. 자동/수동을 코드로 가르는 기준

눈대중으로 "이 칸"이라고 박아두지 않는다. **조건을 실측해서 코드가 고르게** 한다 — 데이터가 바뀌어도 맞는다.

| 실제 사례 | 나쁜 방법 | 쓴 방법 |
|---|---|---|
| `+1.7` 을 막대 안 흰 글씨로 | "2021번 칸" 고정 | 막대 위 라벨 자리가 **곡선보다 위**로 올라가면 안으로(`valueInside`) |
| 지도 라벨 자리 | 겹치면 아래로만 밀기 | 거리 + 도형 밖 벌점 + **겹침 면적**(연속값) 최소 자리 |
| 표 행 수 | "10행쯤" | 검수를 돌려 한계를 찾고 그 이유를 주석에 적기 |
| 기준 시점 글자 크기 | 고정 28px | **제목 실측값의 절반**(제목이 커지면 따라간다) |
| 카드 값 폰트 | 고정 70px | 카드 폭을 실측해 **줄이는 방향으로만** 자동 축소 |

## §4. 기술 함정 (한 번씩 다 밟았다)

- **Handlebars 숫자 인덱스는 `{{a.b.[0]}}` 브래킷.** `{{a.b.0}}` 은 파싱 오류("Expecting 'ID', got 'NUMBER'")
- **`{{#if}}` 는 컨텍스트 프레임을 만들지 않는다** — 안쪽에서 부모 참조는 `../` 한 단계
- **한국어 줄바꿈은 `word-break: keep-all`** — 기본값이면 어절 중간에서 끊긴다("역사상 최 / 고")
- **정사각 카드의 줄 수는 빌더가 고정**한다. 자동 줄바꿈에 맡기면 폰트·데이터가 바뀔 때 한 줄 늘어 정사각형을 넘친다
- **SVG `preserveAspectRatio="none"` 은 글자를 늘린다.** 또 `inset:0` 만 주면 viewBox 비율로 높이를 잡아 컨테이너를 넘친다 → `width/height:100%` 명시
- **사선 무늬만 깔면 뒤 레이어가 비쳐 뒤엉킨다** → `var(--wirit-paper)` 바탕을 함께
- **`process.exit(0)` 은 스크립트 맨 마지막.** 중간에 두면 뒤에 붙인 단계가 조용히 안 돈다
- **CSS 는 상한일 뿐이다.** 데이터가 한 자리 늘면(+12.4%) 테두리 밖으로 삐져나간다 → 실측 후처리(`__wiritFit`)로 막는다

## §5. 발행본은 픽셀이 변하지 않는다

카드는 매번 데이터에서 다시 그려지므로, **공용 템플릿을 건드리면 이미 발행한 카드가 조용히 바뀐다.**

- 새 스타일은 **variant 로 격리**한다 — 카드가 요청할 때만 켜지는 클래스/필드
  (`.sm-c` · `.sm-h3`(head.c) · `data-fit="1"`(fitTitle) · `placement:"nearest"` · `stamp2`)
- 공용 파일을 고쳤으면 **발행본 md5 를 다시 확인**한다

| 카드 | 상태 | 기준 md5 |
|---|---|---|
| `tohuh-rank` — 2026년 6월 신고가 지역 | **발행** (2026-07-26) | `572b4238dd87968e8f604f3f6caff68d` |
| `tohuh-rent-map` — 1년 만에 월세 38만원 | **오너 확정** (2026-07-30) | `ec4cad52505fcdbba9bb1bf76e33c9b6` |
| `wolse-flip-p1` — 미쳐버린 서울 월세 폭등 상황 | **오너 확정** (2026-07-30) | `87ef2d006936e7629d593c747e466843` |
| `jeongbi-board` — 올해 서울 정비사업 수주 1위는? | **오너 확정** (2026-07-31) | `57783108f6f9a7a7d824179f2fe853cd` |

확인은 손으로 하지 않는다 — **진단기가 빌더부터 돌려 전부 대조한다**:

```bash
node scripts/doctor.mjs        # 빌더 → 렌더 → md5 대조 → 자동 검수
```

⚠️ 위 표는 **사람이 읽는 사본**이고, 기계가 읽는 원천은 `data/review/pixel-baselines.json` 하나다.
새 카드를 확정하면 **그 파일에 추가**하고 이 표도 같이 고친다(두 곳에 적으면 반드시 어긋난다).

오너가 **확정**이라고 한 카드도 발행본과 같다 — 확정 이후엔 그 카드 픽셀을 바꾸지 않는다.

## §6. 세션을 닫기 전에

- [ ] `STATUS.md` 갱신 — 무엇을 왜 그렇게 했는지(다음 세션이 같은 실수를 하지 않게)
- [ ] 오너 피드백을 **원천에 반영**: 판단·취향 → `company/CEO.md` / 팀 일하는 방식 → `company/teams/*.md` 학습 로그 / **반복된 지적 → 이 문서 §2 + 가능하면 검수 코드**
- [ ] 커밋·푸시 (커밋 안 한 작업은 세션과 함께 사라진다)
- [ ] 오너에게 **눈으로 볼 수 있는 형태**로 결과 전달(렌더 PNG)

- [ ] **로고를 대타로 쓸 때 브랜드 로고를 회사 자리에 넣지 않았는가** —
      '압구정 현대'(단지명 미정)에 힐스테이트 로고가 붙었던 사고(2026-07-31).
      대타는 **회사 로고만**, 회사 로고가 없으면 로고를 안 붙인다.
- [ ] **카드 안 글자가 접히거나 잘리지 않았는가** — '포스코이앤씨'가 두 줄로 접히고
      '억'이 잘렸다(2026-07-31). 칸 폭 = 카드폭 − 로고 − 여백 으로 먼저 계산한다.
- [ ] **근사 좌표를 카드가 밝히고 있는가** — 동 중심으로 찍은 점은 각주에 이름을 적는다.
