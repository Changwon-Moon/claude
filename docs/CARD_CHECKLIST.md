# ✅ 카드 제작 체크리스트 — 만들기 전·내보내기 전에 반드시 훑는다

> **이 문서가 있는 이유** (2026-07-30 오너 지적)
> 「미쳐버린 서울 월세 폭등」·「1년 만에 월세 38만원」 두 카드를 만들면서 오너가 **이미 정해둔 기준을
> 다시 말하게 된 항목이 열 개가 넘었다.** 원인은 기준이 없어서가 아니다 — 기준이 긴 학습 로그
> 안에 흩어져 있어서 작업 전에 아무도 훑지 않았기 때문이다.
>
> 그래서 이 문서는 **짧고, 순서가 있고, 자동/수동이 구분된 단일 창구**다.
> CEO.md·BRAND.md·TEMPLATES.md 는 *왜*를 설명하는 원천이고, 이 문서는 *무엇을 확인하는가*다.
> **정확한 값은 여기에 복사하지 않고 정본을 가리킨다**: 템플릿별 픽셀·필드는 `TEMPLATES.md`, 색·워터마크 투명도는 `BRAND.md`, 지하철 시리즈는 `LINE_CARDS.md`, designQa 검수 항목 목록은 코드(`designQa.ts`). 같은 값이 여러 문서에 얼어붙어 서로 다른 시점에 늙는 것을 막기 위해서다.
>
> **규칙**: 카드 작업을 시작할 때 이 문서를 읽고, 내보내기 전에 §0 을 실행한다.
> 오너가 같은 지적을 또 하면 → 그 항목을 여기에 올리고, 가능하면 **검수 코드로 승격**한다.
>
> 🔌 **새 데이터가 필요한 소재면 `docs/API_CONNECTIONS.md` 를 먼저 읽는다** (2026-08-12 오너 지시).
> "원자료가 없다"고 결론짓기 전에 그 문서 §4 의 순서를 끝까지 밟는다 — 없는 게 아니라
> **안 받아온 것**일 때가 많다. 그리고 **오너에게 API 키를 요구하지 않는다**: 키는 이미 Secrets 에
> 있고, 세션은 **대기열 파일에 한 줄 밀어** Actions 를 깨운다. `doctor` 의 "키 없음" 경고는
> *이 컨테이너에 없다*는 뜻이지 *배관이 없다*는 뜻이 아니다.
>
> 🏢 **청약·분양 소재는 이 문서 위에 전용 기준이 하나 더 있다** —
> **`docs/guides/청약분양-카드-기준.md`** (판형 `danji-cover@1`, 사실의 원천, 발행 게이트).
> 그 소재를 만지기 전에 **먼저** 읽는다.

## §0. 내보내기 전 검사 (예외 없음)

```bash
node scripts/rebuild-cards.mjs             # 전 카드 재생성 + 자동 디자인 검수
node scripts/build-tower-site.mjs          # 관제탑 화면 조립
node scripts/smoke-tower.mjs               # 관제탑 스모크
pnpm --filter @wirit/renderer audit-head   # 머리 규격 전수 표(뱃지·위 여백·흰 테두리)
node scripts/doctor.mjs                    # 발행본 픽셀 회귀 · 자가진단 (§5)
node scripts/apply-signature.mjs           # 캡션 고정 서명 — **반드시 맨 뒤**
node scripts/apply-signature.mjs --check   # 붙었는지 증명
```

> 세션을 **닫을 때**는 이걸 손으로 치지 않는다 — `node scripts/close-session.mjs` 가
> 관제탑 배포 순서까지 포함해 전부 밟는다. **§7 이 마감 절차의 정본이다.**

### ⚠️ 서명은 왜 맨 뒤인가 — 규칙이 두 번 바뀌었다

**"`apply-signature` 는 `rebuild-cards` 뒤"** 는 맞다. 몇몇 빌더가 재생성하면서 캡션을
통째로 다시 써 고정 서명을 날리기 때문이다(2026-08-16c 에 실제로 캡션 2건이 서명을 잃었다).

그런데 **재생성하는 것이 `rebuild-cards` 하나가 아니었다.** `doctor` 도 카드를 다시 만든다 —
진단이 말로 확인하지 않고 **실제로 찍어 보기** 때문이다. 그래서 재생성 직후에 서명을 붙여도
뒤에 오는 doctor 가 도로 날렸고, `tohuh-rent-map`·`wolse-flip` 두 캡션이 **매번** 서명을
잃은 채 남아 있었다(2026-08-16d 실측으로 확인).

→ **카드를 만드는 것들을 먼저 다 돌리고, 서명을 마지막에 붙이고, `--check` 로 증명한다.**
`confirm.mjs`·`close-session.mjs` 둘 다 이 순서로 고쳤다.

**오너가 "확정할게" 라고 하면 위 줄들을 따로 치지 않는다 — 확정 스크립트가 다 한다:**

```bash
node scripts/confirm.mjs estate-84 estate-59 metro-speed --note "메모"
```

재생산 → 검수(error 면 중단) → 확정 기록 → **고정물만** 픽셀 기준값 등록(§5) →
위 검사 7종 → 커밋. 푸시 명령만 마지막에 찍어 준다(토큰이 필요해 스크립트가 쥐지 않는다).
순서가 늘 같고 판단이 없는 일은 사람이 외울 일이 아니다.

`error` 가 하나라도 있으면 **내보내지 않는다.** `warn` 은 이유를 대고 넘길 수 있다.

### ⚠️ 검수가 "통과"라고 말해도 **무엇을 검수했는지** 본다 (2026-08-16 실제 사고)

`rebuild-cards`·`produce-card` 는 `data/content/<날짜>/` 를 검수·렌더한다.
그런데 빌더가 **`--publish` 없이** 돌면 결과는 `data/out/_spike` 로 간다
→ **옛 발행본을 검수하고 "통과"라고 말한다.** 그 상태로 판이 칸을 7px 넘긴 카드가
초록으로 나갔고 확정 직전까지 갔다.

- `builders.json` 의 args 에 **`--publish` 를 넣는다**(대부분의 빌더는 원래 `data/content` 에 쓴다).
- 지금은 `produce-card` 가 두 파일의 mtime 을 비교해 어긋나면 **멈춘다** — 조용히 고쳐 주지 않는다.
- 눈으로 확인할 때도 `data/content/<날짜>/` 의 옛 PNG 를 보고 "안 바뀌었다"고 판단하지 말 것.

## §0.5. 시안 선검수 — 오너에게 보여주기 **전에** 3팀이 먼저 본다 (08-04 오너)

> 검수를 **확정 순간이 아니라 시안이 나온 순간으로 앞당긴다.** 오너가 "레이아웃은 알아서
> 검수하고 맞춰야지"·"기획·검수·디자인팀 돌려서" 를 반복해 말한 뒤 굳힌 기본값이다.
> **시안을 처음 제시할 때부터 항상** 아래를 세션이 스스로 돌리고, 잡힌 것을 고친 뒤,
> 무엇을 봤고 무엇을 고쳤는지 **한 줄 요약**을 시안과 함께 낸다. 오너가 "팀 돌려"라고
> 말하기 전에 이미 돌아가 있어야 한다.

**3팀 렌즈(시안마다 전부):**
- 🧭 **기획**: 소재 의도·후킹이 서는가 / '왜 이게 1등·핵심'이 설득되는가 / **오보 위험**(verified 여부·수치 상충·보도 vs 계산) / 캐러셀 vs 단일 판단.
- 🎨 **디자인**: 렌더 PNG를 **실제로 띄워** 본다(눈+좌표). 여백·정렬·넘침·대비·머리 규격·브랜드 자산 상속(로고/워터마크). 눈대중 금지 — 어긋나면 **픽셀로 재서** 고친다.
- 🔎 **검수(QA)**: 결정성(이중 렌더 md5 동일) / **발행본 픽셀 불변**(doctor) / 캡션 린트(있으면) / 루브릭 판정(pass·revise·block).

**한 방 명령(코드 검수, 키 불필요):**

```bash
pnpm --filter @wirit/pipeline review -- data/content/<날짜>/<slug>.json --label <slug> --out data/review
node scripts/doctor.mjs   # 발행본 픽셀 회귀까지
```

- `ANTHROPIC_API_KEY` 가 있으면 위 review 가 design·copy·adversarial·reference **LLM 렌즈**까지 자동 채점한다(없으면 세션이 그 렌즈를 직접 본다).
- 판정이 **block** 이면 오너에게 내기 전에 고친다. **revise** 는 고치거나, 못 고칠 이유를 시안 설명에 적는다.
- 이 선검수는 §0(내보내기 전)을 **대체하지 않는다** — 시안에서 한 번, 확정에서 §0 로 다시 한 번.

## §2. 사람이 봐야 하는 것 — 두 번 말하게 한 항목 (재발 금지)

### 제목

**정기물 제목에 '조건부 예외'를 두지 않는다 (2026-08-16b).**
「오늘의 신고가」 제목은 앞에 지역을 붙이되 *단지명이 이미 지역을 품으면 생략*하는 규칙이었다.
규칙 자체는 맞는 말인데, 결과가 **카드마다 제목 모양이 다른 것**이었다 — 매일 나가는 판형에서
그건 브랜드가 흔들리는 것과 같다. 오너가 지역을 통째로 뺐고 제목은 두 토막으로 고정됐다.
→ 정기물에서는 "이럴 땐 이렇게, 저럴 땐 저렇게"가 보이면 **둘 중 하나로 고정할 수 있는지** 먼저 묻는다.
- [ ] **폭에 맞춰 크게, 좌우 여백 최소.** `fitTitle`(singoga-map) / `__wiritFit`(year-bars) 을 켠다. 고정 폰트 크기로 두지 않는다
- [ ] 제목 좌우 끝 = **본문(표)과 동일**. 카드 끝 풀블리드 지양
- [ ] 우상단 로고 뱃지와 **"붙어 보이지도 않게"** — 겹치지 않는 것만으론 부족, 세로 30px 이상
- [ ] 강조는 한 군데만. 이 계정에서 **레드 = 오름**이라 상승 카드 제목 강조에 써도 뜻이 어긋나지 않는다

### 표
- [ ] **열을 늘리기 전에 값의 길이를 잰다.** `--val-w` 176px · `--sub-w` 188px 이다.
      "7조 6,946억" 같은 값은 176px 를 넘겨 **옆 칸을 덮는다**. 4열이 안 들어가면
      3열로 줄이고 나머지는 캡션으로 내린다 — 카드는 한 가지만 또렷하게 말한다 (2026-07-31)
- [ ] **보조 열(`sub`)은 짧은 수치 전용이다.** "현재 227만원"·"24.8%" 는 되고
      지명("압구정3구역 외 3곳")은 안 된다. 지명은 길이를 예측할 수 없다
- [ ] 머리글 열 = 데이터 열과 **같은 grid**. `auto` 열은 **고정 폭으로 못박는다** (auto 는 머리글은 라벨 폭, 행은 값 폭으로 각자 계산해 어긋난다 → `colalign`)
- [ ] **값 열이 왼쪽정렬인데 '가운데처럼' 보이면 다른 열의 `auto` 를 의심한다.** grid 에 `auto`(내용폭) 열이 하나 있으면 행마다 그 폭이 달라 **남은 `fr` 열의 좌측선이 매 행 이동**한다(왼쪽정렬해도 줄이 안 맞음). 세로선을 공유해야 하는 표는 **가변 열을 두지 말고** 값 열을 고정폭·`fr` 로 박는다 (08-05 오너 "그 열 왼쪽정렬로 줄 맞춰" 2회)
- [ ] 머리글 정렬은 **데이터에 맞춘다** — 순위 가운데 / 이름 왼쪽 / 값 오른쪽
- [ ] 행 수는 눈대중이 아니라 **실측으로 한계를 찾는다**. 보조값이 붙어 2줄이 되면 들어가는 줄 수가 달라진다(16행 넘침 → 11행 통과)
- [ ] 행이 10개 이하로 적으면 `spread` 로 간격을 펴서 본문 높이를 채운다(정보를 늘리지 않고 간격만)
- [ ] **네 열이 폭 전체에 고르게 퍼졌는가** — 좁은 열들을 왼쪽에 몰아 두고 오른쪽 숫자 열까지
      한 칸만 크게 비우면 "왼쪽으로 치우쳤다"고 읽힌다(07-31 오너 지적).
      좌우 여백·열 간격을 함께 키워 퍼뜨린다. 단, **가장 긴 값이 안 잘리는 선**까지만 —
      잘리면 `clipped` 가 error 로 막는다(칸을 넓히거나 글자를 줄인다).

### 자산 — 받기 전에 **먼저 찾는다** (08-12 오너)
- [ ] 사진·로고가 필요하면 **`node scripts/assets-find.mjs <낱말>` 부터**. 취득은 Actions 왕복이라 한 장에 3~4분이다 — 있는 걸 또 받지 않는다
- [ ] 새로 받았으면 파생본까지 등록: `node scripts/assets-sync-photos.mjs` (원본 메타를 물려받는다)
- [ ] **인물 사진은 규격화본(`-face.png`)을 쓴다** — `python3 scripts/normalize-portraits.py <slug>`.
      화각이 다른 초상을 그대로 나란히 두면 얼굴 크기가 두 배까지 벌어진다(08-12 오너 "사진 사이즈 균일하게")
- [ ] 얼굴 아래 개월 수 같은 **부가 라벨은 독자가 읽는 뜻으로 맞춘다** — 데이터 구간을 적어 놓고 재임기간처럼 보이게 두지 않는다(08-12 기획팀)

### 새 판형을 만들 때 — 남의 자를 빌려 쓰지 않는다 (08-12)
- [ ] **SVG 안 좌표계와 HTML 격자의 자를 하나로 맞춘다.** SVG 에 좌우 여백을 주고 아래 HTML 격자는

      (`templates/_shared/metro-lines.json`)를 본다. 두 곳에 적으면 반드시 어긋난다.

### 지도 — 사업지 점 지도

- [ ] **사업지가 20곳을 넘는데 라벨을 다 붙이려 하지 않았는가** — 지도에는 번호만,
      이름은 표·카드가 말한다. 다 붙이면 밀집 구역에서 지시선이 지도를 가로지른다.
- [ ] **지도를 마커에 딱 붙여 자르지 않았는가** — 마커 bbox + 넉넉한 여백(≥50px)으로 자른다.
      꽉 차지만 서울 모양이 안 보이는 지도는 점 그림이다.
- [ ] **좌표를 지어내지 않았는가** — 지오코딩 결과가 **그 구 도형 안에 있는지 실측**하고,
      못 찾으면 비워 둔다. 틀린 좌표는 없는 좌표보다 나쁘다.
- [ ] **근사 좌표를 카드나 캡션이 밝히고 있는가** — 동 중심으로 찍은 점은 이름을 적는다.
- [ ] **워터마크 자리를 손으로 찍지 않았는가** — 마커 상자를 피해 빈 곳을 재서 고른다.

### 레이아웃 — 넘침과 빈자리

- [ ] **제목이 카드 폭을 채우는가** — 이 판형의 제목 맞춤은 줄이기만 하지 않고 **키우기도** 한다.
- [ ] **제목과 그림이 한 행을 나눠 쓰면 폭은 제로섬이다** — 한쪽을 키우면 반드시 다른 쪽이 준다.
      둘 다 키우려면 **폭을 먹는 군더더기**를 줄인다(07-31: 평형 뱃지를 줄여 제목의 '가장 긴 줄'
      자리를 내주게 하니 글자가 5% 커졌고, 칸 사이 간격을 줄여 지도에 8px 를 돌려줬다).
      세로 여백을 늘려도 **폭에 묶인 요소는 커지지 않는다** — 늘어난 건 빈 공간뿐이다.
- [ ] **위로 올릴 수 있는 한계는 우상단 뱃지 아래끝**이다(카드 위 패딩 72 + 34 ≈ 106).
      그보다 올리면 그림 오른쪽 위가 뱃지와 부딪힌다.
- [ ] **지도가 제 칸을 넘지 못하게 묶여 있는가** — `height:auto` 로 두면 지도가 커지다
      제목을 덮는다(07-31 실제 발생). `width/height:100%` + viewBox 로 넘침을 구조적으로 막는다.
- [ ] **칸 안 글자가 접히거나 잘리지 않는가** — 칸 폭 = 카드폭 − 로고 − 여백 을 **먼저 계산**한다.
      '포스코이앤씨'가 두 줄로 접히고 '억'이 잘렸다.
- [ ] **빈자리가 한쪽에 몰려 있지 않은가** — 목록 길이가 칸마다 다르면 위아래로 쌓지 말고
      **좌우로 나눈다**(왼쪽 로고 / 오른쪽 목록). 서로의 높이를 채운다.

### 세트 등록 — 캡션이 없으면 검사도 없다 (07-31)

- [ ] **세트를 `sets.json` 에 올렸으면 캡션도 함께 올렸는가** — `smoke-tower` 의
      「세트 ↔ 빌더 정합」 검사는 **캡션이 있는 세트만** 본다(`if (!hasCap) continue`).
      캡션을 비워두면 그 세트는 빌더가 없어도 조용히 통과한다.
      실제로 `metro-speed` 세트가 `caption: ""` 인 채 남아 있었고,
      `scripts/build-metro-speed-card.mjs` 는 **`builders.json` 에 등록조차 안 돼 있었다.**
      갓 clone 한 환경에서 `rebuild-cards` 를 돌리면 지하철 카드만 **아예 생성되지 않는데**
      스모크는 계속 통과했다 — 검사받지 않은 것이 통과한 것으로 보인 전형이다.
      → 캡션이 아직 없으면 세트를 올리지 말고, 올렸으면 빌더 등록을 **눈으로** 확인한다.
- [ ] **커버를 뺀 세트로 바꿀 때 커버 빌더는 지우지 않는다** — `sets.json` 의 `cards` 에서
      커버 슬러그만 빼고 `builders.json` 의 커버 빌더는 남긴다. 오너가 되돌리자고 하면
      그 자리에서 다시 붙일 수 있어야 한다(07-31 커버 없이 재업로드 결정).

## §3. 자동/수동을 코드로 가르는 기준

눈대중으로 "이 칸"이라고 박아두지 않는다. **조건을 실측해서 코드가 고르게** 한다 — 데이터가 바뀌어도 맞는다.

| 실제 사례 | 나쁜 방법 | 쓴 방법 |
|---|---|---|
| `+1.7` 을 막대 안 흰 글씨로 | "2021번 칸" 고정 | 막대 위 라벨 자리가 **곡선보다 위**로 올라가면 안으로(`valueInside`) |
| 지도 라벨 자리 | 겹치면 아래로만 밀기 | 거리 + 도형 밖 벌점 + **겹침 면적**(연속값) 최소 자리 |
| 표 행 수 | "10행쯤" | 검수를 돌려 한계를 찾고 그 이유를 주석에 적기 |
| 기준 시점 글자 크기 | 고정 28px | **제목 실측값의 절반**(제목이 커지면 따라간다) |
| 카드 값 폰트 | 고정 70px | 카드 폭을 실측해 **줄이는 방향으로만** 자동 축소 |
| 무순위 카드 판형 | "이번엔 타입·분양가 판" 플래그 | `price.byType` **유무**가 판을 가른다(2026-08-06) |
| 조감도 크롭 자리 | 눈으로 보고 좌표 조정 | 창문 격자 대비로 단지 **무게중심**을 재고, 세로는 `shift = 남는 세로 × 42.5%` 를 뒤집어 푼다 |
| 빌더 인자 | `argv[2]` = 날짜 (위치) | 날짜 **모양**(`/^\d{4}-\d{2}-\d{2}$/`)인 인자만 날짜로 — `--only` 를 앞에 쓰자 제목에 `(..only)` 가 찍혔다 |
| 밴드에서 뺄 면적대 | "펜트하우스는 뺀다"고 손으로 지정 | **총 공급 대비 비중**(`RARE_SHARE` 0.5%) 미만인 면적대만, 그것도 밴드가 한 줄에 안 들어갈 때만(2026-08-14) |
| 밴드 라벨의 타입 | `types[0]` | **최고가를 낸 타입**(`price.byTypeAll`) — 금액이 최고가면 라벨도 그 타입이어야 한다. `byArea` 와 어긋나면 던진다 |
| 밴드 칸 수 한계 | "6칸까지" (눈대중) | **재서 정한다** — 5칸에서 이미 푸터가 47px 밀린다(실측). 한계는 4칸 |
| 코드가 만든 줄을 되찾기 | `flags.filter(f => f.includes("펜트하우스"))` | **인자를 가른다**(`noticeOf(d, flags, carried)`). 문자열 매칭은 계약이 아니다 — 문구 한 낱말만 바꿔도 줄이 조용히 증발했다 |

      명부 → 문턱(2020년 이후 최고가) → **서브면적별 최고가** → 판정 → 알림 이력을 한 화면에.
- [ ] 파일을 손으로 뒤지지 않는다. 손으로 뒤지면 **어느 날은 "우리가 틀렸네요"라고 답하게 된다.**
- [ ] 기준을 바꾸자는 결론으로 바로 가지 않는다. 묶기는 **문턱이 높아지는 쪽**이라
      틀려도 '못 잡는' 쪽으로 틀린다 — **놓친 소재는 손실이지만 잘못 나간 신고가는 사고다.**

## §4. 기술 함정 (한 번씩 다 밟았다)

- **Handlebars 숫자 인덱스는 `{{a.b.[0]}}` 브래킷.** `{{a.b.0}}` 은 파싱 오류("Expecting 'ID', got 'NUMBER'")
- **`{{#if}}` 는 컨텍스트 프레임을 만들지 않는다** — 안쪽에서 부모 참조는 `../` 한 단계
- **한국어 줄바꿈은 `word-break: keep-all`** — 기본값이면 어절 중간에서 끊긴다("역사상 최 / 고")
- **단지명·건설사명 줄바꿈은 반드시 단어 단위** — `-webkit-line-clamp` 로 두 줄을 낼 때도 음절 중간에서
  끊으면 안 된다("호반베르디움트 / 라엘", "자연앤힐스테이 / 트" 는 실격). `word-break: keep-all` 로
  깔되, **띄어쓰기 없는 브랜드명**(예: 논현신동아파밀리에, 광교자이더클래스)은 keep-all 만으로는 못 끊어
  한 줄 넘치면 잘린다 → 빌더가 **동네·건설사·브랜드 경계에 ZWSP(`​`)를 삽입**해 그 지점에서만 끊는다
  (`build-sinbundang-loop.mjs` 의 `WRAP` 맵 참고: "논현신동아​파밀리에", "호반베르디움​트라엘"). 공백이
  있는 이름(래미안 리더스원, 롯데캐슬 골드타운)은 keep-all 이 공백에서 알아서 끊으니 ZWSP 불필요.
- **정사각 카드의 줄 수는 빌더가 고정**한다. 자동 줄바꿈에 맡기면 폰트·데이터가 바뀔 때 한 줄 늘어 정사각형을 넘친다
- **SVG `preserveAspectRatio="none"` 은 글자를 늘린다.** 또 `inset:0` 만 주면 viewBox 비율로 높이를 잡아 컨테이너를 넘친다 → `width/height:100%` 명시
- **사선 무늬만 깔면 뒤 레이어가 비쳐 뒤엉킨다** → `var(--wirit-paper)` 바탕을 함께
- **`process.exit(0)` 은 스크립트 맨 마지막.** 중간에 두면 뒤에 붙인 단계가 조용히 안 돈다
- **CSS 는 상한일 뿐이다.** 데이터가 한 자리 늘면(+12.4%) 테두리 밖으로 삐져나간다 → 실측 후처리(`__wiritFit`)로 막는다
- **템플릿 좌표는 CSS px 이다 — PNG 픽셀이 아니다.** 카드는 1080×1350 뷰포트에 `deviceScaleFactor: 2`
  로 캡처해 2160×2700 PNG 가 나온다(`screenshot.ts`). PNG 크기를 보고 `top: 1600px` 이라고 적으면
  카드 밖이라 `overflow:hidden` 에 잘려 **아무것도 안 보인다**(07-31 지하철 워터마크 2개 중 1개가 그렇게 사라졌다).
- **`designQa` 는 상자가 아니라 Range(글자)로 잰다 — 절대배치 자식이 부모 Range 를 부풀린다.**
  줄 안에 `position:absolute` 뱃지가 있으면 그 줄의 Range 가 뱃지까지 감싸 위아래로 커지고,
  **윗줄과 항상 겹친 것으로 나온다**(거짓 경보). 글자를 `<span class="tx">` 로 감싸 그 span 을
  검사 목록에 올리고, 뱃지는 **따로** 올린다. 그래야 진짜 겹침(뱃지 ↔ 윗줄 글자)만 잡힌다.
- **`.m2-wm span` 처럼 후손 전체를 잡는 셀렉터는 안쪽 `.dot` 까지 절대배치로 만든다** → `> span` 으로 좁힌다
- **`designQa.ts` 의 `MEASURE_JS` 안에는 역따옴표를 쓰지 않는다** — 블록 전체가 템플릿 리터럴이라
  주석 안의 역따옴표 하나가 파일을 통째로 깨뜨린다(07-31 실제로 깨뜨렸다).
- **특정 달을 말하는 카드는 그 달보다 뒤의 데이터를 읽으면 안 된다.** 빌더가 캐시 폴더를
  통째로 읽으면, 다음 달 데이터가 들어오는 순간 **이미 발행한 카드가 조용히 바뀐다.**
  2026-07-31 에 7월 실거래가 들어오자 「2026년 6월 신고가」 카드의 픽셀이 바뀌었고,
  그냥 바뀐 게 아니라 신고가 판정이 `날짜 >= 6월 1일` 이라 **7월 거래까지 6월 신고가로 세고
  있었다**(오보다). → 대상 월을 인자로 받는 빌더는 파일 목록을 `ym <= latest` 로 자른다.
  이 사고를 잡아낸 건 사람 눈이 아니라 **발행본 md5 회귀 검사**다 — §5 를 끄지 않는다.
- **배경 장식을 실제 `<div>` 로 넣으면 `:nth-child` 셈이 밀린다.** 07-31 에 순위표 워터마크를
  첫 자식으로 넣었더니 **짝수행 음영이 통째로 뒤집혔다**(눈으로는 "원래 저랬나?" 싶어 넘어가기 쉽다).
  → 장식은 `::before` 가상요소로. 가상요소는 nth-child 에 세지 않는다. 고친 뒤에는
  **이전 판본과 같은 x 좌표를 픽셀 샘플링해 밴딩이 동일한지 대조**한다.
- **`margin-top: auto` 는 남는 세로를 통째로 빨아들이는 장치다.** 이걸 지우면 푸터가 위로 떠서
  카드 아래에 흰 띠가 생기고(2026-08-06), 반대로 **한 곳에만 있으면** 남는 자리가 전부 아래로 몰려
  표가 제목에 달라붙는다. 여백을 나누고 싶으면 auto 를 **하나 더** 둔다 — 그러면 반씩 갈린다.
  ⚠️ 확정본이 같이 움직이지 않게 새 규칙은 **선택자로 가둔다**(`:has(.frow.four)` 같은 식).
- **`font-feature-settings:"tnum"` 이 걸린 곳에서 `style.font` 단축 속성을 쓰면 그 설정이 풀린다.**
  글자 폭을 재려고 만든 probe 에 폰트를 한 번에 넣으면 tnum 이 사라져 **다른 폭을 잰다.**
  폰트 속성은 하나씩 옮긴다(2026-08-03 광학 정렬).
- **감싼 DOM 을 자로 쓰던 코드는 조용히 거짓말을 시작한다.** 값을 shrink-to-fit 상자로 한 겹
  감쌌더니 `parentNode.clientWidth` 가 늘 내용 폭과 같아져 **넘침 보호가 통째로 꺼졌다**.
  폭을 잴 때는 `closest('.cell')` 처럼 **자리를 정하는 상자**를 잡는다.
- **`transform: rotate()` 를 건 요소는 `left: 20px` 이어도 잘린다** — 회전하면 모서리가 상자 밖으로
  돌아 나간다. 가운데에 두려면 `left/top: 50%` + `translate(-50%,-50%) rotate(...)`, 가장자리에
  두려면 여백을 넉넉히(40px 이상).

## §5. 발행본은 픽셀이 변하지 않는다

카드는 매번 데이터에서 다시 그려지므로, **공용 템플릿을 건드리면 이미 발행한 카드가 조용히 바뀐다.**

### ⚠️ 고정물 / 정기물 — 이 규칙이 적용되는 범위 (2026-07-31)

「픽셀 불변」은 **한 번 만들고 마는 카드**를 전제로 만든 규칙이다.
실거래·증시처럼 **정기 수집으로 매달 다시 그려지는 카드**를 `pixel-baselines.json` 에 넣으면
다음 수집일에 doctor 가 통째로 빨간불이 된다 — 데이터가 바뀌었으니 픽셀도 당연히 바뀐다.

| | 고정물 | 정기물 |
|---|---|---|
| 예 | 지하철 표정속도, 브랜드 순위 | 실거래 랭킹, 증시, 월세지수 |
| 약속 | **픽셀이 안 바뀐다** | **같은 데이터면 같은 픽셀**(결정성) |
| `pixel-baselines` | 등록 → md5 회귀 검사 | **등록하지 않는다** |
| 확정 기록 | 기준값이 곧 기록 | `sets.json` 에 `confirmedAt` + 그 판본 md5 |

판정은 손으로 하지 않는다 — `scripts/confirm.mjs` 가 **워크플로가 갱신하는 데이터셋 목록**을
`.github/workflows/*.yml` 에서 읽어 세트의 의존 경로와 대조해 자동으로 가른다.

> ⚠️ 워크플로에 `git add data/datasets/*.json` 같이 **폴더를 통째로 쓸어 담는** 표현이 있으면
> 손으로 만든 데이터셋까지 '정기물'로 오인한다 — 그런 표현은 목록에서 버린다(지하철이 그랬다).

- 새 스타일은 **variant 로 격리**한다 — 카드가 요청할 때만 켜지는 클래스/필드
  (`.sm-c` · `.sm-h3`(head.c) · `data-fit="1"`(fitTitle) · `placement:"nearest"` · `stamp2`)
- 공용 파일을 고쳤으면 **발행본 md5 를 다시 확인**한다

**표를 여기 두지 않는다.** 예전엔 사람이 읽는 사본 표를 여기 뒀는데, 확정할 때마다 두 곳을
고쳐야 해서 결국 어긋났다(2026-08-16 감사: 문서 6장 vs 실제 9장). **기계가 읽는 원천 하나만** 둔다:

```bash
node scripts/doctor.mjs        # 빌더 → 렌더 → md5 대조 → 자동 검수
cat data/review/pixel-baselines.json | node -e '
  const d=JSON.parse(require("fs").readFileSync(0,"utf8"));
  d.cards.forEach(c=>console.log(c.md5.slice(0,12), c.at||"", c.label));
'                               # 지금 등록된 기준값 목록
```

⚠️ **정기물은 여기 넣지 않는다.** 자료가 갱신되면 다시 그려지는 카드(신고가·노선 시세 등)는
`sets.json` 의 `confirmedMd5` 에만 남긴다 — 넣으면 다음 수집일에 doctor 가 통째로 빨간불이 된다.
어느 쪽을 정본으로 믿는지는 `docs/guides/신고가-카드-기준.md` §7 에 표로 있다.

오너가 **확정**이라고 한 카드도 발행본과 같다 — 확정 이후엔 그 카드 픽셀을 바꾸지 않는다.

## §6. 지하철 노선 시세 카드 시리즈 (2026-08-01)

### 지도 — 행정구역은 데이터보다 먼저 늙는다 (2026-08-03)
전국 시군구를 **전수로** 칠하는 카드(인구 히트맵 등)를 만들기 전에 세 가지를 확인한다.

1. **지도의 기준 연도를 본다.** `korea-municipalities.geojson` 은 통계청 **2013년판**이다.
   청원군(2014 소멸)이 살아 있고, 인천 미추홀구가 '남구'이고, 화성 4구 분구(2026-02)가 없다.
   전국 카드는 `data/geo/korea-sgg-2026.geojson`(255개)을 쓴다.
   *일부 지역만 쓰는 카드에서는 이 어긋남이 안 드러난다 — 안 드러난 것이지 맞는 게 아니다.*
2. **코드 체계를 맞춘다.** 통계청 행정구역코드(동작구 `11200`)와 법정동코드(동작구 `11590`)는
   **시도 2자리가 서울만 우연히 같다.** 시군구부터 완전히 다르다. 섞으면 엉뚱한 구가 칠해지는데,
   지도는 그럴싸하게 그려지므로 **눈으로는 안 잡힌다.** `data/geo/sgg-codes.json` 대조표를 거친다.
3. **조인을 수치로 확인한다.** "맞은 개수 / 지도에 없음 / 데이터에 없음"을 찍고 **미매칭 0** 일 때만
   낸다. 조용히 빈 칸으로 그리면 그 자체가 오보다(`joinReport()` 가 계산한다).

### 정기 수집기 — "N개월 연속"을 셀 때 (2026-08-03)
값이 **같은 달은 연속을 끊는다.** 늘지도 줄지도 않았는데 이어 세면 "N개월 연속 감소"가 부풀려져
그대로 오보가 된다. 셀프테스트에 보합 표본을 넣어 고정해 둔다.

또한 상위 N 건만 올리는 자동 수집기는 **잘라낸 개수를 반드시 말한다.** 조용히 자르면 읽는 사람이

- [ ] **문서에 확정 md5 를 베껴 적지 않는다** — 정본은 `sets.json` 의 `confirmedMd5`.

**③ 커밋·푸시** — 커밋 안 한 작업은 세션과 함께 사라진다

- [ ] 의미 단위로 커밋. 메시지는 **무엇을 했나가 아니라 왜 그렇게 했나**
- [ ] 프록시 우회 옵션(`-c http.proxy= -c https.proxy=`)을 **fetch 에도** 붙인다
- [ ] 푸시 실패는 세 가지고 원인이 다르다 — 토큰 미탑재 / 프록시 / non-fast-forward.

- [ ] 정말 막혔으면 `git format-patch origin/<브랜치>..HEAD --stdout` 로 뽑아 오너에게 보낸다
- [ ] **저장소가 공개다**(2026-08-16 전환). 밀기 전에 비밀이 섞였는지 본다:

      (세탁은 sha 가 전부 바뀌어 확정 md5·문서가 어긋나고, 이미 클론된 사본은 못 지운다)
