## 1. 인스타그램 세팅

### ① 이름 필드 — 검색 키워드를 심는 자리

인스타는 **이름 필드도 검색에 색인**됩니다. "위릿노트"만 두면 이미 우리를 아는 사람만 찾습니다.
아이디(@wirit_note)는 그대로 두고, 이름 필드에만 키워드를 붙입니다.

| 안 | 문구 | 노림수 |
|---|---|---|
| **A (추천)** | `위릿노트 · 부동산 데이터` | "부동산 데이터" 검색 유입. 브랜드명이 앞에 와서 각인도 유지 |
| B | `위릿노트 · 경제 인포그래픽` | 부동산 외 확장(증시·통계)까지 커버 |
| C | `위릿노트 | 서울 아파트·경제` | 지역 키워드로 좁혀서 검색 정확도 ↑ |

> 컨셉이 "경제·부동산·주식 코어 + 광범위 통계"니까, 초기 3개월은 **A로 좁게 잡고**
> 팔로워가 붙은 뒤 B로 넓히는 순서를 권합니다. 초기엔 넓은 게 아니라 뾰족한 게 이깁니다.

### ② 카테고리 — 끄거나 바꾸거나

"디지털 크리에이터"는 프로필 상단 한 줄을 먹으면서 아무 것도 알려주지 않습니다.
프로필 편집 → 카테고리에서 **표시 끄기**를 하거나, `뉴스 및 미디어` 정도로 바꿉니다.
그 한 줄을 소개글 3줄 중 하나로 되돌려 받는 게 낫습니다.

### ③ 소개글 — 4가지 안 (150자 제한)

**공통 구조:** `1줄 정체성 → 2줄 수령 약속(뭘·얼마나 자주) → 3줄 CTA`
초기 팔로우 전환에서 제일 잘 먹히는 건 **"얼마나 자주"** 입니다. 구독의 이유가 되니까요.

---

**A안 — 담백한 선언형** (현재 톤 유지·강화)

```
경제와 트렌드를 한 눈에, 위릿.
부동산·증시·통계를 카드 한 장으로
매일 저녁, 숫자 하나씩 👇
```

브랜드 슬로건을 살리면서 "매일 저녁"이라는 수령 약속을 붙였습니다.
세련·미니멀 무드에 가장 가깝습니다. 다만 정보량은 제일 적습니다.

---

**B안 — 효용 명시형** (팔로우 전환에 제일 강함)

```
복잡한 부동산·경제, 카드 한 장으로.
서울 아파트 · 월세 · 증시 데이터를 매일 정리
📌 모든 수치는 원자료 출처 표기
```

3번째 줄이 핵심입니다. **"출처를 반드시 밝힌다"는 건 이 계정의 진짜 차별점**이고
(오보 0 원칙이 실제로 코드에 박혀 있으니 빈말이 아님), 데이터 계정이 널린 판에서
신뢰를 파는 가장 싼 문장입니다. 벤치마크인 아파트랩·flow와 갈리는 지점이기도 하고요.

---

**C안 — 사람 냄새 섞기** (스레드 확장 대비)

```
기사 말고 데이터를 봅니다.
부동산·경제에서 오늘 제일 중요한 숫자 한 개
해석까지 붙여서 매일 한 장 👇
```

"해석까지"가 포인트입니다. 강점으로 꼽으신 **본질 해석·대중적 언어**를
프로필에서 미리 약속하는 문장입니다. 얼굴 노출 없이도 사람이 느껴집니다.

---

**D안 — 하이브리드 (제 추천)**

```
경제와 트렌드를 한 눈에, 위릿.
서울 부동산 · 증시 · 생활통계 매일 한 장
숫자는 원자료에서, 해석은 쉽게.
```

슬로건(각인) + 범위(뭘) + 빈도(언제) + 차별점(출처·해석)이 3줄에 다 들어갑니다.
링크 없이도 "이 계정이 뭐 하는 곳"이 완결됩니다.

### ④ 링크 — 지금은 1개면 충분

인스타는 링크를 여러 개 걸 수 있지만, 지금 단계에서 5개 거는 건 역효과입니다.
**스레드 계정 링크 하나**만 겁니다. 팔로워 5명 단계에서 필요한 건 랜딩페이지가 아니라
"다른 채널에서도 이 사람 보기"입니다.

유튜브를 시작하면 그때 `링크 2개(스레드 / 유튜브)`로 늘리고,
뉴스레터나 부마클 퍼널은 **팔로워 1,000 넘은 뒤에** 붙이는 걸 권합니다.
초기에 수익 링크가 보이면 팔로우 전환이 눈에 띄게 떨어집니다.

### ⑤ 고정 게시물 3개 — 프로필의 진짜 첫인상

지금 게시물 8개 중 **가장 후킹이 센 3개를 상단 고정**합니다.
프로필에 들어온 사람이 실제로 보는 건 소개글 3줄과 이 3칸입니다.

| 3 | **출근길 지하철 속도, 1등과 꼴등이 같은 노선** | 부동산 밖 소재. **"이 계정은 부동산만 하는 게 아니다"**를 보여줌 |

확장 의도(월드컵·월급 순위·통계)가 막힙니다. 정체성의 폭을 첫 화면에서 미리 선언하는 겁니다.

## 2. 스레드 세팅 (지금 완전 백지)

### 왜 스레드를 따로 세팅해야 하나

스레드를 인스타의 복사본으로 쓰면 팔로우할 이유가 없습니다. 이미 인스타에서 보니까요.
**역할을 나눠야** 합니다:

| | 인스타 | 스레드 |
|---|---|---|
| 형태 | 완성된 카드(결론) | 카드 되기 **전**의 숫자·과정·의견 |
| 톤 | 정제됨·무표정 | 말투가 있음·질문을 던짐 |
| 역할 | 저장·공유되는 자산 | 도달·대화, 인스타로 보내는 입구 |

기억하실 게, **스레드 캡처를 인스타에 올려 인사이트를 섞는 원소스 멀티유즈**를
원하셨죠. 그러려면 스레드가 먼저 "쓸 만한 문장"을 생산하는 곳이어야 합니다.
스레드 = 카드의 초안 공장, 인스타 = 완제품 매장. 이 구도가 자연스럽습니다.

### ① 스레드 소개글 — 3가지 안

스레드는 인스타보다 소개글이 넉넉하고, 알고리즘상 **대화체가 유리**합니다.

---

**A안 — 인스타 유도형**

```
경제와 트렌드를 한 눈에, 위릿.
여기선 카드가 되기 전의 숫자를 먼저 풉니다.
정리된 한 장은 인스타 @wirit_note 에.
```

역할 분담이 명확해서 두 계정을 다 팔로우할 이유가 생깁니다.

---

**B안 — 대화 유도형** (스레드 알고리즘에 제일 맞음)

```
부동산·경제 뉴스에서 숫자만 꺼내 봅니다.
기사 제목 말고 원자료를 읽는 쪽.
"그래서 이게 무슨 뜻이냐"까지 같이 이야기해요.
```

스레드는 답글이 도달을 만드는 판이라, 소개글부터 대화를 걸어두는 게 유리합니다.
초기 팔로워 0에서 제일 빨리 움직일 안입니다.

---

**C안 — 관점 선언형**

```
집값·물가·증시. 다들 말이 다른 이유는
같은 숫자를 다르게 자르기 때문입니다.
원자료 그대로 자르는 계정, 위릿.
```

톤은 가장 셉니다. 팔로우 전환률은 좋지만 **주장이 들어간 만큼 조심스러운 안**입니다.
27.12 이후 다주택 논지를 콘텐츠로 못 쓰겠다고 판단하신 것과 같은 맥락에서,
"관점을 파는 계정"으로 포지션되면 나중에 방향 틀 때 발목이 잡힙니다.
→ **B안을 먼저, C안은 팔로워 붙은 뒤 검토**를 권합니다.

### ② 첫 게시물 = 고정 스레드 (계정 소개)

스레드는 첫 방문자가 소개글보다 **첫 게시물**을 먼저 봅니다. 하나 써서 고정합니다.

```
안녕하세요, 위릿노트입니다.

부동산·경제 뉴스를 볼 때마다 이상했습니다.
같은 사안인데 기사마다 숫자가 다릅니다.

그래서 원자료를 직접 열어서
숫자만 꺼내 카드 한 장으로 만듭니다.

여기(스레드)에는 카드가 되기 전의 숫자와
"그래서 이게 무슨 뜻인지"를 씁니다.

정리된 한 장은 인스타에 있습니다 → @wirit_note

첫 질문 하나 드릴게요.
요즘 부동산·경제에서 제일 헷갈리는 숫자가 뭔가요?
```

마지막 질문이 중요합니다. 고정 스레드에 답글이 쌓이면 그 자체가 도달을 계속 만들고,
**답글이 다음 카드 소재가 됩니다.** 소재 발굴 파이프라인의 무료 입력창인 셈입니다.

### ③ 초기 운영 (팔로워 0 → 100)

스레드를 본격적으로 키워본 경험이 아직 없다고 하셨으니, 초기 규칙만 단순하게:

- **하루 원글 1~2개** — 카드 한 장에서 숫자 하나 꺼내 3~4줄로
- **하루 답글 5~10개** — 부동산·경제 큰 계정 글에 **숫자를 보태는 답글**. 초기 도달의 90%가 여기서 나옵니다
- **캡처 대상 만들기** — 반응 좋은 스레드는 그대로 인스타 게시물로 재활용 (원하시던 원소스 멀티유즈)
- **금지** — 카드 이미지를 스레드에 그대로 도배. 스레드는 텍스트 판입니다
