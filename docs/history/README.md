# docs/history — 클로드 프로젝트 문서 보존소

2026-08-30 에 클로드 프로젝트「위릿노트」에 쌓여 있던 md **52개**를 그대로 옮겨 왔다.

## 왜 옮겼나

프로젝트 문서는 **세션이 매번 읽지 않는다.** 스킬이 "최신 인수인계 한둘"만 읽도록
설계돼 있어서, 52개 중 50개는 사실상 아무도 안 보는 상태였다. 그런데 오너 화면에는
전부 보이니 **어지럽기만 하고 쓸모는 없는** 상태가 됐다.

여기로 옮기면 (1) 내용은 영구 보존되고 (2) 세션이 필요할 때 grep 으로 찾을 수 있고
(3) 프로젝트 화면은 깨끗해진다.

## 성격별 분류

| 분류 | 개수 | 무엇 | 지워도 되나 |
|---|---:|---|---|
| **인수인계** | 20 | 세션별 작업 서사 | ✅ 최신 2~3개만 프로젝트에 남긴다 |
| **소재 발굴** | 16 | 소재 조사 기록 | ✅ 결정은 `research/DECISION_LOG.md` 에 있다 |
| **자료·기준** | 13 | 조사 자료·설계안 | ⚠️ 아래 승격분 확인 후 |
| 기타 | 3 | 코드 조각·토큰 | ✅ |

## ⚠️ 저장소로 승격된 것 — 이제 정본은 저장소다

프로젝트에만 있던 **기준 문서 2건**을 찾아 저장소로 올렸다.
기준이 프로젝트에만 있으면 세션이 못 읽으므로 **없는 것과 같다.**

| 프로젝트 원본 | 저장소 정본 |

| `claude_릴스-제작-기준.md` | **`docs/guides/릴스-제작-기준.md`** |

반대로 아래 둘은 **저장소본이 이미 더 최신**이라 프로젝트본이 낡은 쪽이었다:

| 프로젝트 | 저장소 | 판정 |
|---|---|---|
| 청약분양 카드 기준 439줄 | `docs/guides/청약분양-카드-기준.md` **595줄** | 저장소가 정본 |
| 신고가 카드 기준 149줄 | `docs/guides/신고가-카드-기준.md` **658줄** | 저장소가 정본 |

## 이 폴더의 규칙

- **읽는 물건이지 따라가는 물건이 아니다.** `docs/archive/` 와 같은 성격의 사료다
- 여기 있는 내용을 근거로 작업하려면 **먼저 저장소 정본과 대조**한다. 낡았을 수 있다
- 링크 검사(`scripts/check-doc-links.mjs`)는 **이 폴더를 보지 않는다.** `docs/archive/` 와 같은
  이유다 — 프로젝트 안에서만 통하던 주소를 가리키는 게 정상이고, 고치면 역사가 왜곡된다
