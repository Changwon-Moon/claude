## 🔴 P0 — 멈춘 소재를 즉시 푸는 4건

### 1. 서울 지하철 승하차 (서울 열린데이터광장)
- **해금 소재 4개**: `nightstn`(잠들지 않는 역) · `transfer`(환승 순위) · `congest`(혼잡도) · `commutemap`(통근 지도)
- 서울 열린데이터광장 `CardSubwayStatsNew`(역별 시간대 승하차). **인증키 이미 보유**(생활인구용으로 발급받은 것과 동일 계정)
- 난이도 **낮음** — `seoulOpenApi.ts` 배관을 그대로 재사용. 경로형 인증키·1000행 페이징 이슈도 이미 해결돼 있음
- 부수효과: 이미 done인 `metrospeed`·GTX 시리즈와 같은 계열이라 **"지하철이 온다" 주간 시리즈 탄약이 한 번에 채워진다**
- 👉 **가장 먼저 붙일 것.** 투입 대비 산출이 압도적

### 2. 국토부 미분양 통계
- **해금 소재**: `unsold`(📉 미분양의 역설)
- 경로: [국토교통 통계누리 — 시·군·구별 미분양현황](https://stat.molit.go.kr/portal/cate/statView.do?hRsId=32&hFormId=2082) · [공사완료 후 미분양](https://stat.molit.go.kr/portal/cate/statView.do?hRsId=32&hFormId=5328) · [e-나라지표 요약](https://www.index.go.kr/unity/potal/main/EachDtlPageDetail.do?idx_cd=1234)
- ⚠️ **REST API가 아니라 통계표/파일 배포**. KOSIS에 미러 표가 있는지 먼저 확인(있으면 기존 `kosisCli` 재사용 가능 → 난이도 급락)
- 가치: 미분양은 **부동산 심리의 선행지표**라 단발이 아니라 월간 정기물이 된다. 청약·실거래와 교차 서사도 가능

### 3. 소상공인시장진흥공단 상가(상권)정보
- **해금 소재 2개**: `cafe`(카페 창업 vs 폐업) · `cvs`(편의점 밀도 지도)
- [API 15012005](https://www.data.go.kr/data/15012005/openapi.do) (실시간) · [파일데이터 15083033](https://www.data.go.kr/data/15083033/fileData.do) (분기 전수, 2026-03-31판)
- 업종 대분류~소분류 + 좌표 제공 → **지도 카드와 궁합 최상**. 위경도가 있어 구/동 단위 밀도 계산 자유
- 확장성 큼: 카페·편의점뿐 아니라 "무인점포 급증", "치킨집 밀도", "약국 없는 동네" 등 **소재 공장**

### 4. 국민연금 가입 사업장 내역
- **해금 소재 2개**: `salarymap`(회사별 연봉 지도) · `pension`(세대 격차)
- [API 3046071](https://www.data.go.kr/data/3046071/openapi.do) · 보조: [사업장가입자 현황 파일](https://www.data.go.kr/data/15071659/fileData.do)
- 사업장별 **가입자 수·월 보험료 총액·주소** 제공 → 보험료에서 **추정 평균연봉**을 역산할 수 있고, 주소가 있어 **회사 위치 지도**가 된다
- DART(상장사 한정)의 결정적 한계를 보완: **비상장·중소기업까지 커버**
- ⚠️ 추정연봉은 상한(보험료 상한액) 때문에 고연봉 구간이 눌린다 — **"추정"임을 카드에 명시**하고 DART 실측값과 교차검증하는 구조로 설계할 것

## 🟡 P1 — 새 시리즈를 여는 4건

### 5. K-apt 공동주택 관리비
- [단지 관리비 정보 3039714](https://www.data.go.kr/data/3039714/fileData.do) · [공동주택 기본정보 API 15058453](https://www.data.go.kr/data/15058453/openapi.do) · [단지목록 API 15057332](https://www.data.go.kr/data/15057332/openapi.do) · 원본 [K-apt](https://www.k-apt.go.kr/)
- 신규 소재: **"관리비 비싼 아파트 TOP"**, "같은 평수인데 관리비 2배", "겨울 난방비 지도", "경비원 있는 단지 vs 없는 단지"
- 위릿 니치와 정확히 일치하고 **생활 체감도가 매우 높다** — 실거래가보다 오히려 반응이 좋을 수 있는 영역
- 실거래 데이터와 단지 키로 조인 가능 → "비싼 집 = 비싼 관리비인가?" 같은 교차 분석

### 6. 부동산 공시가격 (공동주택 공시가격)
- 신규 소재: 보유세 시뮬레이션, "종부세 대상 단지 지도", 공시가/실거래가 괴리율
- 세제는 **정기적으로 이슈화**되는 주제(기존 `주택세제-카드-설계안` 문서와 연결)
- ⚠️ 세금 계산은 오보 리스크가 큼 — 계산 로직을 코드로 고정하고 가정(1주택·연령·보유기간)을 카드에 명시

### 7. 법원 등기정보광장 / 법원경매정보
- **해금 소재**: `foreign-buy-tohuh`(토허제×외국인 매수 — 데이터 대기 중 상태로 장기 정체)
- 신규 소재: 경매 낙찰가율 추이, "경매로 나온 강남 아파트", 임의경매 급증
- ⚠️ 공식 오픈API가 약해 **크롤링 성격**이 될 가능성 — robots·약관 확인 필수. 이전 세션에서 사이트 점검으로 막혔던 이력 있음

### 8. 건축행정시스템(세움터) 인허가·착공 통계
- 신규 소재: **"3년 뒤 입주 물량 절벽"** — 인허가는 2~3년 선행지표라 미래를 말할 수 있는 드문 데이터
- 미분양(P0-2)과 묶으면 **공급 사이클 시리즈** 완성

## 붙이는 순서 제안
```
1) 서울 지하철 승하차   → 소재 4개 해금, 배관 재사용, 난이도 최저   ★ 최우선
2) 소상공인 상가업소     → 소재 2개 해금 + 지도 소재 공장
3) 국토부 미분양        → 월간 정기물 신설 (KOSIS 미러 여부 먼저 확인)
4) 국민연금 사업장       → salarymap 해금, DART 보완
5) K-apt 관리비         → 완전 신규 시리즈, 생활 체감도 최상
```

## 연결할 때 반드시 지킬 것 (기존 사고 이력에서)
- **probe 먼저, 추측 금지.** 표 ID·필드명·분류축을 실제 응답으로 확인하기 전에는 `enabled: false`. (KOSIS 사망표에서 '사망원인 50항목' 축을 안 고르면 특정 사인 숫자가 총사망자수로 나갔던 사례)
- **인증키가 경로에 들어가는 API는 전용 redact 함수를 쓴다.** 쿼리스트링만 지우는 로직으로는 키가 로그로 샌다(서울 열린데이터광장이 이 형태).
- **행정구역 코드 체계는 표마다 다르다.** 통계청/법정동 혼용 — 조인 전 대조표를 거친다.
- **부분 수집은 던진다.** 페이징으로 받은 행 수가 전체와 다르면 순위·합계가 거짓이 된다.
- **수집 결과 0건이면 API 장애보다 코드 폐기를 먼저 의심**한다(화성 분구 사례).
