## 1. 새로 생긴 배관 — ECOS M2

저장소의 ECOS 수집기는 기준금리·환율 둘뿐이었다. M2 는 없었다.

| 파일 | 역할 |
|---|---|
| `packages/collectors/src/ecosM2Cli.ts` | 통계표 목록 → 항목 목록 → 월별 시계열까지 **코드가 스스로 찾아** 받는다 |
| `.github/workflows/ecos-m2.yml` | `data/ecos-queue.txt` 푸시로 깨어남 → `data/datasets/m2-monthly.json` 커밋 |

세션 컨테이너에서 `ecos.bok.or.kr` 은 egress 허용목록 밖이라 **Actions 에서만** 돈다.

### ECOS 를 다루며 실측한 함정 4개 (다음 세션이 다시 밟지 않게)

1. **이름이 글자까지 같은 은퇴한 표가 있다.** `101Y004`(1.7.3.1.2 구지표)와 `161Y006`(1.1.3.1.2 신지표)는 이름이 동일한데 앞의 것은 2004-09 에서 멈춘다. → 최근 24개월을 **찔러 보고** 데이터가 살아 있는 표를 고르게 했다.
2. **긴 구간을 한 번에 물으면 앞쪽 81개월만 오고 서버가 "총 81건"이라 답한다.** 거짓 총계다. → 1년 창으로 잘라 여러 번 물어 붙인다.
3. **항목의 `END_TIME` 을 믿고 자르면 안 된다.** 구지표 표가 "1986~2003"이라 답하는데 실제로는 지금도 발표된다. 끝은 **언제나 지금**까지 물어본다.
4. `StatisticTableList` 에 부모코드 `101` 을 주면 `INFO-200`(데이터 없음)이 온다. → 전체 목록을 받아 이름으로 거른다.

## 2. ★ 가장 중요한 판단 — 2025-12-30 한국은행 통화지표 개편

한은이 **수익증권(펀드·ETF)을 M2 에서 제외**했다(약 -400조). 신·구를 1년간 병행 발표한다.

- 신 기준으로 역대 정부를 재면 **현 정부 구간만 유독 작아진다** — 자를 바꿔 놓고 키를 비교하는 꼴.
- ECOS 는 같은 통계표 안에 **`BBHA16 [참고] 구 M2(평잔, 원계열)`** 로 개편 전 계열을 싣는다.
- **오너 지시: 카드는 개편 전 기준으로 전 구간 통일.**
- 2026-05 기준 — 구 M2 **4,771조** / 신 M2 **4,184조** (차이 587조).

> 처음엔 신 기준으로 표를 만들어 오너에게 드렸다가 **오너가 "기준이 바뀌었다"고 바로잡아 줬다.**
> 이 소재를 다시 만질 때는 **어느 M2 인지부터** 확인한다. 숫자의 뜻이 통째로 바뀐다.

### 계열 접합
개편 전 계열(`BBHA16`)은 2003-10 부터라 노무현 취임 직전월(2003-01)이 없다. 그 앞은 구지표 표(`101Y004`, 1986-01~)에 있고 **겹치는 달의 값이 소수점까지 같다(차이 0.00)**. 빌더가 매 빌드마다 다시 대조하고, 다르면 던진다.

### 오너 확정 사항
- 구간 = **전임 퇴임월 → 자기 퇴임월**(겹침 0, 합 일치). 권한대행 기간은 후임에 포함.
- 막대 = 총 증가액, 막대 안 알약 = 월평균. **강조 둘**: 최대 총액(문재인, 레드 막대) / 최고 속도(이재명, 레드 알약) — 채널이 달라 초점이 갈리지 않는다.
- **대통령 사진 넣는다** — Wikimedia 자유 라이선스만. `data/photo-batch.tsv` 에 줄 추가 → `photo-batch.yml` 이 취득. 윤석열은 `wikipedia|Yoon Suk Yeol`(`yoon-sukyeol4`)로 잡혔다(하이픈 표기는 실패).
- **재임 중 막대는 점선 + 옅은 칠** — 13개월을 5년과 나란히 꽉 찬 막대로 세우면 "임기 다 채우고 저만큼"으로 읽힌다. 글자만이 아니라 **모양으로도** 말한다.
- 하단 문구: `현 정부가 월평균 40.8조로 문 정부의 약 2.0배 속도`
- **'부동산 규제/완화' 라벨은 넣지 않는다** — 검증 안 된 정치적 해석. 넣으려면 1차 출처 대조가 선행돼야 한다.
