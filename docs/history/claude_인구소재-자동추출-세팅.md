## 가장 중요했던 발견 — 대조표 방향이 반대였다

첫 실전 수집 로그에서 연령 표를 나눠 부르는 URL 의 지역 코드가 이상했다. 파 보니:

| | 종로구 |
|---|---|
| **우리 지도** | `11010` |
| 인구·세대·이동·연령 | `11110` |
| 출생·사망 | `11010` |

**지도 코드 255개와 인구표 코드가 겹치는 것은 9개뿐이고, 그 9개는 우연히 같은 숫자입니다.**
그동안 출생·사망만 변환하고 인구는 그대로 쓰고 있었습니다 — 정확히 거꾸로였습니다.
그대로 뒀으면 9곳에 엉뚱한 시군구 숫자가 들어가고 246곳은 빈 채로 지도가 그려집니다.
빈 지도는 "데이터가 없다"로 보이고, 채워진 9곳은 아무도 의심하지 않습니다.

문서에도 "우리 지도는 통계청 코드"라고 적혀 있었습니다. **틀린 기록이었고, 그 기록을
믿고 배관을 짰습니다.** 실측이 문서를 이겼습니다. 이제 여섯 표 전부 대조표를 거칩니다.

## 🚧 알려진 결손 하나 — 화성시

출생·사망이 3% 부족한 것은 **화성시 하나** 때문입니다. 2026년 2월에 4개 구로 나뉜
도시라 우리 지도에는 만세구·효행구·병점구·동탄구만 있는데, 2024년 데이터에는
`화성시` 한 행으로만 있습니다.

**이 결손은 지도에서 안 보입니다.** 화성시 자리는 비어 있고, 빈 칸은 "데이터가 없는 곳"
으로 읽힙니다. 전국 순위 카드를 만들면 화성시 없는 순위가 되는데, 그건 틀린 순위가
아니라 **틀린 줄 모르는 순위**입니다.

그래서 같은 응답 안의 전국 행과 우리 합계를 매번 대 보고 3% 이상 벌어지면 경고를
남깁니다. 되살리지는 못해도 **빠졌다는 사실이 보이게** 합니다.
출생·사망으로 전국 순위 카드를 만드실 때는 이걸 아시고 만드시면 됩니다.

## 순이동은 굵기가 다릅니다

인구이동 표는 일반시를 구로 안 나눕니다 — 수원시·성남시·고양시·용인시가 시 단위
한 행으로만 옵니다. 우리 지도는 그 시들을 구로 쪼개 놓아 39곳이 빕니다.
수원시 순이동을 4개 구에 나눠 넣는 것은 만들어 낸 숫자라 비워 뒀습니다.

## 가는 길에 잡은 것들

**워크플로가 한 번도 안 돌던 이유는 키가 아니었습니다.** YAML 이 깨져 있었습니다 —
여러 줄 셸 문자열의 이어지는 줄이 1열에 붙어 블록이 끊겼습니다. GitHub 은 깨진
워크플로를 **등록조차 하지 않아 실행 목록에 뜨지도 않습니다.** 빨간불조차 없습니다.
`auto-produce.yml` 도 같은 결함으로 조용히 안 돌고 있었습니다.

**인증키가 저장소에 커밋됐습니다.** KOSIS 가 응답하지 않던 시각, 실패한 URL 이 오류
메시지에 실렸고 그게 결과 파일로 커밋됐습니다. 재발급하셨고, 이제 `redactUrl()` 이
모든 오류 메시지에서 키를 지웁니다 — 국토부·DART·부동산원 수집기에도 함께 적용됩니다.

**사망 표는 C1 이 지역이 아니었습니다.** C1 이 사망원인이고 C2 가 행정구역입니다.
그대로 뒀으면 `11=호흡기 결핵`이 지역 코드로 들어갈 뻔했습니다.

**연간 표에 월 형식을 주고 있었습니다.** `202407` 같은 해는 없어서 출생·사망이
"데이터가 존재하지 않습니다"로 통째로 빠졌습니다. 표가 틀린 것처럼 보였지만
한 줄짜리 형식 문제였습니다.

## 조용한 실패를 막은 곳

- **전국 합계와 대조** — 빠진 시군구를 %로 잡는다 (화성시를 이렇게 찾았다)
- **깨진 워크플로를 doctor 가 매 세션 검사** (27/27 정상)
- **인증키가 로그·산출물에 실리지 않는다**
- **여섯 표 전부 코드 대조표 필수** — 없으면 던진다
- **지도 커버리지 90% 미만이면 대조표 생성이 멈춘다** (굵은 표는 이유를 적어야 통과)
- **지역 축을 틀리면 조용히 비지 않고 던진다**
- **65세 이상이 한 줄도 없으면 던진다** — 0은 '고령인구 없는 시군구'가 되어 오보다
- **한 표가 넘어져도 나머지는 간다** — 실패는 모아 보고하고 빨간불로 끝낸다
- **probe 가 네트워크 실패만 골라 재시도** — KOSIS 가 몇십 분씩 안 열리는 날이 있다
