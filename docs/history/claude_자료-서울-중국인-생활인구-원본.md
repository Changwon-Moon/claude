# 서울 중국인 생활인구 — 원본 데이터 정리 (2026-08-06)

> 보내주신 인포그래픽(`zz2` 제작, 「서울 내 중국인 생활인구(%) Top 50」)의 원본을 특정했다.
> 결론부터: **공개 데이터가 맞고 API 로 우리가 직접 뽑을 수 있다.**
> 다만 **정의에 함정이 크다** — 그대로 옮기면 오보가 된다.

---

## 🔴 0. 가장 먼저 — "생활인구"는 "거주인구"가 아니다

**서울 생활인구 = 서울시와 KT 가 통신·공공 빅데이터로 추계한, 특정 지역·특정 시점에
"존재하는" 모든 인구.** 거주 여부와 무관하다.

| | 생활인구 | 등록인구(거주) |
|---|---|---|
| 뜻 | 그 시각 거기 **있던** 사람 | 거기 **사는** 사람 |
| 시간 | **시간 단위** | 분기 단위 |
| 출처 | KT LTE 시그널 + 대중교통 + 주민등록 + 사업체·건물DB | 행정자료 |

**→ 가리봉 27.59% 는 "가리봉 주민 넷 중 하나가 중국인"이 아니다.**
"그 시간대 가리봉동에 있던 인구 추계 중 27.59%" 다.

이 차이가 특히 큰 곳:
- **구로·가산·독산** — 산업단지·상권. 낮 시간 **근무·방문 인구**가 잡힌다
- **회기·화양·이문·안암** — 대학가. 인포그래픽도 별표로 표시했다(경희대·건대). **유학생**이다

  개별 국가별로는 안 나온다. ⚠️ 컬럼명은 원본 파일에서 직접 확인 필요

## 3. ⚠️ 이 인포그래픽에서 확인 안 되는 것 넷

원본을 재현하려면 이 넷이 있어야 한다. 인포그래픽에는 **없다.**

1. **기준 시점** — 몇 년 몇 월 데이터인가
2. **시간대** — 생활인구는 **시간별**이다. 새벽 3시와 오후 2시가 완전히 다르다.
   평균인지, 특정 시간인지, 일평균인지 안 적혀 있다
3. **장기 / 단기 / 합산** — 세 가지 중 무엇인가
4. **행정동 이름의 단위** — '대림'은 대림1·2·3동 중 무엇인가, 아니면 합친 것인가

**→ 이 넷을 모르면 같은 숫자가 재현되지 않는다.** 우리가 카드로 만들려면
우리 기준을 정하고 **그 기준을 카드에 명시**해야 한다.

## 4. 우리가 직접 뽑는 법

```
서울 열린데이터광장 Open API (인증키 발급 필요, 무료)
  http://openapi.seoul.go.kr:8088/{KEY}/json/SPOP_FOREIGNER_RESD_JACHI/1/5/{YYYYMMDD}
  ※ 정확한 서비스명은 데이터셋 페이지의 'Open API' 탭에서 확인
```

- 비율을 만들려면 **분모**가 필요하다: 내국인 생활인구(`OA-14991`) + 외국인
- API 는 최근 2개월만 → **과거는 ZIP 다운로드**(2017~)
- 우리 수집기에 붙이면 매일 자동 갱신 가능

**서울시 데이터는 KOSIS 와 별개 API 다.** 인증키를 따로 발급받아야 한다.

## 5. 보완용 — '거주' 기준 데이터

생활인구만 쓰면 "있던 사람"과 "사는 사람"이 섞인다. 대비용으로 이게 있다.

**법무부 「장기체류외국인 등록 — 월별 등록외국인 시군구별 거주 현황」**
(공공데이터포털 `15100022`, **2026년 6월 기준까지 제공**)

- 행정자료 기반이라 **추계가 아니다**
- **시군구 단위** (행정동은 아님)
- 국적별로 나온다

> **생활인구(있던 사람) vs 등록외국인(사는 사람)을 나란히 놓는 것**
> — 이게 이 소재에서 가장 정확하고, 동시에 가장 새로운 각도다.

---

## 6. 카드로 만든다면 — 지켜야 할 선

1. **제목에 '생활인구'를 반드시 넣는다.** '중국인 비율'로 줄이면 거주로 읽힌다
2. **기준 시점·시간대를 카드에 명시**한다. 없으면 검증 불가능한 숫자가 된다
3. **비율과 인원을 함께 보여준다.** 비율만 쓰면 가리봉(4,393명)이 구로(22,724명)보다
   커 보인다
4. **대학가는 별도 표시** — 원 인포그래픽도 별표를 달았다. 유학생과 정주 인구는 다르다
5. **'중국'에는 한국계 중국인이 포함**된다(국적 기준)
6. 3명 미만은 비식별 처리, 소수점 포함이라 **부분 합이 전체와 안 맞을 수 있다**
7. 추계값이다 — **KT 가입자 기반**이라 통신사 점유율 보정이 들어간다

## 7. 판단이 필요한 것

이 소재는 **숫자보다 프레임이 위험하다.** 같은 데이터로
"외국인이 몰려 산다"도, "산업단지 근무인구가 잡힌 것"도 쓸 수 있다.
데이터가 실제로 말하는 것은 **"그 시각 거기 있던 사람의 국적 구성"** 까지다.

위릿이 이 소재를 다룰지, 다룬다면 어떤 프레임으로 갈지는 **오너 판단**이다.
다루신다면 §6의 일곱 가지는 협상 대상이 아니다 — 하나라도 빠지면 오보가 된다.
