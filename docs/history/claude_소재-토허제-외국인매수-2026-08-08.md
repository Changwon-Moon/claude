## 1. 카드 한 줄 요약
토허제(외국인 토지거래허가) 시행 전후, 서울에서 외국인이 집합건물(아파트·오피스텔·빌라 등)을
얼마나 샀고 어느 나라 사람이 어느 구를 샀는지를, 기존 **토허제 지도 템플릿**에 얹는다.

## 2. 원자료(1차 출처)
- **법원 등기정보광장** `data.iros.go.kr` — 소유권이전등기(매매) 신청현황, **매수인 국적별·지역별**.
  이것이 "외국인 매수 X명, 중국 Y%" 보도의 공통 원천이다.
  - 관련 메뉴: 소유권이전등기 신청현황(지역별) `openRgsCs.do?ris_menu_seq=0000000022`
  - ⚠️ 포털형(엑셀/조회). 클린 API 아님 → **manual feed**(사람이 받아 넣는다) 또는 스크레이퍼 필요.
- 교차확인용: 한국부동산원 **외국인 주택소유현황**(KOSIS orgId=408, `DT_408004_009`) — 단, 이건 **보유(stock)**이고 우리 소재는 **매수(flow)**다. 혼용 금지.

## 3. 확보된 수치 (보도 인용 · 출처=등기정보광장) — 대조 전 잠정
- **서울 집합건물 외국인 매수(2025년)**: 1,916명 (전년 1,727명 대비 +10.94%)
  - 국적: **중국 822명 · 미국 585명** (2강)
- **토허제 시행(2025년 8월 말) 후 월별 감소**: 9월 174명 → 12월 127명
- **지역×국적**:
  - 중국인 다수: **구로(145) · 금천(126) · 영등포(95)** — 서남권, 소형·수익형 비중
  - 미국인 다수: **강남(77) · 서초(70) · 송파(52)** — 강남3구, 학군·한강변·브랜드
- 전국 각도(별도 보도): "외국인 매수 2,000명 감소, 73%가 중국인" — **전국 스케일**이라 서울 수치와 섞지 말 것.

출처 보도: 한국부동산뉴스(karnews idxno=22332, 등기정보광장 인용), 아시아경제 부동산AtoZ(2026-08-06).

## 4. 어그로 각(궁금증 갭) — 선동 아님

  국적마다 사는 동네가 극명히 갈리는 게 후킹 포인트.

## 5. 설계 (기존 자산 재활용)
- 토허제 지도 템플릿(`build-tohuh-map.mjs` 계열, 한강+서울 외곽선+구 라벨) 재활용.
- 구성안: (p1) 서울 지도에 구별 외국인 매수 국적 1위 색칠(중국/미국) + 상위 구 라벨.
  (p2) 토허제 전후 월별 매수 추이 꺾은선(9→12월) + 국적 도넛(중국/미국/기타).
- 수치는 빌더가 데이터 JSON에서 읽는다(손으로 안 적음, provenance 기록).

### 8-2. 등기정보광장 원자료 대조: **막힘 (미대조 유지)**
- 점검(2026-08-09 11:00)은 종료됨. 사이트 접속 자체는 됨.
- 그러나 등기정보광장은 **통계 표를 화면에서 자바스크립트로 불러오는 포털**이라,
  이 세션이 쓸 수 있는 웹 도구(WebFetch = 정적 HTML만 읽음)로는 **표의 실제 숫자를 읽지 못한다.**
  여러 통계/인포그래픽 페이지를 시도했으나 모두 "숫자 없음"(메뉴·안내문만 반환).
- 또한 이 세션은 예약 실행(스케줄)이라 오너 컴퓨터·로컬 브라우저에 연결이 없어
  대화형 조회/다운로드가 불가능하다.
- **결론: 오보 0 원칙상 보도 수치를 발행값으로 승격할 수 없다. `verified: false` 유지.**
