# 서울 생활인구 배관 현황 + 열린데이터광장 소재 후보 (2026-08-08)

## 1. 서울 생활인구 3종 — 서비스명·컬럼 확정됨

오너가 데이터셋 공식 샘플 URL에서 서비스명을 확인해줬고, probe(Actions)가 실제 데이터를 받아 컬럼까지 확인했다. (기준일 20260728로 성공 — 공개 지연이 길어 날짜 폴백을 넣음)

| 구분 | 데이터셋 | 서비스명 | 상태 |
|---|---|---|---|
| 내국인 | OA-14991 | `SPOP_LOCAL_RESD_DONG` | 이름·컬럼 확인 (enabled 대기) |
| 단기체류 외국인 | OA-14993 | `SPOP_FORN_TEMP_RESD_DONG` | 이름·컬럼 확인 (enabled 대기) |
| 장기체류 외국인 | OA-14992 | `SPOP_FORN_LONG_RESD_DONG` | 이름·컬럼 확인 (enabled 대기) |

### 컬럼 (probe 결과 = data/seoul-probe.md)

- **외국인 표(장기·단기 동일 구조, 6컬럼)**: `STDR_DE_ID`(기준일), `TMZON_PD_SE`(시간대 00~23), `ADSTRD_CODE_SE`(행정동코드), `TOT_LVPOP_CO`(총계), `CHINA_STAYPOP_CO`(중국), `ETC_STAYPOP_CO`(중국 외)
- **내국인 표(32컬럼)**: 위 3개 + `TOT_LVPOP_CO` + 성별×5세단위 연령대(MALE/FEMALE F0T9…F70T74)

### 저장소가 몰랐던 핵심 질문 3개 — 답 나옴
1. 중국인 구분 컬럼 = `CHINA_STAYPOP_CO`(중국) / `ETC_STAYPOP_CO`(중국 외)
2. **외국인 표의 `TOT_LVPOP_CO` = 외국인 합계다(전체 인구 아님).** 검산: 233.329 ≈ 89.22(중국)+144.107(중국외). → **외국인 비율(%) 분모 = 내국인 TOT + 외국인 TOT** (두 표를 합쳐야 함)
3. 시간대는 시간별(00~23) — 하루치 = 424동 × 24시간 = 10,176행

## 2. 남은 결정 (enabled 켜기 전) — 오너/다음 세션 판단

- ⚠️ **행정동코드 체계가 다르다.** 서울 API는 `11110515`(청운효자동), 우리 지도(`data/geo/`)는 `11110038` 계열. 겹치지 않음 → **대조표가 필요**하다. 동 단위 지도 카드를 만들려면 이 매핑이 선행. (구 단위 집계 카드는 매핑 없이도 가능)
- **어느 시간대를 쓸지** 정해야 한다(예: 낮 인구는 14시, 밤 인구는 03시). 시간별이라 카드 목적에 따라 고른다.
- 위 둘 정하면 `sources/seoulOpenApi.ts`의 `enabled`를 켜고 정기 수집 시작.

## 3. 콘텐츠 소재용 서울 열린데이터광장 데이터셋 후보
