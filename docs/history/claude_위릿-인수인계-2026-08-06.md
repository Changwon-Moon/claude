## 이 세션에서 굳은 것

### 1. 무순위(줍줍) 카드는 판이 둘이다

`price.byType` **유무**가 판을 가른다. 플래그를 손으로 켜지 않는다.

| | 규모 우선 (송도형) | 타입·분양가 (장위형) |
|---|---|---|
| 조건 | `price.byType` 없음 | 있음 |
| 위 단 | 전용면적별 잔여 세대 | 단지 규모 4칸(총 세대수/동수/최고 층수/잔여) |
| 아래 단 | 잔여/동수/층수 | 타입별 세대수 · 최고 분양가 4칸 |

무순위라고 늘 분양가를 모르는 게 아니다 — 본청약 때 값이 매겨진 단지의 잔여 세대는 안다.

### 2. 새 판형은 **선택자로 가둔다**

확정본 셋이 같은 템플릿을 쓴다: 한강 `3dc78a13…` · 송도 `553d4532…` · 장위 `5af157c8…`.
공통 CSS 를 고치면 셋이 같이 움직인다. `.frow.four` · `:has(.frow.four)` 처럼 그 판형만
잡는 선택자로 가두고, **고칠 때마다 셋의 md5 를 전부 다시 찍는다.**
필요가 없어진 장치는 통째로 걷어낸다(이번에 `compact`·`fhead` 를 그렇게 지웠다).

### 3. 조감도 크롭은 계산이다

오너의 "너무 작다 / 치우쳤다"를 감으로 고치지 않는다.
- 확대 = 크롭 **폭**. 가로세로비 `1080 ÷ 446 = 2.42` 가 상한(넘으면 빌더가 던진다).
- 좌우 = 창문 격자의 세로 대비로 **진짜 건물**만 골라 가로 중앙값을 구하고 크롭 중심을 맞춘다.
  **크롭 창을 왼쪽으로 옮기면 단지는 오른쪽으로 간다.**
- 상하 = `shift = 남는 세로 × 42.5%` 를 뒤집어 푼다. 건물 밑동이 잉크 번짐에 닿아야
  제목 위 검정 띠가 사라진다.
- 좌표는 데이터셋 `photo.provided` 에 적는다.

### 4. 확정 ≠ 발행 승인

픽셀을 고정(`confirmedMd5`)해도 1차 출처 대조가 안 끝났으면 `state` 를 **발행 보류**로 두고
`publishGate` 에 남은 것을 적는다. **발행 대기열에는 올리지 않는다.**

### 5. 매일 도는 것은 조용한 이유를 스스로 말한다

`schedule` 은 **기본 브랜치**의 워크플로만 깨운다 — 이걸 몰라서 예약 7개가 한 번도 안 돌았다.
그리고 성공해도 새 공고 0건이면 침묵했다. 지금은 예약 실행이 항상 요약(digest)이고
어제와의 차이는 🆕 로 보인다. **알림이 아예 안 오면 그건 고장이다.**

### 6. 실패가 마지막에 몰리는 구조는 검사를 앞으로 당긴다

`scripts/check-push.mjs` → `doctor` 가 부른다. **읽기가 된다고 쓰기가 되는 게 아니다**
(프록시는 fetch 를 통과시키면서 push 만 막을 수 있다) — 판정은 `push --dry-run` 이다.
막힌 것을 다른 인증 경로로 돌아가지 않는다.

### 7. 캡션 규칙 (오너 지시)

- 출처는 `한국부동산원 청약홈` 까지만. 괄호 설명과 URL 은 뺀다(단, '출처' 낱말은 남긴다).
- ⚠️ 로 시작하는 조언·경고 문단을 넣지 않는다. 사실만 전한다.
- 인스타는 마크다운을 렌더하지 않는다(`**굵게**` 는 별표가 그대로 보인다).
- 숫자는 **카드와 같은 표기**로. `9.5억 (95,100만원)` 처럼 정확한 값은 괄호에.
- 카드에서 뺀 단서는 캡션이 받는다(예: 회색 머리글을 지워 사라진 '최고가 기준').
