## 막힌 것 — git push
매번 동일한 오류:
```
access denied by the git proxy: Changwon-Moon/claude is not in this session's authorized
repository set, so the proxy will not inject a credential for it.
```
- PAT 토큰 문제 아님 — 읽기(`git ls-remote`)는 항상 성공, 같은 토큰으로 push만 403
- 오너가 토큰(`wirit_note2`)에 code/actions/workflows **Read/Write 권한을 새로 켜고 재시도해도 동일**하게 막힘
  → 토큰 스코프와 무관한 **세션 레벨 저장소 인가 목록** 문제로 재확인
- 데스크톱 앱 연결(`mcp__remote-devices__*`)도 이 세션엔 안 붙음(PC 앱을 켰다고 응답했지만 도구가 안 잡힘)
- claude.ai GitHub 커넥터("Add from GitHub")는 문서상 **읽기 전용 컨텍스트 임포트**용이라
  이 git-proxy 인가와는 별개 메커니즘일 가능성이 높음(미검증)

   - 오너가 첨부한 `wirit-songpa-tower.bundle`(25커밋)을 이 컨테이너에 두고

   - `git push origin claude/instagram-content-automation-roadmap-fxnb7p`
