## 1. 판면 구조

```
[오늘의 N억 클럽 (계약 YYYY.MM.DD)]  [🔵 역명 뱃지]
[단지명(잉크) 평형(코발트)]              ← 지역 안 붙임
[가격(레드 150px) 달성!(잉크)  │  제원 3줄(회색 34px)]
[월별 최고가 곡선 — 옅은 회색 판 + 판 안 대각 흰색 워터마크]
[푸터: 출처 · 2020년 이후 기준            @wirit_note]
```

| 자리 | 확정 규칙 |
|---|---|
| 킥커 날짜 | **계약일.** `계약` 두 글자를 앞에 붙인다 |
| "N억 클럽" · "달성!" | **돌파일 때만.** 그냥 신고가면 `오늘의 신고가`, 달성! 없음 |
| **지역** | **안 붙인다** (2026-08-16b 변경 — 아래 §1-1) |
| 평형 | 코발트 |
| 가격 | 레드 150px + "달성!" 잉크 62px (서체는 둘 다 `--font-num`) |
| 제원 | **회색 700 / 상한 34px** · 3줄(세대수·준공 / 전용·층 / 세대당 주차) |
| 역 뱃지 | 자료 있고 **직선 1,000m 이내**일 때만. 거리는 싣지 않는다 |

### 1-1. ⚠️ 제목에서 지역을 뺀 이유 (오너 "이름 앞에 지역은 빼는걸로 전체 세팅")

예전 규칙: 앞에 회색 지역 라벨을 붙이되, **단지명이 이미 지역을 품으면 생략**
(`광명한진타운` → 지역 없음, `늘푸른벽산` → "영통 늘푸른벽산").

규칙 자체는 말이 되는데 **결과가 카드마다 제목 모양이 다른 것**이었다.
매일 나가는 정기물에서 그건 브랜드가 흔들리는 것과 같다.
→ 지역을 통째로 빼고 제목을 **`단지명 + 평형` 두 토막으로 고정**했다.

지역이 자료에서까지 사라지지는 않는다:
- 카드에서는 **역 뱃지**(길음역·다산역)와 **캡션**이 말한다
- `meta.region` 에 구·법정동·지번이 남는다 — 캡션 쓰는 사람이 다시 찾지 않게
- 다시 싣게 되면 제목이 아니라 **킥커 쪽**에 둔다(제목은 주인공 하나만 세우는 자리)

적용 범위는 `singo-record@1` 뿐이다. `build-dogam-card` 의 `"{구} 신고가 TOP3"` 처럼
**구 자체가 소재인 카드**는 해당 없다.
확정본 `singo-gwangmyeong-hanjin` 은 원래 지역 라벨이 없어 **픽셀 불변**(md5 `7f875b0a2540` 재확인).

## 2. 곡선 판

| 선 | 무엇 | 색 | 점 |
|---|---|---|---|
| 위 | 이번에 넘은 선 (라벨은 오늘 자리) | 잉크 점선 | — |
| 중간 | 지난 사이클 고점 + `지난 고점대비 +N%` | **빨강** | 빨강 채움 |
| 아래 | 기준선 이후 최저점 + `저점대비 +N%` | **코발트** | 파랑 채움 |
| 오늘 | — | — | **채우기 없이 잉크 테두리** |

- 색 기준은 방향이 아니라 **무엇과 견주는가**다.
- 두 세로 직선의 **길이가 곧 그 퍼센트**. 곡선 뒤에 깐다. 저점 직선은 **오늘 점 x** 에 세운다.
- **달마다 관측 점을 찍지 않는다** — 65개월치가 곡선 위에서 회색 털이 된다.

## 5. ⚠️ 게이트 구멍 두 개 (다른 카드에도 있었다)

### 검수가 "통과"라고 말해도 무엇을 검수했는지 본다
`rebuild-cards`·`produce-card` 는 `data/content/<날짜>/` 를 본다. 그런데 빌더가
**`--publish` 없이** 돌면 결과는 `data/out/_spike` 로 간다 → **옛 발행본을 검수하고 통과**.
판이 칸을 7px 넘긴 카드가 초록으로 나갔고 확정 직전까지 갔다.

**고침**: `builders.json` args 에 `--publish` / `produce-card` 가 mtime 비교로 **멈춘다** /
`rebuild-cards` 는 새로 쓰인 쪽을 검수한다.

### 캡션 서명 검사가 재생성보다 **앞**에 있었다
`build-foreign-rank`·`build-jeongbi-map` 등이 캡션을 다시 쓰면서 고정 서명을 날린다.
재생성 전에 통과한 검사가 재생성 직후 깨져 **확정이 매번 같은 자리에서 막혔다.**
**고침**: `재생성 → 서명 반영(멱등) → 서명 확인` 순서로.

⚠️ **주차대수는 기본정보에 없다.** 세대수는 `getAphusBassInfoV4`, 주차대수는
`getAphusDtlInfoV4`(`kaptdPcnt` 지상 + `kaptdPcntu` 지하) — 다른 오퍼레이션이다.
지상+지하를 더하고, 둘 다 0이면 파일을 안 쓴다(0대인 아파트는 없다).
카드에는 **세대당 대수**로 적는다 — 총 대수만 적으면 큰 단지가 무조건 좋아 보인다.
