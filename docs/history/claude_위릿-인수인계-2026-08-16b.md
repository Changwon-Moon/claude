**08-16 15:18(KST) 이후 모든 워크플로가 스텝 0개로 3초 만에 실패**한다.

- **주차대수 5건**을 못 받았다 → 제원이 2줄이다. 판형이 "자료 없으면 안 붙인다"라 그대로 낼 수 있다.
- **관제탑이 안 올라간다.** 배포도 Actions 가 한다.
  세션에서 화면 조립(`_site`)까지는 되지만 Cloudflare 로 **올리는 건 못 한다**(토큰이 GitHub Secrets).
  → **"조립 완료"와 "배포 완료"는 다르다. 구분해서 말한다.**
- 살아나면 `apt-detail.yml` cron(`17 */2 * * *`)이 대기열 5건을 알아서 받는다. 사람이 밀 필요 없다.

(공개 저장소는 Actions 무제한 무료. 다만 커밋 이력까지 공개되니 키가 섞였는지 먼저 훑어야 한다).

  **확정된 캡션은 생성기가 못 덮는다.**
- **주차·역은 자료가 있을 때만.** 없으면 그 줄이 없다(빈칸·물음표·추정값 금지).

## 5. 이 세션이 밟은 함정 (다음 사람이 다시 밟지 않게)

| 함정 | 지금은 |
|---|---|
| 빌더를 `--publish` 없이 돌려 **옛 판본을 검수**하고 "통과"라 했다 | `produce-card` 가 멈춘다 · 배관 점검 ④ |
| `rebuild-cards` 단독 실행이 **캡션 고정 서명을 날린다** | 체크리스트 §0 순서에 못박음 · 뒤에 `apply-signature` |
| 캡션 생성기가 **확정본을 덮어썼다** | `state: 오너 확정` 이면 멈춘다(`--force` 필요) |
| 자동 검수 PASS 를 믿고 그림을 안 봤다 → 곡선이 라벨을 뚫고, 캡션이 시간을 거슬렀다 | **PASS 는 "볼 준비가 됐다"는 뜻이다.** 반드시 눈으로 본다 |
| 확정 md5 를 문서에 베껴 적어 실제와 어긋났다 | 문서엔 **어디를 보라만** 적는다 · 배관 점검 ⑪ 이 잡는다 |
| `STATUS.md` 가 **폐기된 제목 규칙**을 가르치고 있었다 | 갱신 · 배관 점검 ⑪ 이 잡는다 |
