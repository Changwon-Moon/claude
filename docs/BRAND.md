# 브랜드 가이드 — wirit (위릿)

> 2026-07-18 운영자 확정. 이 문서는 모든 템플릿(base.css)의 계약이다. M2(템플릿 1호) 세션은 이 문서대로 브랜드 토큰을 구현한다.

## 1. 계정 정보

| 항목 | 값 |
|---|---|
| 브랜드명 | **wirit** (위릿) |
| 인스타그램 | **@wirit_note** (계정 개설 완료) |
| 워터마크 표기 | `@wirit_note` (모든 카드 하단 고정) — 로고 마크 병기 여부는 M2 시안에서 결정 |

## 2. 로고

- 형태: 잉크네이비 원형 배경 + 소문자 워드마크 `wirit` (웜화이트, 볼드 기하학적 산세리프) + **코발트 마침표** — 마침표가 브랜드 시그니처
- 카드 안 `wirit.` 뱃지·워터마크는 renderHtml이 CSS로 자동 삽입한다(별도 이미지 파일 불필요).
- 기업 로고 라이브러리는 `templates/_shared/logos/`에 있다(§4c). 없는 로고는 asset-hub 취득 절차로 채운다.

## 3. 컬러 팔레트 — 잉크네이비

| 역할 | 이름 | HEX | 토큰명 |
|---|---|---|---|
| 주색 / 텍스트·배경(다크) | 잉크네이비 | `#141821` | `--wirit-ink` |
| 배경(라이트) | 웜화이트 | `#FAFAF8` | `--wirit-paper` |
| 강조 / 액센트 | 코발트 | `#2E6BFF` | `--wirit-cobalt` |
| 상승·경고 | 레드 | `#E5484D` | `--wirit-red` |
| 보조 텍스트·차트 뉴트럴 | 블루그레이 | `#5B6B7F` | `--wirit-gray` |

### 사용 규칙 (운영자 확정 — 그대로 구현할 것)

- 배경은 **웜화이트**, 본문·수치는 **잉크네이비**
- 강조·차트 하이라이트·로고 마침표는 **코발트**
- **상승률/경고 수치만 레드**
- 차트의 비강조 바·캡션·라벨은 **블루그레이**
- **한 카드에 강조색은 코발트 1개 축**으로 유지 — 레드는 시그널 전용

### 파생 규칙 (시스템 반영용 — 운영자 규칙에서 도출)

- **하락 수치 = 코발트** (M3에서 채택, 운영자 최종확인 대기): 한국 시장 관례(상승 빨강·하락 파랑)와 팔레트가 자연 정합한다. 증시 카드에서 등락 표기는 그 자체가 강조이므로 "코발트 1개 축" 규칙과 충돌하지 않는다. market-daily에 적용됨(상승=레드, 하락=코발트).
- 표의 행 구분선·배경 밴딩: 잉크네이비의 저투명 버전(예: 6~8% 알파) — 별도 색 추가 금지
- 다크 카드 변형(잉크네이비 배경 + 웜화이트 텍스트)은 허용하되, 시리즈 단위로 통일 (같은 시리즈 안에서 라이트/다크 혼용 금지)
- 로고·기업 CI 색상은 예외 (기업 로고는 원색 유지)

### CSS 토큰 (M2 구현 계약)

```css
:root {
  --wirit-ink:    #141821;  /* 본문, 수치, 다크 배경 */
  --wirit-paper:  #FAFAF8;  /* 기본 배경 */
  --wirit-cobalt: #2E6BFF;  /* 강조 1축, 하락(제안) */
  --wirit-red:    #E5484D;  /* 상승·경고 시그널 전용 */
  --wirit-gray:   #5B6B7F;  /* 보조 텍스트, 비강조 차트 */
  --wirit-ink-06: rgba(20, 24, 33, 0.06);  /* 행 밴딩, 구분선 */
}
```

## 4. 타이포그래피

**폰트 시스템 (2026-07-18 확정 · 2026-07-23 제목 폰트 변경)**: 3개 역할로 분리.

| 역할 | CSS 변수 | 폰트 | 이유 |
|---|---|---|---|
| 헤드라인(제목) | `--font-title` | **태백체(TAEBAEK)** | 개성 강한 지오메트릭 디스플레이 (2026-07-23 운영자 지정, 이전 Wanted Sans) |
| 숫자(수치·순위·등락) | `--font-num` | **Wanted Sans** | 데이터 강조 + tabular 정렬 |
| 본문·라벨·캡션 | `--font-sans` | **Pretendard** | 긴 텍스트 가독성 |

- base.css @font-face 번들(Pretendard/Wanted Sans/Black Han Sans/**태백체**). Black Han Sans는 미사용(특집 옵션 보존).
- **태백체는 WOFF2 번들만 사용**: 원본 OTF(CFF+세로메트릭 vhea/vmtx)는 Chromium OTS가 거부해 렌더에서 폴백됨 → `scripts/font_pipeline.py`+`font-convert.yml`(Actions)에서 OTS 정화·CFF→TTF 변환 후 `TAEBAEK.woff2` 생성. **새 폰트 도입 시 반드시 이 파이프라인으로 WOFF2 변환 후 사용**(OTF 직접 참조 금지). 태백체는 단일 웨이트라 @font-face `font-weight:100 900`으로 선언해 전 웨이트 요청을 매핑(폴백 이탈 방지).
- 태백체는 Wanted Sans보다 자폭이 넓다 → nowrap 제목은 크기/여백 재확인 필수(예: index-2026 제목 78→64px).
- 실험용 전환 클래스: `font-pretendard` / `font-wanted` / `font-wanted-blackhan` (카드 루트). 미지정 시 위 확정 하이브리드.
- 위계: 제목 ExtraBold~Black(자간 타이트) / 수치 Bold(Wanted) / 라벨·캡션 Regular(Pretendard, 블루그레이)
- 숫자 tabular figures(고정폭) — 표 정렬 품질의 핵심.

## 4a-2. 카드 아이덴티티 요소 (2026-07-18 운영자 지정)

- **우상단 원형 로고**: 모든 카드에 `wirit.`(잉크네이비 원 + 흰 글씨 + 코발트 마침표) 자동 삽입(renderHtml). 스타일 `.wirit-corner`.
- **카드 테두리(2026-07-23 갱신)**: 최외곽 **얇은 흰색 라인 3px + 안쪽 잉크네이비 프레임 12px**(`.wirit-card::after`: `border:3px #fff` + `box-shadow:inset 0 0 0 12px 잉크`). 캡처 시 흰 배경·다크 배경 어디서도 카드 경계가 또렷하게 보이도록 흰 라인을 기본 적용. 레이아웃 영향 없는 오버레이.
- **하단 바**: 높이 1.5배(패딩 34px), 워드마크 `@wirit_note` 확대(37px).

## 4a-3. 아이덴티티 노출 기준 — 뱃지·인스타 아이디 배치 (2026-07-25 확정)

**원칙: 잘려도 남는다, 그러나 세 번을 넘지 않는다.**
캡처·크롭·재업로드로 돌아다녀도 출처가 남게 하되, 로고가 콘텐츠보다 눈에 띄면 광고처럼 보인다.
그래서 **카드 1장의 wirit 표식은 고정 2 + 조건부 1 = 최대 3개**로 못 박는다.

| 슬롯 | 위치 | 표기 | 적용 | 구현 |
|---|---|---|---|---|
| **A (고정)** | 우상단 | `wirit.` 로고 뱃지 | **모든 카드** | `.wirit-corner` — renderHtml 자동 삽입 |
| **B (고정)** | 하단 바 | `@wirit_note` 흰색 워드마크(37px) | **모든 카드**. 단 C를 쓰는 그래픽형 카드는 **아이디를 C로 옮기고 푸터에서 뺀다**(아이디는 카드당 1개, 중복 금지) | `.wirit-watermark` / `hideFooterId` |
| **C (조건부)** | 그래픽 안쪽 빈 코너 | `@wirit_note` 22px·잉크 16% | 아래 조건 **모두** 충족 시에만 1개 | `.wirit-stamp` (템플릿이 `stamp` 필드로 on/off + 좌표 지정) |

**2026-07-31 개정 — 지도형 카드는 아이디 3개까지 허용한다.**
`jeongbi-board`(정비사업 지도) 확정 때 오너가 "지금 그대로 3개 둔다"고 판단했다.
지도가 카드 면의 절반을 넘게 차지하는 카드는 크롭·재업로드로 **지도만 잘려 나가는** 일이 잦고,
그때 하단 바가 함께 사라져 출처가 통째로 없어진다. 그래서 이런 카드에 한해
그래픽 안쪽 스탬프를 **2개까지** 두고 하단 바 아이디도 유지한다(= 아이디 3개).
조건: ① 지도·차트가 카드 높이의 절반 이상 ② 스탬프끼리 충분히 떨어져 있을 것
③ 스탬프 자리는 **빈 곳을 재서** 고를 것(손으로 좌표를 찍지 않는다).
| **D (캐러셀 한정)** | 마지막 장 | 대형 워드마크 + 팔로우 유도 | 3장 이상 캐러셀의 **마지막 장에만** | 커버/마무리 템플릿 |

**슬롯 C를 붙이는 조건 (셋 다 만족해야 함)**
1. 지도·차트·사진 등 **하나의 그래픽이 카드 면적의 절반 이상**을 차지한다
2. 그 **그래픽만 잘라내도 콘텐츠로 성립**한다(= 도용·무출처 재업로드가 실제로 가능하다)
3. 그래픽 안에 **데이터와 겹치지 않는 빈 코너**가 있다 → 겹칠 자리밖에 없으면 **넣지 않는다**

**슬롯 C 스펙** — 이 투명도 값은 **BRAND.md가 정본**이다(다른 문서에 다른 값이 있으면 이쪽이 맞다).
- 밝은 배경(종이·연한 코로플레스) = 잉크 `opacity .16` / 다크·사진 배경 = 흰색 `opacity .26`(`.on-dark`) — **콘텐츠보다 먼저 눈에 띄면 실패**
- 크기 22px, 굵기 800, 표기는 항상 `@wirit_note` (로고 마크 아님 — 아이디가 유입을 만든다)
- 위치는 **템플릿이 고정 좌표로 지정**(자동 배치 금지 → 결정적 렌더 유지)

**금지**
- 대각선 반복 타일 워터마크(=콘텐츠 가독성 훼손, 스팸 인상)
- 데이터(막대·라인·지도 도형·라벨) 위에 겹치는 표식
- 표식 4개 이상, 같은 슬롯 중복, 카드마다 다른 위치로 흔들리는 배치

> 배경 워터마크(`wirit.` 대각 반복 opacity 0.03, 07-20 기록)는 **슬롯 C와 병용하지 않는다.** 그래픽형 카드는 C, 텍스트·표 위주 카드는 배경 워터마크 중 하나만.
