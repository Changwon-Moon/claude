## 2. 로고

- 형태: 잉크네이비 원형 배경 + 소문자 워드마크 `wirit` (웜화이트, 볼드 기하학적 산세리프) + **코발트 마침표** — 마침표가 브랜드 시그니처
- 원본 파일 위치(계약): `assets/brand/logo.png` (원형 프로필용), `assets/brand/wordmark.svg` (카드 내 워터마크용, M2에서 제작)
- **원본 업로드 필요**: 로고 파일은 아직 저장소에 없다. 넣는 방법은 [../assets/brand/README.md](../assets/brand/README.md) 참고 (GitHub 웹에서 드래그 업로드가 가장 쉬움)

## 3. 컬러 팔레트 — 잉크네이비

| 역할 | 이름 | HEX | 토큰명 |
|---|---|---|---|
| 주색 / 텍스트·배경(다크) | 잉크네이비 | `#141821` | `--wirit-ink` |
| 배경(라이트) | 웜화이트 | `#FAFAF8` | `--wirit-paper` |
| 강조 / 액센트 | 코발트 | `#2E6BFF` | `--wirit-cobalt` |
| 상승·경고 | 레드 | `#E5484D` | `--wirit-red` |
| 보조 텍스트·차트 뉴트럴 | 블루그레이 | `#5B6B7F` | `--wirit-gray` |

### 사용 규칙 (운영자 확정 — 그대로 구현할 것)

- 배경은 **웜화이트**, 본문·수치는 **잉크네이비**
- 강조·차트 하이라이트·로고 마침표는 **코발트**
- **상승률/경고 수치만 레드**
- 차트의 비강조 바·캡션·라벨은 **블루그레이**
- **한 카드에 강조색은 코발트 1개 축**으로 유지 — 레드는 시그널 전용

### 파생 규칙 (시스템 반영용 — 운영자 규칙에서 도출)

- **하락 수치 = 코발트** (M3에서 채택, 운영자 최종확인 대기): 한국 시장 관례(상승 빨강·하락 파랑)와 팔레트가 자연 정합한다. 증시 카드에서 등락 표기는 그 자체가 강조이므로 "코발트 1개 축" 규칙과 충돌하지 않는다. market-daily에 적용됨(상승=레드, 하락=코발트).
- 표의 행 구분선·배경 밴딩: 잉크네이비의 저투명 버전(예: 6~8% 알파) — 별도 색 추가 금지
- 다크 카드 변형(잉크네이비 배경 + 웜화이트 텍스트)은 허용하되, 시리즈 단위로 통일 (같은 시리즈 안에서 라이트/다크 혼용 금지)
- 로고·기업 CI 색상은 예외 (기업 로고는 원색 유지)

### CSS 토큰 (M2 구현 계약)

```css
:root {
  --wirit-ink:    #141821;  /* 본문, 수치, 다크 배경 */
  --wirit-paper:  #FAFAF8;  /* 기본 배경 */
  --wirit-cobalt: #2E6BFF;  /* 강조 1축, 하락(제안) */
  --wirit-red:    #E5484D;  /* 상승·경고 시그널 전용 */
  --wirit-gray:   #5B6B7F;  /* 보조 텍스트, 비강조 차트 */
  --wirit-ink-06: rgba(20, 24, 33, 0.06);  /* 행 밴딩, 구분선 */
}
```

## 4. 타이포그래피 (방향 — M2 시안에서 확정)

- 후보: Pretendard (무료·상업 이용 가능, 웹폰트 로컬 번들) — 로고의 기하학적 산세리프와 결이 맞음
- 위계: 제목 ExtraBold~Black / 핵심 수치 Bold(큰 사이즈, 자간 타이트) / 라벨·캡션 Regular(블루그레이)
- 숫자는 tabular figures(고정폭 숫자) 사용 — 표 정렬 품질의 핵심

## 5. 카드 공통 레이아웃 규칙 (TEMPLATES.md §5 보충)

- 상단: 카테고리 뱃지(코발트 테두리 또는 배경) + 제목(잉크네이비 Black)
- 하단 고정: 출처 표기(블루그레이, 작게) + `@wirit_note` 워터마크
- 참고 계정과의 차별점: 원색 남발 대신 **"신문 같은 절제 + 코발트 한 방"** — 피드에서 위릿만의 톤이 한눈에 구분되는 것이 목표
