## 2026-08-03 (16) — 청약 카드 **원커맨드 자동화** (`scripts/danji-card.mjs`)

오너: "향후 *새로운 조감도 사진과 함께 [단지명] 청약 위릿 카드 만들어줘* 하면 자동화될 수

### 만든 것

```bash

```

### 자동화를 위해 먼저 고쳐야 했던 것 셋

1. **빌드 대상 목록이 코드에 손으로 적혀 있었다.** `cards = [["danji-hangang", …], …]`.
   새 단지를 데이터셋에 넣어도 카드가 안 나온다 — 자동화의 전제가 깨진다.
   → `doc.danji` 전체를 돌고 `--only <id>` 로 한 곳만도 만든다. 출력 파일명은 `slug` 가 정한다.
2. **크롭 px 가 CSS 에 박혀 있었다**(`top: -63px`). 한강 사진 전용 숫자다. 다른 사진을 넣으면
   하늘 비율이 조용히 틀어진다.
   → 빌더가 JPEG/PNG 헤더에서 원본 크기를 직접 읽어 계산한다:
   `shift = round((round(1080·h/w) − 446) × 0.425)`.
   **이 식은 오너가 승인한 값(63px)을 그대로 재현한다** — 렌더 md5 가 `424ea5ff…` 로 동일함을
   확인했다. 1600×900 테스트 사진에서는 69px 가 나왔고 하늘 비율이 유지됐다.
   가로로 너무 긴 사진은 던지고, 크롭이 원본 아래 5%(건설사 고지문 자리)에 닿으면 경고한다.
   → 규칙: **사진에 딸린 수치는 CSS 가 아니라 데이터로 흐른다.**
3. **동수·층수가 없으면 `String(null)` → "null"** 이 찍혔다. 신규 단지는 이 값이 비어 있다.
   → 없으면 회색 '미고지'. 지어내지 않는다.

| 자리 | 분양 예정 | 무순위 |
|---|---|---|
| 머리 밴드 | 타입별 분양가 | **전용면적별 잔여 세대** |

**왜 분양가를 못 쓰나**: 청약홈 무순위 공고는 공급금액을 `사업주체 문의`로 비워 둔다.
없는 값을 억지로 채우는 대신 **있는 값 중 가장 궁금한 것**(어떤 평형이 얼마나 남았나)을 올렸다.

## 2026-08-05 (22) — 글로벌 자본 임대시장 카드(world-capital) 제작·확정

뉴스 소재("글로벌 투자자의 국내 임대시장 진출")를 A안(지도+표)으로 카드화. 오너와 여러 번
반복하며 굳힌 교훈. 확정본 = 고정물 md5 등록, 캡션 확정.

- **표 정렬이 '가운데처럼' 보이면 grid 의 `auto` 열을 의심한다.** 값 열(위치)을 왼쪽정렬 했는데도
  행마다 시작선이 흔들렸다 — 오른쪽 금액 열이 `auto`(내용폭)라 행마다 폭이 달라, 그 여파로
  가운데 `1fr` 열의 좌측선이 매 행 이동했다. **금액 열을 고정폭(168px)으로** 박으니 정렬이 고정됐다.
  → 여러 행이 세로선을 공유해야 하는 표는 **가변(auto) 열을 두지 않는다**(값 열은 fr·고정폭으로).
- **큰 제목(좌) + 지도(우) 2열은 서로 폭을 뺏는다.** 서울 지도는 가로로 넓어 폭이 좁아지면 세로도
  줄어든다. "제목 2배 + 지도 최대"는 동시에 불가 — 오너에게 트레이드오프를 먼저 말하고, 제목 줄수를
  정해(오너 지시 5줄) 그 폭에서 지도를 최대화한 뒤 **지도를 세로 중앙 배치**해 빈 공간을 없앴다.
- **designQa 의 `titlegap`(제목-바로아래 요소 간격)은 2열 레이아웃에서 오탐**이 난다(제목은 좌열,
  아래 요소는 우열 지도라 음수 간격으로 잡힘). error 아님(warn) — 시안 설명에 "2열 오탐"으로 명시하고
  넘긴다. (좌표로 못 가르는 예외 → 검수 코드 승격 대상 아님, 문서로 남긴다.)
- **뉴스 소재 캡션의 억 단위 금액은 전부 카드에 있어야 한다(caption-number 검수).** CPPIB 병기용으로
  캡션에 '1,330억~5,000억'을 넣었더니 카드엔 그 값이 없어(카드는 '약1,500실' 표기) 검수가 막았다.
  → 상충·미표기 금액은 캡션에서 뺀다. 카드와 캡션 수치가 어긋나면 그게 오보다(오보 0).
- **지도 핀 좌표는 손으로 찍지 않는다.** 서울 동/시군구 경계 지오데이터에서 중심점을 계산했다
  (분동은 평균). 새 자산: `scripts/lib/seoul-invest-map.mjs`(서울 25구+투자 위치 핀),
  `capital-invest-map.mjs`(수도권), `world-map.mjs`(세계지도, 미사용 보존). world 지오는
  `data/geo/world-countries.geojson`(world-atlas 110m 변환).
- **서울 외(이천·광역)는 지도에 안 찍고 표에만.** 지도 범위(서울)와 표 정보(수도권 전역)를 분리해
  지도는 깔끔하게, 세부는 표가 갖는다.
